# OpenClaw vs Hermes Agent 对比分析

> 综合多篇公众号文章的对比观点。

## 核心对比维度

### 1. 架构设计
- [[OpenClaw]]：基于 Skill + MCP 扩展的多 Agent 平台，强调灵活性和社区生态
- [[Hermes-Agent]]：更轻量的 Agent 框架，强调简洁和 Token 效率

### 2. Token 效率
- Hermes Agent 在 Token 消耗上更优，部分场景仅为 OpenClaw 的 1/20
- 有工具可同时为两者优化 Token 消耗达 60%

### 3. 多 Agent 协作
- OpenClaw 有更成熟的多 Agent 生态（路由、协作、Sub-Agent）
- Hermes Agent 在单 Agent 场景下更高效

### 4. 使用场景
- OpenClaw 适合复杂的企业级多 Agent 场景
- Hermes Agent 适合个人开发者快速搭建 AI 助手
- 两者可以同机部署、协同工作
