# 万万没想到，淘宝竟然开放给龙虾了【openclaw】

> 来源: [ENCORD](https://mp.weixin.qq.com/s?__biz=MzU2MzM5NjA2Mw==&mid=2247506771&idx=1&sn=b501a641b6c320629e56a22cf8a5c214&chksm=fda4772367336d0e07f841d5d32c85fc0d4506b4b190ab35b225e604a81046bbf238a03740e6&mpshare=1&scene=1&srcid=0417lRWT3T99buOQGfWWqN6M&sharer_shareinfo=400559e76edbfa2b0652f5dc0d455213&sharer_shareinfo_first=400559e76edbfa2b0652f5dc0d455213) | 2026-04-17

## 摘要

淘宝桌面客户端已向 OpenClaw（龙虾）开放原生 API 接口。这意味着：
买东西这件事的玩法，可能真要变天了。
以前逛淘宝很累，像一场耐力赛。要反复挑、看参数、问客服。现在直接一个龙虾能搞定，AI 会自己去搜商品、按照你的指令筛完之后直接帮你放进购物车。
我只需要最后付款。
真的，省脑子到有点离谱。
───
实测场景
**场景 A：采购**
• 指令：「Mac mini M4，最低价优先」
• 人工介入点：仅付款确认
**场景 B：限时抢购**
• 指令：「定时任务：找到某商品并定时抢购」
**场景 C：售后自动化**
• 覆盖场景：催发货、自动评价、发票申请、优惠券谈判
• 价值：消除重复性人工操作
───
启用路径
淘宝桌面版 → 设置 → AI 设置 → 开启 OpenClaw 接入
───
