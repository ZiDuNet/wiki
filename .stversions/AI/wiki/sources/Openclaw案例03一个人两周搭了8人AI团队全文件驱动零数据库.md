# 【Openclaw案例#03】一个人两周搭了8人AI团队，全文件驱动零数据库

## 摘要

Jason 是一家 BPO 公司的总监。他一开始只造了一个通用 AI 助手 Oscar，负责邮件、研究、写作、代码审查——啥都干。
结果很快就崩了。Oscar 写博客写到一半被拉去审代码，回来思路全断。不是能力问题，是**上下文切换**的问题。
于是他做了一个大胆的决定：把一个全能 Agent 拆成 8 个专职 Agent。
**🦞 团队阵容：**
Oscar（首席参谋）负责协调全局。Radar（情报员）全网监控有价值的信号。Muse（策略师）想创意和角度。Ink（写手）负责产出文字。Lens（设计师）做视觉。Forge（工程师）写代码部署。Shield（安全官）审计漏洞。Guru（导师）记录团队教训，帮大家复盘学习。
**⚙️ 最硬核的设计：全文件驱动**
没有数据库，没有向量搜索。所有 Agent 的记忆都是 Markdown 文件——日志、项目状态、长期记忆。全部 Git 版本控制，VS Code 直接打开就能看。透明、可追溯、零黑箱。
**📊 关键指标："直通率"**
他们只追踪一个核心数据：Agent 写完的内容，能不能直接发布不用改？两周内做到了 80% 直通率。
