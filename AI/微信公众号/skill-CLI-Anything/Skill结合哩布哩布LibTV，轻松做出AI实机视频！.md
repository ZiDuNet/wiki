**Skill思路**

分享这个 Skill 的版本和思路。

Skills 分为两个版本：

轻量版（lite）：如果希望最终只聚焦于提示词，而不要其他的废话，节省 token，可以安装这个版本。

完整版：提示词从头到尾非常详细。

比如我有一个灵感、想法、基于角色想做一个游戏效果等等，我输入的内容是角色图片或关键词，加上游戏类型以及我想要补充的细节。

输出会是一份可以直接复制并提供给图片或视频模型的完整提示词文档，其中包含角色锚点、UI 规范、6 到 12 个镜头的图片提示词和视频提示词序列、时间轴，如果是剧情向的内容，还会额外加上字幕脚本和 TTS 配音脚本。

![](assets/img_ae81c59eeb6c.png)

这整套设计的骨架是为了保证三个方面：

1. 游戏的角色不会飘，会整体保持一致性。

2. UI 界面和 HUD 保持一致，这样就不会出现上一个镜头跟下一个镜头连不起来，从而失去那种完整的实机游戏感觉的情况。

3. 每个镜头都会使用“图片提示词 + 视频提示词”的配对，图片和视频提示词很清晰。图片生成经由Lib Image 生成关键帧，视频生成使用 SeedDance 2.0 VIP 生成动态效果。

下面是输出文件包的内容截图，可以看到图片分成参考图提示词4组，分镜图提示词和分镜图生成视频提示词各6组（默认6组，可以自行要求）。有了所有提示词了，接下来就可以一步步生成图片和连线了。

这个最适配的工具是 LibTV，连线方便参考也清晰直观，所以我 Skill 的参考图的格式也基本按照他们的来的。

也是在这次测试里，我更能理解 LibTV 为什么要做 Creator + Agent 双入口。Creator 端适合我们手动检查角色、UI、镜头和节奏，Agent 端则更轻松随意，可以把重复的生成、拆分、编排动作自动化。

多宫格切分让分镜更规整，多种图片和视频模型应对不同需求场景，最后再在画布里按顺序合成。后面如果要做更长的系列内容，也可以继续把角色多视图、剧情推演四宫格、镜头多角度，多机位九宫格这些能力一起用起来。

**调用 Skill**

安装完 Skill 以后，直接在 Claude Code 或其他支持 Skill 的 CLI 工具里说类似的话就可以调用：“我有一个制作游戏实机效果的提示词 Skill，帮我调用一下它。”

如果我们已经有明确主题，就可以直接告诉它自己想做什么类型的视频。比如东方神话、赛博修仙、RPG、古风冒险、机甲战斗、第一人称视角、像素风等等都可以。

如果当下没有灵感，也可以先让它帮我们发散方向。比如我当时就是直接问它：**有没有什么很酷炫、很容易出片的方向？**它给了我一组按视觉冲击力排序的方向，比如黑神话系东方神话、深海百慕大潜艇救援、蒸汽朋克空中堡垒、山海经风格等等。提问很通俗也没有关系，完全没有什么高端的打法，就口语化沟通就好👇

![](assets/img_476bd010d4df.png)

我最后选了其中一个方向，然后继续补充自己的风格要求：想做彩色、水墨质感、中国古代风格，而且要有毛笔笔触的感觉。

这一步该描述清楚的还是要讲清楚，想要的风格想要的元素和细节都要说明白，因为这里补充的关键词，会直接影响后面角色、UI、镜头画面的统一感。我们描述得越清楚，后面 Skill 写出来的整个提示词包越接近想要的效果。

**输出完整文档**

首先是简介，是AI基于我们的要求进行的拓展和延展👇

![](assets/img_ca20d1cefb58.png)

第一个是角色四视图的提示词。它负责把主角的形象先定下来，比如服装、发型、气质、武器、正侧背视图这些。

![](assets/img_e2d294a39649.png)

![](assets/img_6f93bd547ec9.png)

第二个是 UI 风格总览。Skill 限制了后面所有 HUD、头像、状态条、地图、按钮、任务提示，都尽可能参考这张图来做。这样最后看起来会像同一个游戏里的界面，而不是每个镜头都不一样，看起来完全没有一致性和连贯感。这里只有 UI 没有人物和场景，是为了它作为参考的时候不会影响输出图的画面。

![](assets/img_e8b8cf23cde6.png)

后面还有 UI 规范字典、进度条状态链表、六个镜头的图片 Prompt 和视频 Prompt。这里大家要注意，图片 Prompt 和视频 Prompt 是两套内容，复制的时候一定不要混。

如果发现某张图人物崩了、UI 变了、场景逻辑不对，建议就在图片阶段重跑。不要等到视频生成完再修，那样更费积分，也更难精准调整。

**生成视频**

图片确认没问题以后，就可以把每张镜头图拖到视频生成节点里。这一步复制的是视频 Prompt。文档里已经写好了每个镜头的运动方式、镜头语言、UI 动效、角色动作、环境变化和时长建议。

![](assets/img_cea48f560365.png)

视频里我用的是 SeedDance 2.0 VIP 的全能参考。LibTV 最近也把 SeeDance 2.0 满血版放上来了，满不满月相信大家看我前面输出的视频就有判断了。它基本上也不怎么需要抽卡。也可以根据自己的需求尝试其他模型，但同一条片子里分辨率尽量保持统一，这样效果会更好一些。

所有视频片段生成完以后，把它们全选上拉出来，选择视频合成👇

![](assets/img_b6972a8f51a5.png)

接着把镜头 1 到镜头 6 调整好顺序，再点击合成视频。最后就能得到一条完整的实机感短片。

**个人IP做视频**

除了从零生成一个主角，这个 Skill 还有一个很好用的玩法：可以把已有角色图发给它，让它基于这张图继续做四视图、UI 和镜头包。

我之前也用自家猫试了一版。先把猫猫图片给它，让它把这只猫当作主角，做一个游戏人设。它会继续生成四视图、UI、六张镜头图提示词，我再按照前面的逻辑去生成图和视频。猫之贪玩蓝月有了哈哈哈👇

**完整流程梳理**

1. 调用实机游戏视频提示词 Skill
2. 给灵感和想法，让 Skill 给几个方向，细化，输出 Markdown 文档
3. 检查文档提示词，尤其是角色、UI、镜头和参考图关系
4. 打开 LibTV，使用 Lib Image 生成角色四视图和 UI 总览图、分镜图
5. 检查图片中的人物、UI、地图、按钮和场景细节
6. 根据提示词拉线条，图生视频

7. 在 LibTV 工作区把所有片段按顺序拉到视频合成里，合成最终视频
