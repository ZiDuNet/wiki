作为一名图书情报专业的研究生，你可能正面临着论文撰写、数据挖掘、课题申报等多重挑战。而 Agent Skills 的出现，正在改变科研工作者与 AI 的协作方式。这篇文章将带你从零开始，掌握如何用 Skills 提升科研效率。

## 一、Skills 到底是什么？为什么它不是“长提示词”

很多人第一次接触 Skills 时会困惑：这不就是把提示词写长一点吗？

**答案是：完全不同。**

传统的提示词就像你给 ChatGPT 发一段指令，它只能“说”不能“做”。而 Skills 是给 **Agent**（智能代理）用的技能包，Agent 不仅能对话，还能**动手干活**——读取文件、调用工具、执行脚本、生成图表，甚至在遇到问题时自己调试解决。

用一个比喻来说明：

- **传统提示词** = 你给助手口头交代任务，助手只能回答“好的，您可以这样做……”，剩下的活还得你自己干
- **Agent Skills** = 你给助手一本操作手册，助手看完后自己完成整个任务流程，遇到问题还能自己解决

### Skills 的三层结构

一个标准的 Skill 包含：

1. **元数据（Metadata）**：告诉 Agent 这个技能是干什么的、什么时候该用
2. **指令（Instructions）**：详细的工作流程、方法论、注意事项
3. **资源和代码（Resources/Scripts）**：附带的脚本、模板、参考文档

关键特性是**渐进式加载**：不是一股脑把所有内容塞进上下文，而是用到什么加载什么。这意味着你可以给一个 Skill 附带几十份参考文档，只要这次任务用不上，它们就不占用宝贵的上下文窗口。

## 二、科研场景中的 Skills 应用思路

在开始动手之前，我们需要理解一个核心原则：**因需而建，可组合，可迭代**。

### 什么时候需要做成 Skill?

**不要为了做 Skill 而做 Skill。** 真正需要 Skill 的场景是：

✅ **你反复做同一类任务，每次都要重复解释**

- 例如：每次写文献综述都要强调“按时间线梳理、突出研究缺口、使用学术语言”

✅ **任务需要多个步骤串联，但又不值得开发一套系统**

- 例如：文献筛选 → 信息提取 → 结构化整理 → 生成综述表格

✅ **需要调用特定工具或遵循特定规范**

- 例如：使用特定的引文格式、调用数据分析脚本、生成符合期刊要求的图表

❌ **不需要做成 Skill 的情况：**

- 一次性任务
- Agent 本身就知道怎么做的事（比如“帮我总结这篇论文”）
- 简单的对话式咨询

### 科研写作中的 Skills 组合思路

好的 Skills 应该像乐高积木一样可以组合。以论文写作为例：

```
素材收集 Skill → 文献分析 Skill → 大纲生成 Skill → 学术写作风格 Skill → 引文格式化 Skill
```

每个 Skill 专注做好一件事，需要时可以灵活组合。比如：

- 写开题报告时：文献分析 + 研究设计 + 学术写作风格
- 写数据分析章节时：数据处理 + 可视化 + 学术写作风格
- 准备课题申报时：文献分析 + 创新点提炼 + 申报书格式

## 三、为图书情报专业量身定制的 Skills

基于你的专业特点，我建议你优先建立以下几类 Skills:

### 1. 文献管理与分析 Skill

**场景**：你需要阅读大量文献，提取关键信息，梳理研究脉络。

**Skill 能做什么**：

- 自动提取论文的研究问题、方法、发现、局限
- 按主题或时间线整理文献
- 识别研究缺口和未来方向
- 生成结构化的文献综述表格

**示例指令结构**：

```
# 文献分析 Skill  ## 元数据 Name: literature-analysis Description: 当用户需要分析学术文献、提取关键信息或生成文献综述时使用  ## 指令 你是一位图书情报学领域的资深研究者。在分析文献时:  1. 信息提取标准:    - 研究问题/目标    - 理论框架    - 研究方法(定性/定量/混合)    - 核心发现    - 研究局限    - 未来研究方向  2. 分析维度:    - 时间维度:研究主题的演进脉络    - 方法维度:不同研究方法的应用趋势    - 理论维度:主要理论框架的发展  3. 输出格式:    - 使用 Markdown 表格呈现结构化信息    - 关键概念用**加粗**标注    - 提供简明的综述性段落  4. 学术规范:    - 保持客观中立的学术语言    - 准确引用原文观点    - 明确区分描述性总结和批判性分析
```

### 2. 学术写作风格 Skill

**场景**：你希望 AI 生成的内容符合学术规范，而不是口语化或营销式的表达。

**Skill 能做什么**：

- 确保使用学术语言和专业术语
- 遵循“提出问题-文献回顾-方法-发现-讨论”的学术逻辑
- 避免过度主观或情绪化的表达
- 正确使用学术引文格式

**核心要点**：

```
## 学术写作规范  ### 语言风格 - 使用第三人称客观表述(避免"我认为""我们发现") - 使用学术词汇(如"表明""揭示""阐释"而非"显示""说明") - 避免绝对化表述(如"完全""绝对""唯一")  ### 逻辑结构 - 每段有明确的主题句 - 论点需要文献或数据支撑 - 段落间有清晰的逻辑过渡  ### 引文规范 - 直接引用需标注页码 - 间接引用需准确转述原意 - 使用 APA/GB/T 7714 等规范格式
```

### 3. 数据处理与可视化 Skill

**场景**：你需要处理问卷数据、文本挖掘结果或引文分析数据，并生成符合学术规范的图表。

**Skill 能做什么**：

- 调用 Python 脚本进行数据清洗和统计分析
- 生成学术论文常用的图表（柱状图、折线图、热力图、网络图）
- 确保图表符合期刊投稿要求（字体、分辨率、配色）

**技术要点**：

- 可以附带 Python 脚本（如使用 pandas、matplotlib、seaborn）
- 可以引用数据分析的最佳实践文档
- Agent 会根据数据特点自动选择合适的可视化方式

### 4. 课题申报书生成 Skill

**场景**：你需要撰写国家社科基金、省级课题等申报材料。

**Skill 能做什么**：

- 根据课题指南提炼研究问题
- 生成“研究现状-研究问题-研究内容-研究方法-创新点-预期成果”的完整结构
- 确保语言符合申报书的规范和评审习惯

**关键模块**：

- 研究现状综述（突出研究缺口）
- 创新点提炼（理论创新/方法创新/应用创新）
- 研究方案设计（可行性论证）
- 预期成果描述（论文/专著/咨询报告）

## 四、动手实践：创建你的第一个 Skill

现在，让我们一步步创建一个实用的 Skill。我以“学术文献信息提取”为例。

### 第一步：明确需求

在创建 Skill 之前，先用自然语言描述清楚你的需求：

> 我需要一个技能，能够帮我快速提取学术论文的核心信息，包括研究问题、方法、主要发现和研究局限。输出格式要结构化，方便我后续整理到文献综述表格中。

### 第二步：让 Agent 帮你创建 Skill

在 Claude Code 中，你可以直接说：

```
我需要创建一个文献信息提取的 Skill。 当我给它一篇论文(PDF或文本)时,它能自动提取: 1. 研究问题/目标 2. 理论框架 3. 研究方法 4. 核心发现 5. 研究局限 6. 未来研究方向  输出格式用 Markdown 表格,方便我复制到文献综述中。
```

Agent 会帮你生成一个 SKILL.md 文件，并保存到 `~/.skills/` 目录下。

### 第三步：测试和迭代

创建完成后，立即测试：

```
使用文献信息提取 Skill,帮我分析这篇论文:[上传PDF或粘贴文本]
```

如果发现问题（比如提取的信息不够准确，或者格式不符合预期），直接告诉 Agent:

```
这个 Skill 提取的"研究方法"部分太简略了, 我希望它能详细说明是定性还是定量、具体用了什么方法(问卷/访谈/文本分析等)。 请优化这个 Skill。
```

Agent 会自动修改 Skill 并重新测试。这种“边用边改”的方式，比传统的软件开发快得多。

### 第四步：组合使用

当你有了多个 Skills 后，可以组合使用：

```
使用文献信息提取 Skill 分析这5篇论文, 然后用学术写作风格 Skill 生成一段文献综述。
```

Agent 会自动调度这两个 Skills，完成整个流程。

## 五、进阶技巧：让 Skills 更强大

### 技巧 1：附带参考文档

你可以在 Skill 文件夹中放入参考资料，比如：

- 你们学校的论文格式规范（PDF）
- 目标期刊的投稿指南
- 优秀论文的范例

Agent 会在需要时自动读取这些文档，确保输出符合规范。

### 技巧 2：利用开源工具

如果你的任务需要特定工具（比如文本挖掘、引文分析），可以让 Agent 帮你把 GitHub 上的开源项目封装成 Skill。

例如，你想用 Python 的 `wordcloud` 库生成词云图：

```
帮我创建一个词云生成 Skill, 使用 wordcloud 库, 输入是一段文本, 输出是高分辨率的词云图片, 配色要适合学术论文(黑白或蓝色系)。
```

Agent 会自动安装依赖、编写脚本、测试运行。

### 技巧 3：建立个人 Skills 库

随着你使用 Skills 的增多，建议建立自己的 Skills 管理体系：

- **通用类**：学术写作风格、引文格式化
- **文献类**：文献分析、综述生成
- **数据类**：数据清洗、统计分析、可视化
- **申报类**：课题申报书、开题报告

定期回顾和优化这些 Skills，它们会成为你的“科研工具箱”。

## 六、常见问题解答

### Q1：我不会编程，能用 Skills 吗？

**完全可以。** Skills 的核心是用自然语言描述你的需求和流程，Agent 会帮你处理技术细节。即使需要调用脚本，Agent 也会自动编写和调试。

### Q2: Skills 会不会占用很多上下文？

不会。Skills 采用**渐进式加载**，只有被调用时才加载相关内容。你可以安装几十个 Skills，但只有用到的才会占用上下文。

### Q3：用 GLM 4.7 效果怎么样？

GLM 4.7 是智谱的开源模型，在中文理解和代码生成上表现不错。对于学术写作这种重逻辑、重结构的任务，完全够用。如果遇到复杂的数据分析任务，可以考虑切换到更强的模型。

### Q4: Skills 和传统的提示词模板有什么区别？

| 维度 | 传统提示词模板 | Agent Skills |
| --- | --- | --- |
| 执行方式 | 每次手动复制粘贴 | 自动触发，按需加载 |
| 工具调用 | 不支持 | 支持（读文件、运行脚本、生成图表） |
| 可组合性 | 难以组合 | 像乐高一样灵活组合 |
| 迭代成本 | 需要手动更新所有地方 | 修改一次，全局生效 |
| 错误处理 | 遇错停止，需要人工介入 | Agent 自动调试和修复 |

### Q5：我应该从哪个 Skill 开始？

建议从**最高频的痛点**开始：

- 如果你最头疼的是文献综述 → 先做“文献分析 Skill”
- 如果你经常需要润色学术语言 → 先做“学术写作风格 Skill”
- 如果你在准备开题 → 先做“开题报告生成 Skill”

不要一开始就想做一个“万能 Skill”，而是从小而美的单点突破开始。

## 七、实战案例：用 Skills 完成一篇文献综述

让我们用一个完整的案例，演示 Skills 如何赋能科研写作。

### 场景设定

你需要写一篇关于“数字人文在图书馆中的应用”的文献综述，有 20 篇相关论文需要阅读和整理。

### 传统做法

1. 逐篇阅读论文，手动记笔记（耗时 10+ 小时）
2. 在 Word 里整理文献信息表格（耗时 2 小时）
3. 撰写综述段落，反复修改语言（耗时 3 小时）
4. 检查引文格式，手动调整（耗时 1 小时）

**总计：16+ 小时**

### 使用 Skills 的做法

**第一步：批量提取文献信息（10 分钟）**

```
使用文献信息提取 Skill, 分析这 20 篇论文, 生成一个汇总表格。
```

Agent 会自动读取所有论文，提取关键信息，生成结构化表格。

**第二步：生成综述框架（5 分钟）**

```
基于上面的文献表格, 使用学术写作风格 Skill, 生成一个文献综述的大纲, 按"研究主题-方法演进-应用案例-研究缺口"组织。
```

**第三步：撰写综述段落（15 分钟）**

```
根据大纲, 使用学术写作风格 Skill, 撰写每个部分的综述段落, 每段 200-300 字, 引用相关文献。
```

**第四步：格式化引文（5 分钟）**

```
使用引文格式化 Skill, 将所有引文转换为 GB/T 7714 格式。
```

**总计：35 分钟**（不含你的审阅和调整时间）

效率提升：**27 倍**

## 结语：从“AI 用户”到“AI 协作者”

Skills 的本质，是让你从“使用 AI”转变为“与 AI 协作”。

以前，你是 AI 的“保姆”，每次都要手把手教它怎么做。现在，你是 AI 的“导师”，把你的经验和方法论封装成 Skills, AI 就能自主完成复杂任务。

对于科研工作者来说，这意味着：

- **更多时间思考**，而不是被机械性工作占据
- **更高的产出质量**，因为 AI 能帮你处理细节和规范
- **更快的迭代速度**，因为修改和优化成本极低

记住三个核心原则：

1. **因需而建**：不要为了做 Skill 而做 Skill，从真实痛点出发
2. **可组合**：每个 Skill 做好一件事，需要时灵活组合
3. **可迭代**：边用边改，让 Skills 随着你的需求不断进化

现在，打开你的 Claude Code，开始创建第一个 Skill 吧。

祝你科研顺利！
