# AiToEarn

> Let's use AI to Earn!

## 项目简介

AiToEarn 是一个全栈AI驱动的内容增长与变现平台，集创作、发布、互动和变现于一体，为创作者、品牌和企业提供跨全球最受欢迎平台的自动化内容解决方案。

该项目通过先进的AI技术，帮助用户从创意构思到多渠道发布，再到数据分析与盈利，实现完整的内容生命周期管理。

- AI辅助内容创作功能

## 安装与部署

### Docker Compose 部署（推荐）

Docker Compose是最简单快捷的部署方式，无需手动安装MongoDB或Redis，所有依赖服务都由Docker Compose自动启动和管理。

```bash
# 获取部署文件
# 从GitHub仓库下载最新的docker-compose.yml文件和.env.example配置文件
# 将.env.example复制为.env并配置

# 启动服务
docker-compose up -d
```

### 桌面客户端
支持Windows、macOS和Linux平台，提供Electron桌面客户端，兼顾云端服务的灵活性和本地使用的便捷性。
