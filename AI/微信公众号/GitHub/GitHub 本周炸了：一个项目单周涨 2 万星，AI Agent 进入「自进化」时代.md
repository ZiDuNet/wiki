## PART 01 本周明星项目

### 1️⃣ hermes-agent — 自改进 AI Agent

一周新增：19,019 ⭐ | 总⭐：115,393

总 star 突破 11 万，本周继续狂飙。Nous Research 的旗舰 Agent 项目，定位"与你一起成长的 Agent"。

### 2️⃣ claude-mem — Claude Code 跨会话记忆

一周新增：5,961 ⭐ | 总⭐：67,087

Claude Code 生态中最火插件，没有之一。自动记录编码会话的一切操作，AI 压缩后注入未来会话，Claude 终于有"长期记忆"了。

**核心亮点：**

- 全自动：无需手动配置，装上就生效
- AI 压缩：利用 Claude 自身的 agent-sdk 压缩上下文
- 跨会话连续：下次打开直接接着上次的工作流
- 开发者刚需：解决了长期项目最痛的记忆断层问题

**适合：** 长期项目开发者、Claude Code 重度用户

GitHub：https://github.com/thedotmack/claude-mem

### 3️⃣ multica — AI Agent 团队管理平台

一周新增：5,421 ⭐ | 总⭐：20,724

**适合：** AI 团队管理者、需要协调多 Agent 的开发者

## PART 02 本周趋势总结

本期 GitHub 热点可以总结为一个字：**Agent**

| 趋势 | 代表项目 | 关键词 |
| --- | --- | --- |
| 自进化 Agent 爆发 | hermes-agent、GenericAgent、evolver | 自动学习、持续进化、token 效率 |
| Claude 生态繁荣 | claude-mem、claude-context、free-claude-code | 记忆、上下文、免费使用 |
| Agent 工程化 | multica、Archon、openai-agents-python | 团队管理、流水线、生产级 |
| AI 应用落地 | VoiceBox、ppt-master、TrendRadar | 语音、办公、舆情 |

**三个信号值得关注：**

1. **Agent 正在从"玩具"走向"工具"** — hermes-agent 突破 11 万星、multica 和 Archon 让 Agent 开发工程化，说明社区已经不满足于 demo，开始认真做产品。
2. **Claude 生态的插件化速度超预期** — 记忆管理（claude-mem）、代码搜索（claude-context）、免费使用（free-claude-code），Claude Code 的三大痛点正在被社区一周内解决。
3. **自进化成为 Agent 的新共识** — GenericAgent 和 evoler 都在探索"让 Agent 自己变得更强"的范式，这可能是 2026 年 Agent 领域最重要的技术方向。

AI Agent 的 2026，才刚刚开始。
