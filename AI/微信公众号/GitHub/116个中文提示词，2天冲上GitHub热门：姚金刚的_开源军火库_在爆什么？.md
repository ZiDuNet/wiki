GEO：今年最值得关注的营销新概念

这个仓库里最值得单独拎出来讲的是 **AI营销** 这个分类，28个提示词，其中大部分都在讲一个概念——**GEO**。

GEO 是什么？

SEO 你知道吧，Search Engine Optimization，搜索引擎优化，目的是让 Google、百度更容易搜到你。

GEO 是 **Generative Engine Optimization**，生成式引擎优化。目标是让 AI 模型在回答用户问题时，更倾向于引用你的内容。

打个比方：SEO 是让百度收录你，GEO 是让 ChatGPT 在回答用户问题时报出你的名字。

为什么重要？因为现在越来越多人开始用 AI 搜索（ChatGPT、Perplexity、豆包AI搜索），用户不问百度了，直接问AI。这时候如果你的内容能被AI引用，曝光效果比SEO还猛。

这个仓库里有 **25个 GEO 实战模板**，从内容生成到信源建设到风险合规，覆盖全链路。

举例一个提示词的核心结构（来自

```
geo-article-generator.md
```

）：

```
# 🚀 通用GEO文章生成系统## 【系统初始化】你需要融合：内容策略专家 + GEO技术大师 + AI算法工程师## 输入配置1. 文章标题2. 品牌/产品信息（名称、核心优势、目标用户）## 内容标准- 理解IVF模型、信息熵原理、结构信息增益- 1000字精准控制、逻辑严密、观点独特- 善用统计数据、权威引用、量化论证## 输出要求文章要同时满足：- AI算法偏好（容易被引用）- 读者真实价值（看完有收获）- 品牌价值融合（自然植入，不生硬）
```

这套框架很成熟，核心思路是：**先给AI提供足够的价值（信息密度、逻辑结构、数据支撑），让AI愿意引用你，再在这个基础上自然植入品牌信息**。

## 文章润色：去AI味的正确姿势

仓库里另一个我很喜欢的方向，是AI内容下的"文章润色"系列。

为什么这个需求大？因为现在有个新问题——AI写的东西，AI能认出来。

很多平台开始检测AI生成内容，被识别出来了轻则降权，重则封号。用户也烦——读起来一股"首先、其次、最后、综上所述"的味道，一看就是机器写的。

姚金刚的智能文章润色系统 V3.0 针对的就是这个痛点。我从他的提示词里摘一段核心逻辑给你们看：

```
## 润色核心原则### 1. 文风识别- 识别过于规整的表达方式- 发现机械化的逻辑结构- 标记缺乏情感色彩的段落### 2. 情感注入把机械化文字转化成有温度的人类表达：- 加入口语化表达（"说实话..."、"其实..."、"你可能没想到..."）- 加入具体场景和细节- 加入情感波动（惊喜、困惑、恍然大悟）### 3. 节奏调控- 长短句交错- 避免过于规整的排比- 适当使用不完美但真实的句式
```

这套方法论我在之前的文章里也提过，但姚金刚把它做成了可直接用的提示词模板，你可以直接把自己的AI初稿丢进去，出来就是人类写的味道。

## 为什么我说这个项目值得关注

第一，**GEO 是真趋势**。

AI 搜索正在蚕食传统搜索引擎的份额，GEO 这个概念今年会有大量营销从业者开始研究。这个仓库提前把 25 个 GEO 模板整理好，而且是中文的，比市面上任何英文资源都更贴近中文互联网的实际情况。

第二，**中文提示词库这个赛道还几乎是空白**。

GitHub 上英文提示词库一大堆，但中文的、真正面向中文互联网场景的、可以直接商用的，开源的不多。姚金刚这套合集是目前最完整的之一。

第三，**工程化程度超出预期**。

大多数开源提示词库就是丢一堆 Markdown 文件完事。这个仓库有自动化脚本：质量检查

```
check_repo.py
```

、目录重建

```
generate_catalog.py
```

、网页生成

```
generate_webpage.py
```

，工程化程度相当于一个正经软件项目。

## 怎么用这个仓库

1. 1. 先看 CATALOG.md，按场景找提示词
2. 2. 打开对应的 Markdown 文件，复制 Prompt 部分
3. 3. 把

   ```
   {{变量}}
   ```

    或

   ```
   [占位符]
   ```

    替换成你自己的任务信息
4. 4. 在你用的模型（Claude/Kimu/ChatGPT）里测试，根据输出迭代版本
