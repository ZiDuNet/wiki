1、f/prompts.chat

该项目原名 Awesome ChatGPT Prompts，是一个社区驱动的提示词（prompts）共享与发现平台，支持用户上传、浏览和收藏各类 AI 对话提示词。它采用纯 HTML 构建，无需复杂后端，可免费自托管部署，确保组织内部使用的完全隐私。当前拥有 162660 颗星，覆盖 ChatGPT、Claude、Gemini 等主流模型。适合需要系统化积累高质量提示词、提升 AI 交互效率的开发者或团队，尤其适合注重数据隐私的企业场景。

评价：该项目作为社区驱动的提示词集合，创新性地实现了自托管部署以保障隐私。但本质是静态列表，缺乏动态交互与质量评估机制。

语言: HTML | ⭐ 162660

2、Shubhamsaboo/awesome-llm-apps

Shubhamsaboo/awesome-llm-apps 是一个汇集了100多个可直接运行的AI Agent与RAG应用的实用仓库，基于Python构建。项目主打“克隆、定制、部署”的极简流程，覆盖从基础聊天机器人到复杂多智能体协作系统的完整案例，每个应用都附带可复现的代码与配置。其核心价值在于降低了LLM应用的门槛，开发者无需从头搭建，即可快速验证想法或集成到现有系统。当前GitHub星标超过11万，热度极高，特别适合希望快速上手AI应用开发、学习Agent与RAG最佳实践的Python开发者，以及需要原型参考的AI产品团队。

评价：该仓库提供了大量可直接运行的AI Agent与RAG应用示例，覆盖多种场景，实用性强。但部分应用依赖外部API和特定环境配置，快速上手可能遇到依赖兼容性问题。

3、punkpeye/awesome-mcp-servers

punkpeye/awesome-mcp-servers 是一个精心整理的 MCP（Model Context Protocol）服务器资源集合，汇集了众多基于该协议构建的 AI 服务端实现。该项目主要面向开发者，提供了一系列可直接集成或参考的 MCP 服务器示例，涵盖数据处理、模型交互、工具调用等场景。其核心价值在于降低了 MCP 协议的学习与落地门槛，让开发者能快速找到适配自己需求的服务器模板，加速 AI 应用开发。目前该项目在 GitHub 上拥有 87344 颗星，热度极高，适合正在探索 MCP 协议或需要构建 AI 服务端组件的开发者参考使用。

评价：该项目收录了海量MCP服务器资源，为AI工具集成提供了便捷的索引。但作为纯列表式仓库，缺乏对服务器质量、维护状态的评估机制，可能影响实际可用性。

⭐ 87344
