## 这些工具，99%的小白根本搜不到

我扒了一周GitHub才搞明白这件事。

李继刚、花叔、苍何、袋鼠帝……这些头部博主，每个人都在自己的仓库里开源了一套专属工具。

从**一句话生成公众号全文**，到**长文一键去AI腔**，再到**整本书翻译**、**起号全自动化**，每一个都是工作流里最关键的那一环。

问题是——这些Skills既不在官方商店，也没有中文教程。你要是不混AI圈子，连它们存在都不知道。

今天这20个，全部从大佬们的真实工作流里挑出来，按5大场景分好类。

**看完直接抄作业。**

## 一、博主精选合集：大佬们的私藏工具箱

### 1. ljg-skills（李继刚）

**核心能力：** 文字简化、概念拆解、长文伴读、信息图生成

**适合人群：** 做知识付费、深度内容创作的博主

**怎么用：**

- 扔进去一篇5000字的废话文章，它能给你压缩成800字的精华，逻辑更清晰
- 把复杂概念拆解成小白也能懂的表述
- 长文伴读：帮你生成文章的导读、要点、思维导图

**实测效果：**
我用它处理过一篇讲"复利思维"的文章，原文3000字各种专业术语，压缩后800字，核心观点反而更突出了。

**安装命令：**

```
npx skills add lijigang/ljg-skills
```

**踩坑经验：**

**国内福利：** Cocoloop平台可以直接一键安装，不用折腾命令行。

**安装命令：**

```

## 二、写作与深度调研：从选题到完稿，一条龙

**核心能力：** 一键生成公众号全文，标题/摘要/封面全包

**适合人群：** 日更博主、内容工厂

**怎么用：**

- 3个备选标题
- 150字摘要

**实测效果：**

**怎么用：**
把AI生成的内容扔进去，它会：

- 删掉那些"正确的废话"
- 核查引用的数据和事实

**实测效果：**
改完的文章，读者反馈说"终于不像是AI写的了"。

**具体案例：**
原文："在当今快速发展的AI时代，人工智能正在改变我们的生活方式..."

改后："上个月我用ChatGPT帮朋友写了一封辞职信，结果他老板以为是手写的，还夸他文笔好..."

**安装命令：**

```
npx skills add KKKKhazix/khazix-skills --skill khazix-writer
```

**实测效果：**

- 最常用的开头是"上周有个朋友问我"
- 读者更喜欢"有数据支撑"的内容
- 我常用的结构是"问题-方案-案例"

**这些我自己都没意识到的规律，它全给挖出来了。**

**安装命令：**

```
npx skills add xiaohuailabs/tacit-mining
