# WorkBuddy核心玩法拆解：3种模式+Skills+MCP，效率直接拉满

> wuhiufan

装好了WorkBuddy，然后呢？

很多人卡在这一步：工具有了，但不知道怎么用才能发挥最大价值。今天就来拆解WorkBuddy的**三大核心系统**——工作模式、Skills技能、MCP协议，帮你从"会用"升级到"用好"。

## 一、三种工作模式：选错模式，效果减半

WorkBuddy提供了三种模式，对应三种完全不同的工作逻辑。**选对模式，是高效使用WorkBuddy的第一步。**

### Craft模式：别废话，直接干

**适合场景**：你明确知道要做什么，不需要讨论。

**典型指令**：

```
把桌面上的"Q1销售数据.xlsx"按部门汇总，生成柱状图和分析报告，保存到文档目录
```

WorkBuddy收到指令后，直接执行：
1. 读取Excel文件
2. 按部门汇总数据
3. 生成柱状图
4. 撰写分析报告
5. 保存到指定位置

**一句话总结**：目标明确 → 直接交付

### Plan模式：先看方案，再动手

**适合场景**：任务复杂，你想先确认AI的执行计划。

**典型指令**：

```
帮我搭建一个项目管理看板，需要包含任务分配、进度跟踪、自动提醒功能
```

WorkBuddy会先输出一个执行计划：

```
📋 执行计划：1. 在文档目录创建项目看板文件夹2. 生成任务分配表（Excel）3. 创建进度跟踪模板4. 设置每日自动提醒（绑定企微）5. 配置定时任务检查进度确认执行？
```

你确认后，它才开始干活。

**一句话总结**：复杂任务 → 先规划 → 再执行

### Ask模式：只问不动

**适合场景**：只想查资料、问问题，不需要AI操作文件。

**典型指令**：

```
Python中列表和元组的区别是什么？各自适合什么场景？
```

WorkBuddy只回答问题，不会动你电脑上的任何文件。

**为什么要单独设一个模式？** 两个原因：
1. **省积分**——不执行文件操作，消耗更少
2. **更安全**——不会误操作文件

**一句话总结**：只问答 → 零风险 → 最省钱

### 模式选择速查表

| 你的需求 | 选哪个模式 | 为什么 |
| --- | --- | --- |
| 帮我做个PPT | Craft | 目标明确，直接执行 |
| 重构这个项目 | Plan | 复杂任务，先看方案 |
| 这个报错什么意思 | Ask | 只需回答，不动文件 |
| 整理这份数据 | Craft | 操作清晰，直接干 |
| 搭建自动化流程 | Plan | 涉及多步骤，需确认 |
| 解释这段代码 | Ask | 纯问答，省积分 |

## 二、Skills技能系统：给AI装"专业技能"

如果说WorkBuddy是一个通用AI助手，那么**Skills就是它的专业技能证书**。装什么技能，它就拥有什么能力。

### 技能市场：SkillHub

在对话区输入

```
/skills
```

 即可进入SkillHub技能市场。

**必装技能TOP5**：

| 技能 | 功能 | 适用人群 | 消耗积分 |
| --- | --- | --- | --- |
| xlsx | Excel读写、图表、分析 | 数据处理 | 低 |
| docx | Word创建、编辑、格式化 | 文案写作 | 低 |
| pptx | PPT生成、排版、美化 | 汇报演示 | 中 |
| pdf | PDF读取、合并、拆分 | 文档处理 | 低 |
| Browser Automation | 网页自动化操作 | 数据采集 | 高 |

**进阶技能推荐**：

| 技能 | 功能 | 亮点 |
| --- | --- | --- |
| code-review-expert | 代码审查 | 自动评分+问题清单+修复补丁 |
| unit-test-generator | 单元测试生成 | 覆盖边界情况 |
| data-visualizer | 数据可视化 | 自动选择图表类型 |
| email-sender | 邮件批量发送 | 支持模板和变量 |
| schedule-manager | 日程管理 | 自动创建提醒 |

### 安装技能的3种方式

**方式1：SkillHub一键安装（最快）**

```
/skills install xlsx
```

**方式2：拖拽SKILL.md文件**
将别人分享的SKILL.md文件直接拖到聊天框，自动导入。

**方式3：手动放入目录**

```
# 将SKILL.md放到指定目录，重启生效~/.workbuddy/skills/
```

### 技能调用方式

安装完成后，在指令中指定使用哪个技能：

```
使用 xlsx 技能，分析桌面"销售数据.xlsx"中的趋势，生成折线图
```

也可以不指定，WorkBuddy会根据任务自动选择合适的技能。

## 三、MCP协议：让AI"长出手脚"

**MCP（Model Context Protocol）** 是WorkBuddy的底层核心协议，它让大模型能够安全地与你的本地环境交互。

没有MCP，AI只能"说话"；有了MCP，AI能"做事"。

### MCP的三大关键能力

**1. 意图解析与任务拆解**

输入："分析桌面上的会议纪要并提取行动项"

系统自动拆分为：

```
文件读取 → 文本提取 → 逻辑总结 → 生成报告
```

**2. 多Agent并行**

复杂任务分配给多个AI实例同时处理：
- Agent A：抓取网页数据
- Agent B：清洗Excel
- Agent C：生成图表

三个Agent并行工作，效率翻倍。

**3. 模型不可知**

内置混元，同时支持DeepSeek、GLM、Kimi等国产模型。按任务动态切换，不绑定单一模型。

### MCP连接器：让AI调用外部工具

WorkBuddy提供了MCP服务集成面板，可以统一管理所有外部工具连接：

| 连接器 | 功能 | 配置难度 |
| --- | --- | --- |
| 文件系统 | 读写本地文件 | ⭐ |
| Shell命令 | 执行终端命令 | ⭐⭐ |
| 浏览器 | 网页自动化 | ⭐⭐ |
| 数据库 | 读写数据库 | ⭐⭐⭐ |
| Git | 代码版本管理 | ⭐⭐ |

新增的连接器优化：
- OAuth授权流程优化
- Token主动刷新机制
- 连接自动重连
- 异常后快速恢复

## 四、需求描述：说清楚才能做对

很多人觉得AI不好用，根本原因是**需求描述不清楚**。

WorkBuddy推荐"三要素法"：

| 要素 | 说明 | 示例 |
| --- | --- | --- |
| **做什么** | 动词+目标 | 整理/分析/生成/转换 |
| **给什么** | 输入材料 | 上传文件/提供数据 |
| **要什么** | 输出格式 | Word/Excel/PPT，多长，什么风格 |

**对比示例**：

| ❌ 模糊需求 | ✅ 清晰需求 |
| --- | --- |
| 帮我写个总结 | 基于附件中的3份会议纪要，整理一份党建工作总结，2000字左右，分三个部分 |
| 帮我分析数据 | 读取附件Excel中的报名数据，按部门统计人数，做成柱状图 |
| 帮我做个PPT | 把这份工作汇报转成PPT，不超过10页，风格简洁 |

**核心原则**：你描述得越具体，AI输出的结果就越精准。

## 五、实战演练：3个典型场景

### 场景1：Excel数据分析（Craft模式）

```
读取桌面"2026Q1销售数据.xlsx"，按部门汇总销售额，计算环比增长率，生成柱状图+分析报告，保存到文档目录
```

执行过程：读取文件 → 数据汇总 → 计算环比 → 生成图表 → 撰写报告 → 保存

耗时：约2分钟（手动操作至少需要30分钟）

### 场景2：项目规划（Plan模式）

```
帮我规划一个新产品发布会的筹备方案，包含场地、嘉宾、流程、预算4个模块
```

AI先输出方案框架 → 你确认/修改 → AI生成详细文档

### 场景3：代码审查（Ask模式）

```
这段Python代码有什么性能问题？如何优化？[粘贴代码]
```

AI分析代码 → 输出问题清单 → 给出优化建议
