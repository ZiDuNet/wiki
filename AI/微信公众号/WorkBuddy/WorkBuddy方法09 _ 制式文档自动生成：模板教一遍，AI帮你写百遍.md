上周，一位做企业培训的朋友找我吐槽。

"每次给客户写培训方案，都要调格式调到半夜。标题用几号字、表格怎么对齐、页眉页脚怎么设...明明内容差不多，每次都要重新排版。"

我说："你让WorkBuddy学一遍你的模板，以后直接填内容就行。"

她试了一下，把以前写好的一个方案发给WorkBuddy，说"按这个格式，给我写一个新的"。

5分钟后，新方案出来了——格式一模一样，内容完全不同。

## 01 什么是"制式文档"

所谓制式文档，就是**有固定格式、重复出现、内容可变但结构不变**的文档。

**职场中的制式文档无处不在：**

| 场景 | 典型文档 |
| --- | --- |
| 项目管理 | 项目计划书、周报、会议纪要、需求文档 |
| 商务往来 | 合同模板、报价单、提案书、协议草案 |
| 人力资源 | 岗位说明书、面试评估表、培训教案、考核表 |
| 财务会计 | 报销单、预算表、财务分析报告、审计清单 |
| 教育培训 | 课程大纲、教学PPT脚本、学员手册、考试试卷 |
| 行政办公 | 通知模板、邀请函、活动方案、SOP操作手册 |
| 技术研发 | API文档、测试报告、部署指南、产品说明书 |

**共同特点：**

▸格式固定（标题层级、段落间距、表格样式）

▸结构重复（同样的章节顺序、同样的内容模块）

▸频繁产出（每周、每月、每个项目都要写）

▸耗时费力（调格式的时间比写内容还长）

## 02 核心方法：模板学习法

传统的AI写作，是直接让AI"帮我写一篇XX"。

**问题是：** AI不知道你公司的格式要求、不知道你喜欢的排版风格、不知道具体的章节结构。

**模板学习法的思路：**

|  |
| --- |
| CODE |
| 第一步：给AI一个范本 → 让AI学习格式和结构 第二步：告诉AI新内容 → AI按学到的格式生成新文档 |

**就像教实习生：**

▸先给他一份写好的文档："这是我们公司的标准格式，你看一下"

▸再给他新的素材："按这个格式，用这些素材写一篇新的"

## 03 基础Prompt（直接复制使用）

这是我最常用的基础版本：

|  |
| --- |
| CODE |
| 我会先给你一份【文档类型】的模板，请你学习它的格式和结构。  【模板内容】 [粘贴你的模板文档全文]  请学习以上模板的： 1. 整体结构（章节顺序、层级关系） 2. 格式规范（标题样式、段落间距、表格格式） 3. 语言风格（正式程度、用词习惯、句式特点） 4. 固定模块（哪些部分是每篇都有的）  理解后请回复"已学习"，我会给你新的内容素材。 |

**等AI回复"已学习"后，发送：**

|  |
| --- |
| CODE |
| 请按照刚才学习的模板格式，用以下内容生成新的【文档类型】：  【新内容素材】 [粘贴你的新内容要点]  要求： - 严格遵循模板格式 - 保持章节结构一致 - 语言风格与模板匹配 - 生成完整可直接使用的文档 |

## 06 完整操作步骤

**Step 1：准备模板文档**

找一个你写过的、格式最规范的同类文档作为模板。

**要求：**

▸格式完整（不要省略任何章节）

▸排版清晰（标题层级明确）

▸有代表性（能覆盖这类文档的典型结构）

**Step 2：发送学习Prompt**

使用上面的基础Prompt，让AI学习模板。

**Step 3：确认AI理解**

可以问一句："请简述这个模板的结构特点"，确认AI理解正确。

**Step 4：提供新内容生成**

发送新内容素材，让AI按模板生成。

**Step 5：人工微调**

AI生成的文档是初稿，需要人工检查：

▸事实准确性

▸数据正确性

▸专业术语使用

▸公司特定的格式要求

## 07 避坑指南：这4个错误千万别犯

**❌ 错误1：模板本身格式混乱**

如果模板排版就很乱，AI学出来的也是乱的。

**✅ 正确做法**：先整理好一个格式规范的模板，再让AI学习。

**❌ 错误2：一次给太多模板**

第一次就让AI学十几个模板，容易混淆。

**✅ 正确做法**：先从一个最常用的模板开始，熟练后再增加。

**❌ 错误3：不提供具体内容**

只说"帮我写一篇周报"，AI不知道这周发生了什么。

**✅ 正确做法**：提供具体的内容要点，AI负责按格式组织。

**❌ 错误4：完全不检查直接使用**

AI可能会"脑补"一些内容填充格式。

**✅ 正确做法**：务必人工检查，特别是数据、人名、日期等关键信息。

用了这个方法，我说几点心得：

**第一，格式调优的时间省了90%。**

以前写个方案，调格式要半小时。现在AI直接生成，格式就是对的。

**第二，团队文档风格统一了。**

大家都用同一个模板，生成的文档格式一致，专业感更强。

**第三，新手也能写出标准文档。**

刚入职的同事，不需要背格式规范，直接让AI按模板生成就行。

## 10 总结一下

**核心逻辑：**

▸先给模板 → 让AI学习格式

▸再给内容 → 让AI按格式生成

▸人工检查 → 确保内容准确

**3个关键：**

1模板要规范（格式清晰、结构完整）

2内容要具体（给AI明确的素材）

3生成后要检查（核实数据和专业性）

**适用边界：**

▸✅ 格式固定的重复性文档

▸✅ 结构相似的内容变体

▸❌ 需要深度创意的内容（如品牌文案）

▸❌ 高度个性化、非标准化的文档
