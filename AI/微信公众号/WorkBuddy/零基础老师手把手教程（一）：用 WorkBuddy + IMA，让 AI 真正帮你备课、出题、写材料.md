## 📖 第一章：先搞清楚这两个工具是什么

### 🤖 WorkBuddy 是什么？

简单说：**WorkBuddy 是一个装在你电脑上的AI助手**，不只是聊天，它能*直接帮你干活*——写文档、改Excel、生成PPT、运行代码……

| 你以为的AI（只能聊天） | WorkBuddy（真正干活） |
| --- | --- |
| 给你一段文字，你自己去复制 | 直接帮你生成Word文件并保存 |
| 记不住你上次说的话 | 可以接入你的个人知识库，"记住"你的资料 |
| 只能在网页里用 | 装在电脑桌面，随时打开 |
| 只能生成文字 | 能生成Word / Excel / PPT / 图片 / 代码 |

### 📚 IMA 知识库是什么？

**IMA（腾讯）是你的"个人资料库"**——把你收藏的微信文章、PDF教材、Word备课笔记都存进去，然后让AI来读取和使用这些内容。

打个比方：

 💡 **就像这样理解：**
 IMA知识库 = 你自己的"私人图书馆"
 WorkBuddy = 一个能读懂整个图书馆并帮你查资料、写文章的AI助手

 两者结合：AI基于你积累的教学资料，给出更精准、更符合你需求的回答。

## 🛠️ 第二章：安装 WorkBuddy（约5分钟）

我们从最基础的安装开始，一步一步来。

###

### 第1步：找到 WorkBuddy 小程序

1. 打开手机微信

     点击右上角的 **「+」** → 点击 **「小程序」** → 在搜索框输入 **「WorkBuddy」**

2. 在小程序里下载电脑端

     进入WorkBuddy小程序后，找到 **「下载电脑版」** 按钮，选择你的电脑系统（Windows或Mac），按提示下载安装包。   

3. 安装并打开

     双击下载好的安装包，按提示完成安装。安装完成后，桌面会出现 WorkBuddy 图标，双击打开。
