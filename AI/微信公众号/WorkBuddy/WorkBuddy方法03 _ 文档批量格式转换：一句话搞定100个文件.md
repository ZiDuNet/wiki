## 场景痛点：你经历过吗？

月底归档，收到100个Word文档需要统一转成PDF。

你打开第一个文件，点击"另存为"，选择PDF格式，保存。重复100次。

或者更惨：收到50份PDF合同，需要合并成一份总文件，再按日期重命名。

还有就是整理历史文档、建立知识库都需要进行文档处理。

**这种重复劳动，不该由人来完成。**

## WorkBuddy解决方案

**一句话指令实现批量文件格式转换、合并、拆分、重命名。**

WorkBuddy直接操作本地文件系统，批量处理，告别重复劳动。

把上面的Prompt复制到WorkBuddy对话框，替换文件夹路径和规则。

第三步：检查结果

WorkBuddy会输出处理结果摘要：

▸成功处理文件数

▸失败文件列表（如有）

## 避坑指南

坑1：文件被占用导致转换失败

**解决方案**：

▸确保所有文件已关闭

▸分批处理，每次不超过50个文件

坑2：文件名含特殊字符

**解决方案**：在指令中要求"自动清理文件名中的特殊字符"

|  |
| --- |
| CODE |
| 把"文档"文件夹中所有文件重命名， 自动清理文件名中的特殊字符（/\:\*?"<>|）， 替换为下划线 |

坑3：输出覆盖原文件

**解决方案**：明确要求"输出到新文件夹，保留原文件不变"
