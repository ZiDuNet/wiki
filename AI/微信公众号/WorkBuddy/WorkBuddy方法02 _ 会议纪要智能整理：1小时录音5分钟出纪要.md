## 场景痛点：你中招了吗？

周一例会开了1小时，老板让你整理会议纪要。

你打开录音，边听边暂停边打字——"刚才那句是什么来着？""这个决策是谁说的？""待办事项 deadline 是哪天？"

2小时过去了，纪要还没写完。

更糟糕的是：要点遗漏、决策记错、待办事项混乱，不同会议格式不统一，领导不满意，你还得返工。

**这不是你的问题，是方法的问题。**

## WorkBuddy解决方案

**语音转文字 + 智能提炼 + 结构化输出**

WorkBuddy自动识别核心决策、待办事项、争议点，5分钟输出专业会议纪要。

会议纪要的撰写有两部分，语音转录、文字整理，第一步骤豆包、千问、手机都能完成，困难的是第二部分。

## 核心Prompt模板

|  |
| --- |
| CODE |
| 请将「[文件路径]/[会议录音文件名].mp3」转录并整理成会议纪要：  【格式要求】 1. 会议基本信息（时间、地点、参会人、会议主题） 2. 核心决策（用🔴标注，不超过5条） 3. 待办事项（用✅标注，含负责人和Deadline） 4. 争议点（用⚠️标注，需后续跟进） 5. 下一步计划  【输出要求】 - Word格式，可直接归档 - 待办事项按优先级排序 - 争议点需标注相关方意见 |

## 操作步骤

第一步：准备录音文件

将会议录音保存到本地，确保文件格式为MP3/WAV/M4A。

**小技巧**：

•录音时让参会人轮流报姓名，便于AI区分发言人

•重要会议开始前，在Prompt中补充参会人名单

第二步：执行转录指令

把上面的Prompt复制到WorkBuddy对话框，替换 

```
[文件路径]
```

 和 

```
[会议录音文件名]
```

 为实际路径。

**示例**：

|  |
| --- |
| CODE |
| 请将「/Users/wayen/Documents/会议录音/2026-05-04\_周例会.mp3」转录并整理成会议纪要... |

第三步：人工复核关键点

AI转录完成后，重点检查：

•🔴 核心决策是否准确

•✅ 待办事项的负责人和 deadline 是否正确

•⚠️ 争议点是否记录了各方意见

第四步：保存模板

将优化后的Prompt保存为Skill，下次直接说"执行会议纪要整理"。
