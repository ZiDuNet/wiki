## 01 先说痛点：文档翻译到底烦在哪

你可能也遇到过：

•**术语不统一**：同一个词前后翻译不一样，比如"埋点"一会儿是"buried point"，一会儿是"tracking point"

•**格式丢失**：翻译后表格乱了、标题层级变了、页码对不上

•**专业术语难**：行业黑话不知道怎么翻，直译出来老外看不懂

•**时间成本高**：一份20页的文档，专业翻译要2-3天

**核心问题不是"不会英语"，而是"专业文档翻译要求太高"。**

## 02 解决方案：让AI当你的翻译助手

WorkBuddy的做法：

**你指定文档和术语表，它批量翻译，保持格式，统一术语。**

不需要你逐句翻译、不需要担心格式错乱、不需要查专业词典。

相比专业翻译2-3天的时间成本，这简直就是白送。

## 04 进阶用法：批量翻译并建立术语库

如果你需要翻译多份文档，并建立统一的术语库：

|  |
| --- |
| CODE |
| 请批量翻译"[文件夹路径]"中的所有文档为[目标语言]：  【术语库】 - 埋点 → Event Tracking - 日活 → DAU (Daily Active Users) - 留存率 → Retention Rate - 转化率 → Conversion Rate - 用户画像 → User Persona  【要求】 1. 保持原有格式和排版 2. 统一使用术语库中的翻译 3. 遇到新术语标注出来，建议翻译 4. 生成术语库更新文件 5. 输出为新文件夹，保留原文件 |

**适用场景：**

•产品说明书多语言版本

•合同协议翻译

•技术文档国际化

•市场推广材料本地化

## 05 完整操作步骤

**Step 1：准备术语对照表**

整理你行业的专业术语对照表：

•中文术语 → 英文翻译

•尽量使用行业通用译法

•不确定的术语标注出来

**Step 2：复制Prompt到WorkBuddy**

把上面的Prompt模板复制到对话框，填入文件路径和术语表。

**Step 3：发送并等待生成**

通常3-5分钟完成翻译（取决于文档长度）。

**Step 4：人工复核关键内容**

**重要：AI翻译后务必检查：**

•专业术语是否准确

•数字、日期、金额是否正确

•格式是否保持原样

•商务语气是否合适

**Step 5：建立术语库**

把确认的术语对照表保存下来，下次翻译直接使用。

## 06 避坑指南：这3个错误千万别犯

**❌ 错误1：不提供术语表**

如果不提供术语对照表，AI可能用不同的词翻译同一个术语。

**✅ 正确做法**：提前准备术语对照表，确保全文统一。

**❌ 错误2：完全信任翻译结果**

AI翻译虽然准确率高，但专业术语和商务表达仍需人工确认。

**✅ 正确做法**：关键段落（合同条款、技术参数）务必人工复核。

**❌ 错误3：忽视文化差异**

直接翻译可能不符合目标语言国家的商务习惯。

**✅ 正确做法**：翻译后请母语者或当地同事审阅。
