## 🤔 什么是工作流？

**工作流 = 多个任务按一定顺序串联起来，自动执行。**

### 例子 1：每日数据汇报工作流

**手动流程（每天要花 30 分钟）：**

1. 从系统导出昨日数据（5 分钟）

2. 整理成 Excel 格式（10 分钟）

3. 写邮件（5 分钟）

4. 发送邮件（1 分钟）

5. 存档（5 分钟）

**自动化后（每天 10 秒）：**

1. 9:00 自动执行

2. 导出数据 → 整理 → 发邮件 → 存档（全自动）

### 例子 2：用户注册工作流

**流程：**

1. 用户填写注册信息

2. 发送验证邮件

3. 用户点击验证链接

4. 账号激活

5. 发送欢迎邮件

6. 加入用户列表

想搭建一个工作流，但不知道怎么设计。

```
请帮我设计一个工作流：  需求： 每天自动生成销售日报，并发送给销售总监。  具体流程： 1. 每天 9:00，从数据库导出昨日销售数据 2. 整理成 Excel 格式（按地区、按产品分类统计） 3. 生成可视化图表（销售额趋势图、地区对比图） 4. 写一份简要分析（200 字） 5. 把 Excel 和图表插入邮件，发送给销售总监 6. 存档（保存到指定文件夹）  请帮我： 1. 设计工作流（用流程图或步骤列表） 2. 写出每个步骤的实现方法 3. 给出完整的自动化脚本
```

## 场景 2：实现数据处理工作流

### 痛点

有多个数据处理任务，想串联起来自动执行。

### 解决方案

**提示词模板：**

```
请帮我实现一个数据处理工作流：  流程： 1. 从 API 获取原始数据（JSON 格式） 2. 数据清洗（去掉空值、格式化日期、类型转换） 3. 数据转换（计算衍生字段，比如同比增长率） 4. 数据加载到数据库 5. 生成 Excel 报表 6. 发送邮件通知  要求： - 使用 Python 实现 - 每个步骤写成一个函数 - 用主函数串联所有步骤 - 代码有详细注释 - 异常处理（某一步失败要记录日志，并发送失败通知）
```

## 场景 3：实现文件处理工作流

### 痛点

每天收到很多文件，要分类、重命名、存档。

### 解决方案

**提示词模板：**

```
请帮我实现一个文件处理工作流：  需求： 每天收到不同类型文件（PDF 报告、Excel 数据、图片），要自动处理：  流程： 1. 监控指定文件夹（有新文件就触发） 2. 按文件类型分类（PDF → PDF文件夹，Excel → Excel文件夹） 3. 按日期重命名（20240101_报告.pdf） 4. 如果是 Excel，自动提取数据并合并到总表 5. 处理完成后，发送通知邮件  要求： - 使用 Python 实现 - 使用 watchdog 库监控文件夹 - 代码有详细注释
```

## 场景 4：实现用户运营工作流

### 痛点

用户运营有很多重复工作，想自动化。

### 解决方案

**提示词模板：**

```
请帮我设计一个用户运营工作流：  需求： 提升用户留存率，自动化运营流程。  流程： 1. 每天找出 7 天没登录的用户（流失预警） 2. 自动发送 push 通知（带个性化内容） 3. 如果用户还是没登录，3 天后再发一次 4. 如果用户登录了，停止推送 5. 记录每个用户的推送历史  要求： - 使用 Python 实现 - 使用数据库记录用户状态和推送历史 - 代码有详细注释
```

## 工作流设计的核心原则

### 1. 明确输入和输出

> 每个步骤都要明确：输入是什么？输出是什么？

### 2. 异常处理

> 每个步骤都要考虑：如果失败了怎么办？

### 3. 可监控

> 工作流运行过程中，要能查看进度和日志。

### 4. 可回滚

> 如果某一步失败了，要能回滚到上一步的状态。
