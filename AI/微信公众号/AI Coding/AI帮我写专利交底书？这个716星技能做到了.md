## 写在前面

如果你做过专利申请，一定知道**技术交底书**有多磨人。

要把代码、设计文档、PPT里的技术点梳理成专利代理人能看懂的正式文档，还要画系统框图、流程图，最后还得脱敏处理……光是想想就头大。

更别提定稿之后还要多轮补材料、纠错，文件版本乱成一锅粥。

最近 GitHub 上有一个叫 **patent-disclosure-skill** 的开源项目火了——**716 Star，92 Fork**，它用 AI 把上面这一整套流程全自动搞定了。

今天就来聊聊，这个技能到底能帮你省多少事。

---

## 它是谁？

**patent-disclosure-skill**（中文名：中国专利.skill）

> 从项目文档到**可交付的技术交底书**：专利点挖掘、**查新优先国知局公布公告站**、脱敏成文与自检闭环。

项目地址：https://github.com/handsomestWei/patent-disclosure-skill

这个项目遵循 **AgentSkills** 规范，可以无缝接入 Claude Code、Cursor 等主流 AI 编码助手。

也就是说——你直接在 AI 对话框里说人话，它就能帮你把交底书搞出来。

---

## 七大核心能力，覆盖交底书全生命周期

### 🔍 1. 项目智能扫描

直接把你的项目目录丢给它，它能：

- 按优先级自动读取文档和代码
- 自动把 

  ```
  .docx
  ```

   / 

  ```
  .pptx
  ```

   转成 Markdown 再扫描
- 不漏掉任何可能有专利价值的技术细节

### 💡 2. 专利点挖掘

从项目材料里自动识别**潜在的专利申请点**，还能和你一起讨论、合并候选专利点，输出清晰的专利点分析结果。

不再靠拍脑袋想专利点。

### 🌐 3. 国知局优先查新（这个很关键）

查新是写交底书最繁琐的一步。这个技能的优先级设计很聪明：

1. 1. **优先**爬取中国国家知识产权局（CNIPA）专利公布公告站，精准获取对比专利文献
2. 2. 如果国知局站异常或无结果，自动降级到普通网络搜索（Google Scholar/Patents 等）
3. 3. 检索结果自动写入交底书第一章

专属爬虫工具 

```
cnipa_epub_search.py
```

，次次爬得到，不用担心查新这一步卡住。

### 📄 4. 标准化交底书生成

- 使用**脱敏模板**，避免信息泄露风险
- 自动生成 **mermaid 格式**系统架构图和流程图，渲染成 PNG 插入文档
- 默认输出 **.docx 格式**，专利代理人可以直接编辑修改

交付物是真正"可交付"的文档，不是半成品。

### 📦 5. 标准化交付命名

所有交付文件统一命名规则：

```
{案例名称}_{YYYYMMDDHHmmss}.md
```

 + 同名 

```
.docx
```

版本管理清清楚楚，不会再搞混哪个是最新版本。

### ✅ 6. 自动自检

交底书定稿前自动检查：

- 逻辑闭环是否完整
- 公式和参数是否一致
- 其他常见疏漏

检查结果不会误写入正文，放心。

### 🔄 7. 多轮迭代支持

补充材料或纠错时，不需要重新开始：

- 自动合并/修正已有交底书文件
- 生成独立的新版本文件
- 自动维护 

  ```
  交底书修订对话记录.md
  ```

  ，所有修改痕迹可追溯

## 技术架构：规范、兼容、模块化

这个项目遵循 **AgentSkills** 标准，整体架构非常清晰：

```
patent-disclosure-skill/├── SKILL.md              # 入口：触发条件、工具表、步骤与提示词映射├── prompts/              # 分步模板（Agent 按步骤读取执行）├── tools/                # 图示渲染、格式转换、国知局查新等工具集├── examples/             # 示例原材料与交付物├── outputs/              # 用户交付目录（已加入 .gitignore）└── requirements.txt      # Python 依赖
```

**依赖管理也很讲究**：

| 依赖类型 | 文件 | 说明 |
| --- | --- | --- |
| 基础依赖 | ``` requirements.txt ``` | Office 转换、交底书生成相关包 |
| 查新依赖（可选） | ``` tools/requirements-cnipa.txt ``` | 国知局爬虫，需 Playwright |

查新依赖是可选的——没装的话，技能会自动降级到网络搜索，不影响其他核心功能使用。

## 怎么用？

用自然语言在 AI 对话框里描述需求就行，比如：

- "帮我挖掘这个项目的专利点"
- "生成技术交底书"
- "查新对比专利"
- "/patent-disclosure-skill /交底书"（斜杠命令，取决于宿主配置）

**建议同时指定项目路径或技术主题**，这样 AI 能更精准地识别需求。
