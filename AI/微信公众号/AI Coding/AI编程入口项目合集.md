# AI 编程入口项目合集

> 来源：GitHub Trending 2026-05-04~10 周报提取
> 更新：2026-05-12

## DeepSeek-TUI
- GitHub: https://github.com/Hmbown/DeepSeek-TUI
- Stars: 19464（周内新增）
- 定位：终端原生 AI 编程 Agent（DeepSeek 模型 + Rust）
- 核心价值：AI 编程入口不一定只在 IDE，终端仍然是开发者最稳定的工作界面

## 9Router
- GitHub: https://github.com/decolua/9router
- Stars: 3063（周内新增）
- 定位：多模型路由，连接 Claude Code/Codex/Cursor/Cline/Copilot
- 核心价值：解决开发者被模型额度、价格、供应商限制卡住的问题
- ⚠️ 注意：模型来源、数据流向、隐私边界需确认，适合折腾不适合敏感代码库

## jcode
- GitHub: https://github.com/1jehuang/jcode
- 定位：Coding Agent Harness / 执行框架
- 核心价值：Agent 执行代码任务时的运行框架底座

## aaif-goose/goose
- GitHub: https://github.com/aaif-goose/goose
- 定位：可扩展 AI Agent
- 核心价值：不只做代码建议，而是安装、执行、编辑、测试——"从补全工具到执行工具"

## ChromeDevTools/chrome-devtools-mcp
- GitHub: https://github.com/ChromeDevTools/chrome-devtools-mcp
- 定位：Chrome DevTools MCP 工具
- 核心价值：把调试页面、查看DOM、网络请求、性能问题等能力接给 Agent

## 趋势判断
不是看能不能生成漂亮代码，而是看能不能进入开发者每天真实使用的环境，能不能少切换窗口，能不能把执行和反馈闭环做短。
