说实话，刚开始用 Hermes 的时候，我只知道一个/new。后来才发现聊天框里还能用这么多命令，用和不用简直就是两个工具。

今天就来聊聊这些命令如何使用。

## 先说最基础的

**```
/new
```

 或

```
/reset
```**：开新会话。
这个大家基本都知道。

**/retry** — 重发上一条消息
模型回答得不好、或者网络抖了一下没出来，直接

```
/retry
```

，不用自己粘贴复制。

**/undo** — 撤销最后一轮对话

```
/retry
```

 是重来，

```
/undo
```

 是直接把刚才那轮抹掉，假装没发生过。有时候 Agent 理解偏了，带歪了整个对话方向，用

```
/undo
```

 回退一步，比开新会话强。

**/compress** — 手动压缩上下文
Hermes 会自动压缩长对话，但有时候你想主动触发。比如聊了一个多小时，上下文已经很臃肿了，但你还不想开新会话，

```
/compress
```

 一下，它会把之前的内容精简成摘要，给后面腾空间。

## 改模型、调风格

**/model** — 切换模型
这个是我的高频命令。做简单查询用便宜的模型，写代码或做复杂推理就切到GPT。直接

```
/model
```

 不带参数会显示当前用的什么和列出哪些可以用，带参数就切换。

**/reasoning** — 调推理强度

```
/reasoning high
```

 可以让 Agent 花更多时间"思考"再回答，适合复杂问题。

```
/reasoning none
```

 就是关掉推理，适合简单快速的问答。
可选值是

```
none / minimal / low / medium / high / xhigh
```

，另外还有

```
show
```

 和

```
hide
```

 控制推理过程要不要显示出来。

**/personality** — 切换人格风格
这个比较有意思。你可以给 Agent 设定不同的人格，比如专业模式、闲聊模式之类的。适合不同场景切换语气。

## 进阶命令

### /background — 后台跑任务

这是我最喜欢的命令之一。

想象这个场景：你在跟 Agent 聊一个复杂的技术方案，突然想起另一个事情也要处理。正常情况下你得开新窗口或者新会话，但

```
/background
```

 不一样——它会在后台帮你跑，不影响当前对话。

比如：

```
/background 帮我搜一下最近一周关于 Hermes Agent的文章
```

它会在后台执行，完了把结果带回来。你继续聊你的，不用等。

### /queue — 排队等下一轮

跟

```
/background
```

 类似但有区别。

```
/queue
```

 是把任务排队，等当前这轮对话完了再执行。适合那种"我现在先聊完这个，回头你再帮我看看那个"的场景。

```
/queue 帮我整理一下刚才讨论的方案，写成文档
```

先聊完当前话题，Agent 自动接着处理排队的任务。

### /branch 或 /fork — 分支会话

这个概念来自 Git，用法很巧妙。

比如你在聊一个项目方案，聊到一半想试试另一个方向，但不想丢掉当前的讨论。

```
/branch
```

 会创建一个分支，你在分支里随便探索，觉得不对可以回来，觉得更好就继续。

我经常用的场景：代码改着改着发现可能有更好的写法，

```
/branch
```

 一下开个新分支试试，试完不满意切回来，原来的进度一点没丢。

### /rollback — 文件回滚 **[CLI]**

Hermes 可以开启文件系统检查点（启动时加

```
--checkpoints
```

 参数）。开了之后，每次 Agent 改文件都会自动存个快照。

然后

```
/rollback
```

 就是后悔药：

```
/rollback        # 回退到上一个检查点
/rollback 3      # 回退 3 步
```

Agent 帮你改了一堆代码，改完发现全错了？一个

```
/rollback
```

 搞定。比

```
git reset
```

 还快，因为它追踪的是 Agent 每一次的文件操作。

> ⚠️ 注意：文件检查点回滚仅在 CLI 端可用，聊天平台上没有文件系统访问权限。

### /resume — 恢复历史会话

这个是跨会话的利器。

你昨天跟 Agent 聊了一个项目方案，今天想继续。不用重新从头描述，直接：

```
/resume my-project
```

它会找到那个命名过的会话，把上下文全部恢复。前提是你之前用

```
/title
```

 给会话命了名。

所以我现在的习惯是，每个重要项目开始聊的时候先

```
/title xxx-project
```

，以后随时

```
/resume
```

。

## 网关模式下的专属命令

如果你通过 Telegram、Discord 或飞书用 Hermes，有几个专门的命令：

**/approve** 和 **/deny** **[网关]** — 审批命令
Hermes 执行危险操作（删文件、发邮件之类的）之前会暂停等你确认。这时候你会收到一条待审批消息，在聊天框里回复

```
/approve
```

 或

```
/deny
```

 就行。

这个安全机制很重要。别图省事开了 yolo 模式，除非你真的很信任 Agent。

**/sethome** **[网关]** — 设为主频道
你在某个群聊或频道里跟 Agent 对话，想让它默认来这里，就

```
/sethome
```

。以后它主动找你（比如定时任务的结果）都会发到这里。

**/platforms** **[网关]** — 查看连接状态
不确定哪些平台连着？

```
/platforms
```

 一目了然。Telegram 在线、飞书在线、Discord 掉了——全部看得清清楚楚。

**/commands** **[网关]** — 浏览所有命令
在聊天平台上输入

```
/commands
```

 可以翻页浏览所有可用命令，比记命令名方便。

## 一些小而美的命令

**/btw** — 临时旁问
这个设计很聪明。你正在让 Agent 做一个大任务，突然想问个不相关的小问题。直接问会打断主线，

```
/btw
```

 就是"顺便问一下"的意思：

```
/btw Python 的 defaultdict 怎么用来着？
```

它会回答你，但不影响主任务的上下文。

**/save** **[CLI]** — 保存对话
好的对话值得保存。

```
/save
```

 会把当前对话导出成文件。我经常在跟 Agent 讨论完技术方案后

```
/save
```

，留着以后翻。

**/fast** **[网关]** — 快速模式
赶时间的时候开这个，Agent 会倾向给简短直接的回答，不做过多展开。配合便宜模型用，又快又省 token。

**/skill** — 临时加载技能
Hermes 有技能系统，一般按需自动加载。但有时候你想明确指定用某个技能，

```
/skill skill-name
```

 手动加载。比如你知道接下来要处理 PDF，提前

```
/skill nano-pdf
```

 就行。
