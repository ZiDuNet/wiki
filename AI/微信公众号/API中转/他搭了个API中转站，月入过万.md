## 一、这是什么生意

API中转站，本质是一个「翻译 + 转发」服务。

你在海外服务器上部署一个开源工具（叫One-API），把它对接到OpenRouter、OpenAI、Claude的官方接口，然后给国内用户一个「直连」的地址。用户付钱买Token，你赚差价。

官方API要用美元、要信用卡、要海外手机号；你的中转站，微信支付宝都能付，国内直连，延迟还低。

**📌 核心卖点：**国内直连 + 微信支付 + 比官方便宜20%~50% = 很多人愿意用你的服务而不是官方。

## 二、为什么现在是好时机

**第一，AI工具爆发，API需求暴增。**2026年，GPT-5.4、Claude Opus 4.6、Gemini 3.1陆续发布，开发者、创业者、普通用户都在找「能用的API」。

**第二，官方门槛高。**OpenAI不对中国大陆开放直接注册，Claude需要海外手机号，支付要用美元信用卡。这三座大山，把很多人挡在门外。

**第三，One-API开源项目成熟。**GitHub Star 20K+，一条docker命令就能部署，技术门槛已经降到「有点Linux基础就能搞」的程度。

**第四，睡后收入。**服务器跑起来之后，用户充值、调用都是自动的，你只需要偶尔维护一下，不像其他副业需要一直在线。

## 三、起步怎么做

### 第一步：买一台海外服务器（¥150/年）

年付$18.29（约¥135），洛杉矶或圣何塞机房，国内访问速度快。

操作系统选 Ubuntu 24.04 或 Debian 12，支付宝可付款。

### 第二步：安装Docker，部署One-API（30分钟）

SSH登录服务器，执行：

```
apt update && apt upgrade -y curl -fsSL https://get.docker.com | bash docker run --name one-api -d --restart always \   -p 3000:3000 \   -e TZ=Asia/Shanghai \   -v /home/oneapi/data:/data \   justsong/one-api
```

浏览器访问 `http://你的服务器IP:3000`，默认账号 `root` / 密码 `123456`，**登录后立即修改密码**。

### 第三步：接入OpenRouter，对接所有主流模型（1小时）

注册 openrouter.ai（支持支付宝充值），创建API Key（格式以 `sk-or-` 开头）。

在One-API后台 → 渠道 → 添加渠道：

- 类型：OpenAI兼容
- 代理地址：`https://openrouter.ai/api/v1`
- 粘贴API Key → 点击「测试」→ 显示Success即成功

完成后，你的中转站就支持GPT-4o、Claude 3.7、Gemini、DeepSeek等所有主流模型了。

### 第四步：定价并开放注册（关键一步）

在One-API后台设置「充值链接」，可以接微信/支付宝收款（需要配置支付插件，或手动转账后人工充值）。

定价策略参考：

- 体验版：¥29/月，1000万Token
- 标准版：¥99/月，5000万Token
- 专业版：¥299/月，2亿Token

**比官方便宜30%左右，用户才愿意用你的。**

## 六、三个坑

**坑一：合规风险**
遵守《生成式人工智能服务管理办法》，不要碰灰色地带（禁止用逆向破解API或黑卡购买额度）。建议只做「中转」，不存储用户对话内容，降低合规风险。

**坑二：打价格战，必死**
阿里云、火山引擎等大厂有规模优势，采购成本比你低。拼价格，你必输。正确的做法是：做垂直领域（比如专服务开发者社群）、做好技术支持（用户遇到问题你能快速响应）。

**坑三：服务器被封/不稳定**
海外服务器有时候会被墙，需要备用节点。建议：主节点用美国机房，备用节点用新加坡或日本，One-API支持多渠道负载均衡，一个挂了自动切换。
