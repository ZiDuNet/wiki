本教程旨在极空间私有云通过 Docker 构建这一项目，用于消耗免费、溢出的 tokens。

# **一、InkOS 体验**

InkOS 有一套依托番茄排行榜的市场选题雷达工具，它可以筛选出当前排行榜内的热门题材、组合。

而且项目后期会开发导出番茄小说样式的相关功能，如果想尝试利用 AI 写小说发布的，可以长期关注这个项目。

![](assets/img_124be59bb15b.png)

正式体验之前，需要在模型配置里增加各个模型厂家的配置。其支持海内外主流的 API 模型厂家，支持聚合 API 平台、本地 LLMs，以及 Coding Plan 等等。

系统支持模型路由，即不同的模型可以在不同的小说生成环境里使用，比如架构、书写用高级模型，埋线、剧情梳理用低价模型等等。

![](assets/img_c937526c6518.png)

整个项目创作，一共包含三个重要内容，即文风、题材、续写/改写。

****题材****指的是系统内置的主题内容，这里规划该类题材的章节定义、疲劳词、节奏、规则，所有同一类型的小说都要遵循这一套主题规范。

![](assets/img_6e8961beda00.png)

****文风****指的是具体文字内容的风格，可以导入成熟的文字、作品，然后将其提炼为文风规则，然后导入到我们的书本内使用。

![](assets/img_b4062732eed3.png)

****续写/改写****，指的是将现有的文字内容导入系统，进行继续协作的方式。包括章节续写、母本续写、同人创作。

用得比较多的，应该就是同人创作。目前支持 Canon、AU、OOC、CP 四个类型，具体释义如下：

****Conon****：****原作/官方设定****。
****AU****： Another Universe，****平行宇宙/架空设定****。
****OOC****：Out of Character，****角色崩坏/脱离角色原有性格****。
****CP****：Coupling，****角色配对/情侣组合****。

![](assets/img_559362449136.png)

我这里以同人 OOC 为例，创建了一个《重生之为什么我的火影那么奇怪》小说，构建之后可以在日志里看到具体的进度。

![](assets/img_e26372db3291.png)

生成完成后，系统会构建一整套的规则，包含叙事规则、世界观、人物卡、剧情卡等等，这些规则是整本小说的底层架构，也是 AI 书写遵循的主要原则。

这些内容，建议在正式开始前可以随意修改，但是不建议中途修改。

![](assets/img_27480bb03baf.png)

![](assets/img_7377cafbfa5d.png)

状态卡即整本小说目前的状态，可以理解为项目目标。主要的作用就是帮助创作者随时了解进度。

![](assets/img_c48842a6bfd0.png)

伏笔池会随着剧情的发展不断更新，它很重要。不过个人觉得 InkOS 里的伏笔池有点过于复杂。

![](assets/img_29bd180ec5d3.png)

支线剧情、感情线等等，可以帮助我们梳理小分支剧情，人物情感，这些都可以随时调整。

![](assets/img_3dae08589816.png)

![](assets/img_f52265dc0989.png)

开始创作，就是围绕着和 Agent 的对话来开展的，比如我让 Agent 先补充完整的人物卡片，给出 OOC 之后的人物设定等等。

![](assets/img_5a27f35db50d.png)

一章剧情，大概在 3000 字左右。整一套工作流会包含从书写到审查到修订的过程。完成之后，在右侧的状态栏里会更新角色、章节信息，点击章节就可以看到详细内容，点击角色可以看到当前剧情下的人物发展状态。

![](assets/img_1d070df56fb7.png)

![](assets/img_aa2698efad2d.png)

虽然系统本身有去 AI 味、审查等诸多环节，但是千人千面，每个人对文字质量的要求也不相同。

前几章里，初次创作的结果一般并不会令人满意。建议通过对话进行反复沟通，修订直至自己满意。

![](assets/img_30d3c0577812.png)

几章下来，具体的风格固定了，再让 AI 固化大纲、文风、提示词，然后反复下一章创作即可。

![](assets/img_18637d954d94.png)

# **二、极空间部署 InkOS**

InkOS 项目本身不提供 docker 部署的方案，我自行构建了当前版本（v1.3.10）的容器镜像，理论上可以在容器内更新源代码二进制文件升级的。

打开极空间 Docker 应用，创建一个 Compose 项目，将下面的 

```
yaml
```

 文件全部添加进去保存即可。

![](assets/img_e61f1c54bb3c.png)

```
services:  inkos:    image: crpi-xg6dfmt5h2etc7hg.cn-hangzhou.personal.cr.aliyuncs.com/cherry4nas/cherry:inkos_v1.3.10    container_name: inkos    ports:      - "4567:4567"  # 左侧的 4567 可以自定义更改    volumes:      - ./data:/app    environment:      - TZ=Asia/Shanghai    restart: unless-stopped    stdin_open: true    tty: true
```
