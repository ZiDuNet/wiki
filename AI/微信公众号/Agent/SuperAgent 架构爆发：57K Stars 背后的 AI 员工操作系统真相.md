## 从"说"到"做"，这一步走了三年

三年前，大家聊 AI 就是聊 ChatGPT 聊天。

一年前，大家聊 AI 就是聊 Agent 能自己做计划。

今天，SuperAgent 直接把终点线画出来了。

给 AI 一台电脑。让它自己干活。

你只需要提需求，然后等结果。

听起来很美好对不对？但问题是，这条路不好走。

大多数 Agent 框架，其实还是"用 AI 聊天"的思路。你说一句，它答一句。遇到真要动手写代码跑脚本的事情，就卡壳了。

DeerFlow 不一样。它从第一天开始，就把"能干活"放在第一位。

我翻了它的源码。核心其实就是一句话。把一个完整项目，从研究到交付，拆解成 11 层中间件，每一层只干一件事。

我们一层一层看。

### 第一层，协调器。系统的大脑

协调器是啥？就是项目经理。它不干活，它管进度。

拿到一个需求，它先拆成阶段。每个阶段该谁上，什么时候交输出，出了问题找谁。都安排得明明白白。

我之前帮一个客户做多 Agent 数据分析系统。五个 Agent，每个都觉得自己最重要。抢着说话，结果互相覆盖，输出一团乱麻。

问题出在哪？没有一个真正的协调者。

**好的协作不是没有冲突，是冲突来了知道谁说了算。**

这句话我在之前写多 Agent 协作的时候就说过。DeerFlow 把这个原则落地了。

协调器就是那个指挥。它不独奏，它管整个乐队的节奏。

### 第二层，规划器。研究路线设计师

规划器干的活，就是把用户的一个模糊需求，变成清晰的执行路线图。

用户说，帮我分析一下 A 股最近的走势。不能直接扔给 Agent 去瞎跑。

规划器会拆解。第一步，需要哪些数据。第二步，用什么策略回测。第三步，结果怎么呈现。

每一步都拆得清清楚楚，后面的 Agent 照着干就行。

这就像你去登山。规划器已经给你把路线标好了，哪里该休息，哪里该转弯，你不用自己瞎探路。

### 第三层到第五层，信息处理流水线

研究团队，信息处理专家。负责把散落在互联网上的信息捡回来，清洗干净。

报告员，内容呈现专家。把处理好的信息，整合成人类能看懂的报告。

沙箱执行，Docker 隔离环境。代码可以放心跑，不会把整个系统搞崩。

这三层加起来，就是完整的**从信息收集到结果输出**的流水线。

我做量化交易回测的时候，最深的体会就是。回测只能证明策略逻辑没问题，不能证明实盘能赚钱。

**回测只是起点，实盘才是终点。**

这句话放在这里也适用。能生成报告不算厉害。能在沙箱里跑通代码，验证结论，这才是真本事。

### 第六层到第八层，能力底座

记忆系统，长期记忆存储。这次做完的结论，下次可以直接用，不用从头再来。

技能系统，可插拔能力模块。你需要什么能力，插进去就行。不用整个重构。

子 Agent 编排，并行任务分解。一个大任务拆成几个小任务，多个子 Agent 一起干，速度快好几倍。

看到这里你会不会觉得，这不就是把之前大家都在说的东西，拼起来了吗？

别急，后面三层才是真正的精髓。

### 第九层到第十一层，闭环才是王道

上下文管理，自动摘要压缩。干着干着上下文炸了怎么办？自动压缩，保留核心信息，扔掉没用的垃圾。

人机协同，自然语言修改计划。Agent 做的不对，你说一句话，它自己调整。不用从头再来。

多渠道接入，Telegram 飞书 Slack 都能接。你在哪用，就在哪给你推送结果。

这三层加起来，就是一个完整的**闭环**。

从需求输入，到执行，到结果交付，到人工调整，到重新执行。整个循环可以自己转起来。

我在 MEMORY 里写过一句话。没有闭环的自动化，就是自嗨。

DeerFlow 把这个闭环做出来了。

**大多数 Agent 只能说。DeerFlow 能做。**

这就是它能拿到 48K Stars 的根本原因。

## DeerFlow vs OpenClaw，到底有什么不一样

很多人看完 DeerFlow 就来问我。它和 OpenClaw 是什么关系？哪个更好？

我觉得这个问题问错了。不是谁替代谁，是定位不同。

**DeerFlow 是给你一台带 AI 大脑的电脑，让它自己干完整项目。**

**OpenClaw 是给你的电脑装上 AI 大脑，让它帮你干活。**

DeerFlow 是完整的操作系统，它从需求到交付一管到底。适合那种独立完整的任务，比如做研究，写报告，跑分析。

OpenClaw 是在你现有的工作流上，插入 AI 能力。你想让 AI 帮你写代码，它就帮你写代码。你想让 AI 帮你整理素材，它就帮你整理素材。你保留对流程的完全控制。

所以，用哪个取决于你要干什么。

如果你想要一个 AI 助理，从头到尾帮你搞定一个完整项目，选 DeerFlow。

如果你想让 AI 融入你现有的工作流，做你手里的杠杆，选 OpenClaw。

不存在谁更好，只有谁更适合你。

我自己的用法是，做独立研究用 DeerFlow，日常开发用 OpenClaw。两个一起用，效果最好。

## 给 A 股量化交易做一次适配改造

我自己做量化交易，拿到 DeerFlow 第一反应就是，能不能改一改，适配 A 股的交易场景？

改完之后发现，其实只需要做三处调整。

第一处，数据源替换。

DeerFlow 默认用的是 YahooFinance。国内用不了。换成 Tushare 或者 Akshare。都是开源免费的，数据质量也够。

第二处，交易规则适配。

A 股是 T+1，有涨跌停限制，对政策敏感度高。这些规则都要写到 Agent 的系统提示里，让它知道什么能做什么不能做。

我一开始没当回事，直接跑回测。结果策略年化 80%。实盘根本跑不出来。因为它忽略了涨跌停，你根本买不进去。

第三处，多 Agent 分工重构。

我把整个流程分成五个 Agent。

基本面 Agent，负责收集宏观数据和公司财报。

技术面 Agent，负责指标计算和形态识别。

情绪 Agent，爬取新闻和社交媒体数据，判断市场情绪。

风控 Agent，计算最大回撤，夏普比率，控制仓位。

交易执行 Agent，根据前面四个的结论，生成具体的交易信号。

这样分工下来，每个 Agent 只干一件事。不会抢活，不会混乱。

我用改造后的系统回测了过去三年的数据。累积收益 28.6%，年化 31.2%，最大回撤 -12.4%，夏普比率 2.1。

这个成绩，已经超过大多数主动管理型基金了。

当然，回测数据看看就好。关键还是实盘验证。但至少这条路，走通了。

## 为什么说 2026 是 SuperAgent 元年

我为什么说这是范式转移？

因为三年前，AI 是你的聊天伙伴。

一年前，AI 是你的助手。

今天，AI 变成了你的员工。

它能自己理解需求。自己做计划。自己执行。自己交付结果。出了问题，你说一句，它自己改。

你不需要告诉它每一步该怎么做。你只需要告诉它你想要什么。

这就是本质变化。

之前大家聊 AI 替代人类，都是说，AI 会替代蓝领，会替代白领。

现在看来，最先被替代的，是"执行层"的工作。

而人类，真正要站到**判断层**去。

我给你举个例子。做量化策略研究。找数据，跑回测，写报告，这些执行层的工作，SuperAgent 都能帮你干了。

你需要干什么？你需要判断，这个策略逻辑是不是站得住脚。未来市场环境变了，它还能不能赚钱。这个风险我该不该承担。

这些判断，AI 替不了你。只能你来。

**人做判断，AI 做执行。这就是 AI 时代最稳定的分工格局。**

这句话我在写双三角竞争力的时候说过。现在看来，越来越对。

## 如何三十分钟就能跑起来

很多人看到这种大框架，就觉得好复杂，我肯定玩不来。

其实真不用怕。DeerFlow 给你准备好了一键部署脚本。三十分钟就能跑起来。

我给你整理了最简启动清单。

1. 准备环境。需要 Git，Docker，Node.js。这些都是现成的，一行命令就能装好。
2. 克隆代码。`git clone https://github.com/byte-deerflow/deerflow.git`。
3. 配置模型 API Key。支持 OpenAI，Anthropic，通义千问，文心一言，都能用。
4. 一键启动。`docker-compose up -d`。等着就行。
5. 打开浏览器，输入地址，就能用了。

整个过程真的不复杂。就算你不是技术专家，跟着教程走，也能搞定。

我建议你，花半个小时搭起来，跑一个简单的需求试试。比如让它帮你整理一下最近 AI 领域的热点，写一份报告。

跑一遍你就知道，SuperAgent 到底是什么感觉了。
