# 记忆、上下文和 RAG 项目合集

> 来源：GitHub Trending 2026-05-04~10 周报提取
> 更新：2026-05-12

## LearningCircuit/local-deep-research
- GitHub: https://github.com/LearningCircuit/local-deep-research
- Stars: 1868（周内新增）
- 定位：本地+云端 LLM、多搜索源、私有文档、本地加密研究
- 核心价值：Deep Research 本地化，减少隐私和成本压力

## VectifyAI/PageIndex
- GitHub: https://github.com/VectifyAI/PageIndex
- 定位：Vectorless、Reasoning-based RAG
- 核心价值：不依赖传统向量库和固定切块，强调文档结构、推理和引用可追溯
- 适用：长 PDF、专业报告、论文、合规文档

## cocoindex-io/cocoindex
- GitHub: https://github.com/cocoindex-io/cocoindex
- 定位：Long Horizon Agents 增量引擎
- 核心价值：长期任务里的数据更新、索引维护和持续可用

## mksglu/context-mode
- GitHub: https://github.com/mksglu/context-mode
- 定位：AI Coding Agents 上下文窗口优化
- 核心价值：工具输出隔离、索引、摘要化，避免原始日志污染上下文

## rohitg00/agentmemory
- GitHub: https://github.com/rohitg00/agentmemory
- 定位：AI Coding Agents 持久记忆
- 核心价值：Agent 长期协作不每次从零开始，理解项目偏好、历史决策和代码风格

## 趋势判断
很多 Agent 项目失败不是因为模型太笨，而是因为上下文乱、记忆断、检索不准。记忆、上下文和 RAG 是"看不见的底座"，但决定了 Agent 能不能连续工作。
