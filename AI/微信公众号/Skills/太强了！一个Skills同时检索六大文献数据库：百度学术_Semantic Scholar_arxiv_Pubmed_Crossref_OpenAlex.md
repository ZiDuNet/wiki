## 01 为什么要自研 multi-academic-search？

大家在科研论文搜索时候，肯定发现了市面上的学术搜索工具存在很多问题：

**问题 1：搜索结果单一**

- 只用百度学术，漏掉英文文献
- 只用 Google Scholar，漏掉中文文献
- 每个数据库都要单独搜一遍

**问题 2：质量参差不齐**

- 搜出来的文献没有排序
- 高质量和低质量混在一起
- 需要人工一篇一篇筛选

**问题 3：重复文献太多**

- 同一篇论文，在不同数据库名字不一样
- 下载了十几篇，发现其实是同一篇
- 白白浪费存储空间

**问题 4：无法批量导出**

- 搜到的文献只能一篇一篇下载
- 没有统一的格式导出
- 无法直接导入文献管理软件

这些问题在OpenClaw出来之前，我没有发现很好的解决方法，但是OpenClaw出来后，我决定：**自己写一个技能，一次性解决所有问题。**

## 02 六大学术数据库的选择逻辑

我为什么选择这 6 个数据库？

| 数据库 | 语言 | 类型 | 选择理由 | API 状态 |
| --- | --- | --- | --- | --- |
| **百度学术** | 中文 | 综合 | 中文文献最全、最准 | 需 BAIDU\_API\_KEY |
| **Crossref** | 中英文 | DOI 文献 | 国际 DOI 数据库，覆盖广 | 免费 API |
| **arXiv** | 英文 | 预印本 | 顶会顶刊预印本，质量高 | 免费 API |
| **Semantic Scholar** | 英文 | 综合 | 权威学术数据库，引用数据全 | 免费 API |
| **OpenAlex** | 英文 | 学术图谱 | 开放数据，免费使用 | 免费 API |
| **PubMed** | 英文 | 医学 | 医学文献专业数据库 | 免费 API |

**逻辑**：

- 中文关键词 → 百度学术 + Crossref 补充
- 英文关键词 → arXiv + Semantic Scholar + OpenAlex
- 医学关键词 → 自动触发 PubMed + 其他英文源

### 为什么没有选择其他数据库？

**Google Scholar**

- ❌ 原因：国内网络不支持访问
- ✅ 替代：现有的 arXiv、Semantic Scholar、OpenAlex 三大英文数据库已基本满足英文文献需求
- 💡 优势：这三个数据库都有免费 API，且覆盖范围广、质量高

**CNKI（中国知网）、万方、维普等国内数据库**

- ❌ 原因：没有提供免费 API 接口
- ❌ 限制：需要机构订阅，个人用户无法批量获取
- ✅ 替代：百度学术已覆盖大部分中文文献，Crossref 补充 DOI 文献
- 💡 优势：百度学术免费、开放，适合个人研究者使用

**IEEE Xplore、ACM Digital Library等专业数据库**

- ❌ 原因：需要付费订阅，没有免费 API
- ✅ 替代：arXiv 预印本已覆盖大部分计算机领域顶会论文
- 💡 规划：后续版本考虑通过机构账号接入

**总结**：
选择的 6 大数据库都是**免费开放、有 API 接口、覆盖范围广**的学术数据源，能够满足 90% 以上的学术搜索需求。

**💡 强烈建议**：国内文献数据库（CNKI、万方、维普等）开放 Skills 技能接口，可参考百度学术模式，允许个人注册 API Key 付费接入。这不仅能满足科研人员的个性化需求，也能拓展数据库的服务场景和收入来源。

## 03 功能设计：6 大核心功能

我在设计这个技能时，遵循了 6 个核心功能：

**1. 多源并行，覆盖面广**

- 6 大数据库同时搜索，而不是一个一个搜
- 中英文同时搜索，而不是分开搜
- 医学关键词自动触发医学数据库

**2. 智能评分，质量保证**

- 不是简单罗列结果，而是按质量排序
- 高质量文献排在前面
- 低质量文献自动过滤

**3. 自动去重，避免重复**

- 同一篇文献只保留一次
- 自动识别不同数据库的同一篇论文
- 来源权重高的优先保留

**4. 进度保存，防止丢失**

- 每 5 轮搜索自动保存进度
- 即使断网、死机、停电，重启后可以从断点继续
- 结果自动导出，不会前功尽弃

**5. 继续搜索，灵活补充**

- 初次搜索不完整可继续
- 补充其他搜索源
- 智能合并去重

**6. 多格式导出，一站搞定**

- JSON 格式（完整数据）
- CSV 格式（Excel 兼容）
- BibTeX 格式（文献管理软件兼容）

## 05 检索原理：从输入到输出的完整流程

输入一个关键词后，multi-academic-search 内部到底是怎么工作的？

### 步骤 1：搜索词拆分与变体生成

当你输入"数字孪生"，系统不会只搜这一个词，而是自动生成多个变体：

```
原始词：数字孪生    ↓生成变体：  - 数字孪生  - Digital Twin  - 数字孪生 技术  - 数字孪生 方法  - 数字孪生 算法  - digital twin survey  - digital twin review  - ...（共18个变体）
```

**目的**：扩大搜索覆盖面，确保不遗漏相关文献。

### 步骤 2：语言自动识别

系统检测关键词语言，如果是输入中文关键词，默认会同时搜索中文文献数据库和英文文献数据库，如果是英文关键词，则默认搜索英文文献数据库：

```
输入：数字孪生检测：包含中文字符 → 中文关键词    ↓启用中文源：百度学术、Crossref启用英文源：arXiv、Semantic Scholar、OpenAlex
```

```
输入：Digital Twin检测：纯英文 → 英文关键词    ↓启用英文源：arXiv、Semantic Scholar、OpenAlex、Crossref
```

### 步骤 3：医学关键词自动触发

系统检测是否包含医学关键词：

```
输入：蛋白质检测：包含"蛋白质"（医学关键词）    ↓🏥 启用 PubMed 医学文献库    ↓搜索源：[PubMed, 百度学术, arXiv, Semantic Scholar, OpenAlex]
```

```
输入：人工智能检测：非医学关键词    ↓🌐 按语言选择搜索源    ↓搜索源：[百度学术, arXiv, Semantic Scholar, OpenAlex, Crossref]
```

**医学关键词库**（部分）：

- 中文：医学、医疗、临床、疾病、药物、治疗、诊断、病理、肿瘤、癌症、病毒、疫苗、蛋白质、基因、细胞...
- 英文：medical, medicine, clinical, disease, drug, therapy, diagnosis, pathology, cancer, virus, vaccine, protein, gene, cell...

### 步骤 4：并行多源检索

系统同时向多个数据库发起搜索请求：

```
搜索词：数字孪生    ↓并行搜索：  ✅ 百度学术：新增 10 篇  ✅ Crossref：新增 9 篇  ✅ arXiv：新增 10 篇  ✅ Semantic Scholar：新增 10 篇  ✅ OpenAlex：新增 10 篇    ↓原始结果：208 篇
```

**技术实现**：使用 Python 

```
subprocess
```

 启动多个搜索进程，大幅提升效率。

### 步骤 5：相同结果去重

系统检测重复文献并合并：

```
原始结果：208 篇    ↓去重规则：  - DOI 相同 → 合并  - 标题+作者+年份 相同 → 合并  - 来源权重高的优先保留    ↓去重后：148 篇
```

**去重逻辑**：

- 首先检查 DOI，DOI 相同的直接合并
- 没有 DOI 的，检查标题+作者+年份
- 来源权重高的（如 arXiv 3 分 > OpenAlex 1.5 分）优先保留

### 步骤 6：中英文结果分离与评分

系统将结果分为中文和英文，分别评分：

```
去重后结果：148 篇    ↓分离：  - 中文：108 篇（百度学术 + Crossref）  - 英文：40 篇（arXiv + Semantic + OpenAlex）    ↓评分：  - 中文：满分 7 分（标题3 + 来源2 + 时间1 + 质量1）  - 英文：满分 8 分（标题3 + 来源3 + 时间1 + 质量1）    ↓排序：按分数从高到低
```

**评分维度**：

- **标题匹配**（3分）：完全匹配3分，部分匹配2分，仅摘要1分
- **来源权重**（中文2分/英文3分）：百度学术2分，arXiv3分，Semantic2.5分，OpenAlex1.5分
- **时间新鲜度**（1分）：近3年1分，3-10年0.5分
- **引用/质量**（1分）：被引>10或核心期刊1分

### 步骤 7：中英文结果合并

将评分后的中英文结果合并，生成最终列表：

```
中文排序结果：108 篇（按7分制排序）英文排序结果：40 篇（按8分制排序）    ↓合并：  [1] 数字孪生车间——一种未来车间运行新模式 | 6/7分 | 中文  [2] 数字孪生车间信息物理融合理论与技术 | 6/7分 | 中文  [3] Digital Twin in Industry: State-of-the-Art | 7/8分 | 英文  ...    ↓最终结果：148 篇，按质量排序
```

### 步骤 8：自动保存与导出

系统自动保存结果到多个文件：

```
💾 保存结果...   - search-results-v2.json（完整结果，148篇）   - search-results-zh.json（中文结果，108篇）   - search-results-en.json（英文结果，40篇）   - search-progress.json（搜索进度）
```

### 步骤 9：导出 CSV/BibTeX 格式

用户可以选择导出格式：

**导出 CSV**：

```
用户：导出搜索结果到 CSV 格式系统：✅ 已导出 148 篇论文到 results.csv   包含字段：标题、作者、年份、引用、期刊、来源、URL、摘要、期刊等级、评分
```

**导出 BibTeX**：

```
用户：导出搜索结果到 BibTeX 格式系统：✅ 已导出 148 篇论文到 results.bib   可直接导入 Zotero/EndNote 等文献管理软件
```

**导出字段**：

- Title, Authors, Year, Citations, Venue, Source, URL, Abstract
- isCore, isSCI, isEI（期刊等级标记）
- searchQuery, score（搜索词和评分）

### 完整流程图

```
用户输入关键词    ↓[步骤1] 搜索词拆分与变体生成（18个变体）    ↓[步骤2] 语言自动识别（中文/英文）    ↓[步骤3] 医学关键词自动触发（PubMed）    ↓[步骤4] 并行多源检索（6大数据库）    ↓[步骤5] 相同结果去重（DOI+标题+作者+年份）    ↓[步骤6] 中英文结果分离与评分（7分制/8分制）    ↓[步骤7] 中英文结果合并（按质量排序）    ↓[步骤8] 自动保存（4个JSON文件）    ↓[步骤9] 导出 CSV/BibTeX 格式    ↓输出：148篇高质量文献，按质量排序
```

**总耗时：5分钟**

这就是 multi-academic-search 的完整检索原理：从输入一个关键词，到输出148篇高质量文献，全程自动化，无需人工干预。
