# 金融和行业 Agent 项目合集

> 来源：GitHub Trending 2026-05-04~10 周报提取
> 更新：2026-05-12

## anthropics/financial-services
- GitHub: https://github.com/anthropics/financial-services
- Stars: 10125（周内新增）
- 定位：AI 进入金融服务工作流
- ⚠️ 投研、合规、风控、客户服务、报表分析都可能被 AI 改造，但所有输出都必须有人类复核、权限控制、日志追踪和责任边界

## TauricResearch/TradingAgents
- GitHub: https://github.com/TauricResearch/TradingAgents
- 定位：多智能体 LLM 金融交易框架
- 角色：分析师、研究员、交易员、风控
- ⚠️ 交易不是普通自动化，任何"全自动交易 Agent"都应先放在研究和回测环境

## virattt/dexter
- GitHub: https://github.com/virattt/dexter
- 定位：Autonomous Agent for Deep Financial Research
- 核心价值：金融研究、资料整理、竞品分析、行业报告——比自动交易更现实的落地点

## HKUDS/AI-Trader
- GitHub: https://github.com/HKUDS/AI-Trader
- 定位：Fully-automated agent-native trading
- ⚠️ 越强调自动化交易，越需要看清数据源、回测方法、交易成本、风险控制和极端行情

## shiyu-coder/Kronos
- GitHub: https://github.com/shiyu-coder/Kronos
- 定位：金融市场语言基础模型（Financial Foundation Model）
- 核心价值：金融时序/市场建模方向，比 Agent 编排更底层

## 共识
金融会是 Agent 很重要的试验场，但传播热度和真实可用性之间距离很远。最值得做的是研究辅助、合规审查、报告生成和数据分析，而不是直接跳到全自动交易。
