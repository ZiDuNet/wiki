飞书上周开源了一个命令行工具，叫 Lark CLI。

装上之后，一句命令就能发飞书消息、查日历、建多维表格、发邮件、管任务。以前在飞书里点十几下才能完成的操作，现在一行文字搞定。

更重要的是，Claude Code、Cursor 这些 AI 工具可以直接调用它，替你操作飞书。

200+ 命令，覆盖飞书 11 个模块

Lark CLI 覆盖了飞书 11 个核心业务模块：消息、文档、多维表格、表格、日历、邮件、任务、会议、云盘、知识库。一共 200 多条命令。

给某个群发一条通知，一句命令。拉取多维表格里某个视图的数据，一句命令。查明天的日程安排，一句命令。

这些操作之前也都能做，但要打开飞书，找到对应功能，点好几步。现在省掉了所有中间步骤。

从日常操作到复杂的批量处理都覆盖了。新手可以先用快捷命令（+ 号开头的），最简单直接，一步完成常用操作。用熟了之后，还有更细的命令可以调，飞书的 **2500 多个功能接口**几乎全部开放。

淘宝搜索框就是一种 CLI

说到这里你可能会问：CLI 到底是什么？

CLI 全称 Command Line Interface，命令行界面。听起来很技术，但你每天都在用类似的东西。

打开淘宝，你有两种方式找商品。一种是从首页开始，点分类，翻页，一个一个看。另一种是直接在搜索栏打"红色 Nike 跑鞋 42 码"。

第一种叫 GUI（Graphical User Interface，图形界面）。系统把所有功能做成按钮、菜单、图标，你看着界面一步一步操作。你每天在飞书、微信、淘宝里的操作，都是 GUI。

第二种就是 CLI 的思路：你用一句话直接告诉系统你要什么，系统理解之后直接给你结果。中间没有菜单、没有按钮，你说什么它做什么。

再举个例子。你想设一个 10 分钟的闹钟。

GUI 的方式：打开时钟 App → 找到计时器 → 拨到 10 分钟 → 点开始。每一步都有界面引导你。

CLI 的方式：跟 Siri 说"帮我设一个 10 分钟的闹钟"。一句话，直接搞定。

区别在哪？GUI 是系统引导你一步步做。CLI 是你直接说出你要什么，系统自己去执行。

用 GUI，你得知道功能在哪个菜单里。用 CLI，你只要说得清楚你想做什么就行。

装上飞书 CLI，让 AI 替你操作飞书

这才是飞书做 CLI 最大的价值。

你在飞书里点按钮，飞书看得懂。但 AI 看不懂按钮和图标。AI 天生处理的是文字。

一句文字命令进去，一段文字结果出来。这对 AI 来说是最自然的交互方式。

飞书做 CLI，本质上是给 AI 开了一扇门。

实际用起来是这样的：你在 Claude Code 里说"帮我查一下明天的日程"，AI 自动调用飞书 CLI 查好告诉你。你说"给产品群发个消息说下午 3 点开会"，AI 调用 CLI 直接发了。你不需要切到飞书。

飞书同时还发布了一个叫 MCP Server 的东西。MCP 全称 Model Context Protocol，你可以把它理解成"万能插头"。AI 工具通过 MCP 可以用统一的方式接入飞书、GitHub 等各种外部服务。

CLI 和 MCP 是两种方式，都能让 AI 操作飞书。两个都免费开源，安装方式不同，效果类似。

从零开始：4 步装好飞书 CLI

整个过程大概 10-15 分钟，不需要会写代码。

第一步：装环境

飞书 CLI 需要 Node.js 环境。如果你电脑上还没装，去 nodejs.org 下载安装包，一路点下一步就行。

装好之后，打开终端（Mac 用"终端"App，Windows 用 PowerShell），输入以下命令安装飞书 CLI：

```
npm install -g @larksuite/cli
```

第二步：创建飞书应用

在终端里输入：

```
lark-cli config init --new
```

这一步会引导你在飞书开放平台上创建一个应用。你可以把这个应用理解成飞书发给你的一把"钥匙"，有了它，CLI 才能访问你的飞书数据。

按照提示操作就行，过程中需要登录你的飞书账号。

第三步：授权登录

输入：

```
lark-cli auth login --recommend
```

系统会自动推荐需要的权限，然后弹出一个二维码。用飞书扫一下，确认授权。

这一步完成后，CLI 就和你的飞书账号连通了。

第四步：开始用

现在你可以直接在终端里操作飞书了。

试几个快捷命令（+ 号开头的）感受一下。如果你装了 Claude Code，可以直接用中文说"帮我查一下今天的日历"，AI 会自动调用飞书 CLI 来完成。

飞书还自带了 **19 个 AI Agent Skill**，一行命令安装：

```
npx skills add larksuite/cli -y -g
```

装上之后，AI 能更聪明地使用飞书的各项功能。
