你是否还在为无法下载喜欢的视频而烦恼？今天介绍的这个开源项目，可能是我见过的最强大的视频下载工具——它就是 **yt-dlp**。

## 它是什么

yt-dlp 是一个功能强大的命令行音视频下载工具，支持访问数千个网站。别看名字里带"dl"，它的能力远不止下载 YouTube 视频——从国内的 B站、抖音，到海外的 YouTube、Twitter、Instagram，几乎你能想到的平台它都能支持。

这个项目最初是 youtube-dl 的分支，在原项目停滞后，社区接手并持续维护至今。目前已经斩获 **16.4 万 Star**，是视频下载领域当之无愧的王者。

## 快速上手

### 安装

最简单的安装方式是通过 pip：

```
pip install yt-dlp
```

或者直接下载可执行文件：

• Windows: 下载 yt-dlp.exe
• macOS: 下载 yt-dlp\_macos
• Linux: 下载 yt-dlp

### 基础用法

下载一条视频只需一行命令：

```
yt-dlp "视频链接"
```

下载时自动选择最佳画质和音频，非常方便。

## 进阶技巧

### 指定格式和画质

如果你需要特定格式，比如只要音频：

```
# 提取音频为 MP3yt-dlp -x --audio-format mp3 "视频链接"# 指定下载 1080p 画质yt-dlp -f "bestvideo[height<=1080]+bestaudio" "视频链接"
```

### 下载字幕

很多视频配有字幕，yt-dlp 可以帮你自动下载：

```
# 下载字幕并嵌入视频yt-dlp --write-subs --embed-subs "视频链接"# 指定字幕语言yt-dlp --write-subs --embed-subs --subs-language zh-Hans "视频链接"
```

### 查看所有可用的格式

有时候你想知道视频有哪些画质可选：

```
yt-dlp --list-formats "视频链接"
```

这会列出所有可选的音视频组合，方便你选择。

## 为什么选 yt-dlp

对比其他下载工具，yt-dlp 的优势非常明显：

**支持平台多**：内置支持超过 1000 个网站，几乎涵盖了所有主流视频平台。

**下载速度快**：支持多线程下载，还有断点续传功能，大文件也能轻松应对。

**社区活跃**：16 万 Star，贡献者众多，更新频繁，遇到问题很容易找到解决方案。

**功能丰富**：支持格式转换、字幕嵌入、元数据编辑、代理设置……几乎你想的功能都有。

## 实际使用场景

作为一个技术博主，我经常用它来：

1. **保存教程视频**：看到好的编程教程，先下载下来慢慢看
2. **提取播客音频**：把视频播客转成 MP3，放到通勤路上听
3. **下载中文字幕**：配合字幕学习外语视频
4. **批量下载合集**：支持播放列表，一次性下载整个系列

## 小贴士

• 遇到下载失败可以加

```
--verbose
```

 参数查看详细日志
• 下载速度慢可以试试

```
--downloader ffmpeg
```

 调用 FFmpeg 进行加速
• Windows 用户记得把下载的 exe 放到 PATH 目录下
