## 摘要

Anthropic 官方的用户研究综合 Skill，将访谈、问卷与反馈整理为结构化发现。覆盖完整工作流：研究材料收集 → 主题识别 → 综合输出 → 复核延展。包含详细方法论（Thematic Analysis、Affinity Mapping、Triangulation），以及人物画像、机会评估的具体模板。是 AI Agent 在用户研究领域的实战工具。

## 核心观点

- **定性先行，定量验证**：访谈产生假设，问卷验证规模，两者结合形成强置信度发现
- **5-8 条强发现优于 20 条弱发现**：克制综合冲动，优先级排序
- **矛盾即信号**：不同来源讲出不同故事时，差异本身揭示了用户分群
- **可执行建议**：「改进 onboarding」不可执行，「在设置流程中加入进度指示器」才是
- **行为 > 口头偏好**：真实行为数据比问卷自述更有证据力

## 方法论

### Thematic Analysis（六步）

1. 熟悉材料（Familiarization）—— 通读形成整体判断
2. 初始编码（Initial coding）—— 系统打描述性标签，宁多勿少
3. 发展主题（Theme development）—— 围绕研究问题归纳
4. 复核主题（Theme review）—— 回到数据检查充分性与区分度
5. 细化主题（Theme refinement）—— 1-2 句话清晰定义
6. 输出报告（Report）—— 带证据的发现整理

### Affinity Mapping（五步）

1. 记录每条独立观察为单独便签
2. 按相似性聚类，不预设类别
3. 命名分组抓住共同线索
4. 组织更高层级规律
5. 分组关系揭示关键主题

**提示**：每张便签只记一条；离群点同样重要；第一次分组很少是最优解。

### Triangulation（三角验证）

- **方法三角验证**：访谈 + 问卷 + 数据分析 同验证
- **来源三角验证**：不同参与者/分群 同方法验证
- **时间三角验证**：不同时间点观察同一现象

## 关键框架

### 优先级矩阵

| | 高频 | 低频 |
|---|---|---|
| **高影响** | 最高优先级发现 | 对特定分群很重要 |
| **低影响** | 改善体验质量机会 | 记录，降低优先级 |

### 发现陈述模板

```
- **发现陈述**：一句清晰概括洞察
- **证据**：引语/数据点，注明来源
- **频次**：多少参与者/来源支持
- **影响**：对用户体验/业务影响多大
- **置信度**：高（强）/ 中（有指向）/ 低（早期信号）
```

### 人物画像模板

```
[画像名称] —— [一句话描述]
他们是谁：角色、公司类型/规模、经验水平
他们想完成什么：主要目标、衡量成功方式
他们如何使用产品：使用频次/深度、关键工作流
核心痛点：最主要3个挫败点及绕路方案
他们重视什么：解决方案最重要因素、切换原因
代表性引语：2-3条原话
```

## 数据分析要点

### 定量问卷

- 看分布形状，不只看平均值（双峰 vs 正态含义完全不同）
- 按分群拆开分析，总量平均会掩盖差异
- 统计显著性：N<30 时谨慎解读小差异
- 对比行业基准或历史数据

### 开放题

- 当作迷你访谈笔记处理
- 关注结构化问题中没出现但在开放题里反复出现的主题

### 定性与定量反馈回路

```
先定性（访谈）→ 产生假设
再定量（问卷/数据）→ 验证规模
再回到定性 → 深挖意外发现
```

## 输出结构

1. 研究概览（方法/问题/时间范围）
2. 关键发现（5-8条，高频×高影响优先）
3. 用户分群/人物画像
4. 机会区域
5. 建议（具体、可执行、按影响排序）
6. 待解问题（后续研究方向）
