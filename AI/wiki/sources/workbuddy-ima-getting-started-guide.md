# ima知识库+WorkBuddy入门指南

> 来源：老陈聊营销说管理 | 30分钟跑通AI工作流

## 核心定位

**一句话结论：**
- ima知识库 = "第二大脑"，帮你存知识、管资料、随时查
- WorkBuddy = "AI打工人"，帮你执行任务、处理文件、自动干活

**分工：** ima 负责"记住"，WorkBuddy 负责"动手"

组合在一起：你的知识有人管，你的活有人干

---

## 第一部分：ima 是什么

### 定位

ima 是腾讯出的 AI 智能工作台，带 AI 能力的笔记 + 知识库

**特点：**
- 可存资料：网页、PDF、文档、图片
- 自动整理、摘要
- 自然语言搜索、提问
- 基于存入的内容回答问题

**网址：** ima.qq.com（有网页版、电脑客户端、手机端）

### 核心功能

| 功能 | 说明 |
|------|------|
| AI对话 | 基于知识库回答问题，相当于"读过你所有资料"的AI助手 |
| 个人知识库 | 创建知识库，丢入各种资料，自动解析索引 |
| 知识库广场 | 分享/查看公开知识库，适合团队协作 |
| 网页剪藏 | 浏览器插件一键保存，自动提取关键信息 |

### 适合存什么

- 行业研报、竞品分析报告
- 培训资料、学习笔记
- 项目文档、会议纪要
- 客户资料、案例分析
- 网页文章、干货收藏
- 工作总结、复盘

---

## 第二部分：WorkBuddy 是什么

### 定位

WorkBuddy 是腾讯出的 AI 智能体桌面工作台（龙虾🦞）

**特点：**
- "住在电脑里的 AI 同事"
- 能直接操作电脑上的文件
- 不是给建议，而是真的把活干了

**官网：** workbuddy.qq.com 或 codebuddy.cn/work/

### 核心功能

| 功能 | 说明 |
|------|------|
| 一句话下任务 | 中文说你要做什么，自己拆解执行 |
| 直接操作本地文件 | 授权后可读取、分析、创建、修改文件 |
| 多任务并行 | 同时处理多个任务 |
| Claw远程控制 | 微信/企业微信/QQ/飞书/钉钉远程控制电脑 |
| Skills技能包 | 安装技能包扩展能力 |
| 模型切换 | 多个AI模型可选 |

### 适用场景

- 数据处理：Excel清洗、统计报表
- 文档生成：PPT、会议纪要、周报
- 文件整理：分类、重命名、信息提取
- 调研分析：行业报告、用户反馈分析
- 批量操作：发票信息提取、格式转换

## 第三部分：ima + WorkBuddy 配合方式

### 配合方式

**单独用的问题：**
- ima：只能查，不能干活
- WorkBuddy：每次需求都得从头描述

**组合闭环：存 → 管 → 用 → 创**

| 配合方式 | 说明 |
|----------|------|
| WorkBuddy调用ima知识库 | 写报告时参考ima资料，分析数据时对比历史数据 |
| WorkBuddy帮ima整理资料 | 原始文件整理、分类、摘要后存入ima |
| 微信远程操控 | 手机发微信 → WorkBuddy从ima调资料 → 结果发回微信 |

## 第四部分：安装和使用

### ima 安装

**方式1：网页版**
- 打开 ima.qq.com，微信扫码登录

**方式2：电脑客户端**
- 下载 Mac/Windows 版，数据同步

**第一步建议：** 建知识库，丢几份常用文档试试搜索

### WorkBuddy 安装

1. 打开 codebuddy.cn/work/
2. 点击下载，选择系统版本
3. 安装并登录（微信扫码）

**第一步建议：** 给一个简单任务感受能力

### Claw 远程控制配置

1. 打开 WorkBuddy → Claw 设置
2. 选择微信，扫码绑定
3. 找到 ClawBot，发消息即下任务

## 第六部分：常见问题

| 问题 | 回答 |
|------|------|
| 收费吗？ | 公测阶段免费 |
| 数据安全？ | 腾讯云安全体系，WorkBuddy操作本地文件不上传 |
| 无技术背景能装？ | 能，跟普通软件一样 |
| vs ChatGPT？ | ChatGPT纯对话，ima有知识库，WorkBuddy能操作文件 |
| 手机能用？ | ima有手机端，WorkBuddy通过微信远程控制 |
| vs OpenClaw？ | WorkBuddy兼容OpenClaw Skills格式 |
