# Horizon：打造你的专属 AI 新闻雷达

**Source:** Horizon/Horizon：打造你的专属 AI 新闻雷达.md
**Date ingested:** 2026-05-11
**Type:** article

## Summary

开源项目 Horizon（Thysrael/Horizon），AI 驱动的个人新闻雷达。多源聚合（HN、Reddit、RSS、GitHub）→ AI 评分过滤 → 智能去重 → 上下文丰富 → 社区评论汇总 → 双语简报输出。支持 GitHub Pages、邮件、Webhook（飞书/钉钉/Slack）、MCP 服务等交付方式。

## Key Claims

- 不是简单摘要工具，而是完整的新闻处理流水线
- 多源聚合：HN、RSS/Atom、Reddit、GitHub
- AI 智能筛选：0-10 分评分，自定义阈值过滤噪音
- 智能去重：跨平台合并相同报道
- 上下文丰富：自动搜索不熟悉的概念和公司背景
- 社区评论汇总：收集 HN、Reddit 等平台讨论
- 双语输出：中英文简报同时生成
- 推荐用 GitHub Actions 定时任务自动化运行
