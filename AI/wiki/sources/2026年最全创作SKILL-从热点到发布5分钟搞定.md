## Summary

一篇 21000 字的长文，介绍从热点发现到内容发布的全流程 AI Skill 工作流。围绕 5 个核心环节（信息收集→选题分析→文章写作→视觉排版→一键发布），推荐具体 Skill 组合：last30days-skill（30 天跨平台深度研究）、nicepkg/openclaw（中文热搜聚合）、agent-browser（浏览器自动化）、self-improving-agent（选题分析）、baoyu-format-markdown（格式优化）、Nano Banana Pro（AI 图片生成）、SuperDesign（UI 设计）、PPT Master（PPT 生成）。

## Key Claims

1. **last30days-skill**：跨 12+ 平台（Reddit/X/YouTube/TikTok/Hacker News/Polymarket/GitHub 等）30 天深度研究，AI 合成结构化简报
2. **nicepkg/openclaw**：零配置聚合抖音/微博/百度/B站/快手等中文热搜，无需 API Key
3. **agent-browser**：无头浏览器自动化，支持网页抓取/截图/表单填写
4. **选题分析 Skill 模板**：热度评估→竞争分析→受众匹配→角度推荐的完整框架
5. **视觉技能组合**：Nano Banana Pro（封面图）、SuperDesign（UI 方案）、Image Cog（多模型图像）、Visual Note Card（中文信息图）
6. **PPT Master**：模板复刻、风格生成、内容驱动 PPT，支持 /create-template 保存模板
