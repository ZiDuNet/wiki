# 政策法规监控 Skill：持续跟踪行业新规，把变化变成行动清单

**来源：** 微信公众号/厚国兄（Agent Skills 万千应用 · 第15篇）
**摄入日期：** 2026-05-31
**类型：** 文章

## 摘要

帮助团队把政策、法规、平台规则变化快速转换成业务影响判断和执行清单的 Agent Skill。面向销售、客服、运营和小团队老板，不是写正式法律意见，而是把变化拆成业务影响、风险等级、负责人动作和复核事项。

## 核心观点

- **痛点**：看到了新政策也不知道怎么处理——影响产品功能、运营流程、合同文案、客服话术、技术接口，但各团队各看各的，没有人形成行动清单
- **Skill 定位**：不是"提醒工具"，而是"合规变化到执行动作"的转换器
- **核心机制**：四层——信息源清单 → 变化识别 → 影响映射 → 行动清单
- **使用场景**：AI 硬件（数据合规/录音授权）、跨境电商（平台规则/商品资料）、金融科技、教育工具
