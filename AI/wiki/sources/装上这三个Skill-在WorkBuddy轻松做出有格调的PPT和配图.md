# 装上这三个Skill：在WorkBuddy轻松做出有格调的PPT和配图！

**来源:** WorkBuddy/装上这三个Skill：在WorkBuddy轻松做出有格调的PPT和配图！.md
**摄入日期:** 2026-05-27
**类型:** 文章

## 摘要

文章推荐了三款可在 WorkBuddy 上安装的配图和 PPT 生成 Skill：any2html（复古风 HTML 信息卡片）、info-card-designer（杂志风文字卡片）、guizang-ppt-skill（电子杂志风网页 PPT）。三款工具均能自动生成高质量视觉内容，可直接用于小红书、公众号、X 等平台。

## 三款 Skill 概览

| Skill | 作者 | 风格 | 适用场景 |
| --- | --- | --- | --- |
| **any2html** | 半大熊猫 | 复古风 HTML 信息卡片 | 小红书轮播图、推特长图、公众号文章配图 |
| **info-card-designer** | 向阳乔木 | 杂志风文字卡片 | 文字一键变杂志质感 PNG，支持 Hook 模式 |
| **guizang-ppt-skill** | 归藏 | 电子杂志风 + 瑞士国际主义 | 横向翻页网页 PPT、多平台封面 |

## any2html 特点

- 三种版本：竖版（小红书多图版）、横版（一图流全览版）、插图版（文章极简配图）
- 竖版自动生成多页模块并带精美页脚编号（01/03）
- 插图版极致克制，仅保留标题与核心金句

## info-card-designer 特点

- 经典风格、杂志风格、艺术风格三种可选
- Hook 模式：每条描述改写为 10-20 字钩子句
- 支持 480/600/900px 宽度自定义
- 超长卡片（>1200px）自动分割成多张图
- 使用仓耳今楷（TsangerJinKai）本地字体，截图渲染 100% 一致

## guizang-ppt-skill 特点

- 两套视觉系统：电子杂志×电子墨水 / 瑞士国际主义
- 横向左右翻页（键盘/滚轮/触屏/底部圆点/ESC 索引）
- Codex 可选配图流程：GPT-Image 2.0 / GPT-M 2.0 生成纪实照片、信息图、流程图
- 多平台封面：公众号 21:9、公众号分享卡 1:1、小红书 3:4、视频号横版

## 安装命令

```bash
# any2html
npx skills add blockpanda/any2html --skill any2html

# info-card-designer
npx skills add joeseesun/qiaomu-info-card-designer

# guizang-ppt-skill
npx skills add op7418/guizang-ppt-skill --skill guizang-ppt-skill
```
