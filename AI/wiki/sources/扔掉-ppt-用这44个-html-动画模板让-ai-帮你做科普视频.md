# 扔掉PPT，用这44个HTML动画模板，让AI帮你做科普视频

**Source:** 有料黑科技
**Category:** AI Coding
**Date ingested:** 2026-05-10
**Type:** article

## Summary

介绍开源项目 AI-Animation-Skill（MIT协议），提供44个HTML动画模板，配合 AI Agent 两步生成科普视频动画。与 Gamma、Beautiful.ai 不同，输出为单HTML文件，本地运行零成本，原生支持中文。

## Key Claims

- 44个模板分三类：PPT Level2（26个）、PPT基础（4个）、Animation流程图（14个）
- 纯前端代码零依赖，最轻量模板仅331行代码
- 单HTML文件输出，浏览器打开全屏录屏即为视频
- 支持 OpenClaw、WorkBuddy 等 AI Agent 平台
- 专为中文科普场景设计，与 Gamma/Beautiful.ai 形成差异化
