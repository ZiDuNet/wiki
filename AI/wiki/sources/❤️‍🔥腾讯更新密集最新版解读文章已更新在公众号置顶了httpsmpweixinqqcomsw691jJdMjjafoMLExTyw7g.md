## 摘要

大家好，我是Ada。专注"副业"的仨娃妈妈。
最近腾讯密集推出了三个"小龙虾"相关产品：QClaw、WorkBuddy、ClawBot。
到底有啥区别？装哪个？今天一次说清楚。
|  |  |  |  |
| --- | --- | --- | --- |
| 对比项 | QClaw | WorkBuddy | ClawBot |
| 出品方 | 腾讯电脑管家团队 | 腾讯云CodeBuddy团队 | 微信官方 |
| 安装方式 | 电脑安装软件 | 电脑安装软件 | 先部署OpenClaw，再装微信插件 |
| 使用方式 | 微信发指令 | 定时自动执行+手动触发 | 微信里像好友一样对话 |
| 适用人群 | 个人用户 | 企业/团队 | 有服务器/会部署的人 |
| 核心特点 | "秘书"，你叫才动 | "员工"，定时上班 | "微信好友"，可置顶常驻 |
**本质**：腾讯电脑管家出的"本地AI助手"，装在电脑上，通过微信调用。
**特点**：你发微信，它干活。不发指令，不动。
**适合谁**：个人用户，想让电脑帮自己跑腿的。
