## Summary

这篇文章介绍了一个名为 YouMind 的微信公众号 AI Skill，能够通过一句话指令自动完成公众号文章的全流程创作。从选题、写作、配图、排版到发布草稿箱，整个过程可以全自动执行，大幅降低了内容创作者的工作负担。

Skill 支持多种运行模式：自动模式下全程自动跑完8步流程（热点→选题→写作→SEO→配图→排版→发到草稿箱），交互模式则会在关键环节暂停让用户选择。文章还详细介绍了微信开发者平台的 Token 获取流程、IP 白名单配置方法，以及 Skill 的主题系统、配图降级链和多客户管理等高级功能。

## Key Claims

1. 一句话指令即可完成公众号文章从选题到发布的全流程自动化
2. Skill 内置4款主题（simple、center、decoration、prominent），支持任意 HEX 色值自定义
3. 配图生成采用降级链机制：AI生图 → Nano Banana Pro图库搜索 → 预制封面匹配 → 只输出prompt
4. 多客户管理模式支持每个客户独立目录，互不干扰
5. 通过语料喂养和改稿学习机制，可以让文章越写越像作者风格

## Limitations / Bias

文章主要推广 YouMind 产品，对其他类似工具未做对比分析。需要微信公众号 API 权限，对个人账号（无认证）可能存在限制。
