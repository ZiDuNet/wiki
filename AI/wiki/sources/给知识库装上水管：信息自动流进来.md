# 给知识库装上水管：信息自动流进来

**Source:** 知识库/给知识库装上水管：信息自动流进来.md
**Date ingested:** 2026-05-11
**Type:** article

## Summary

作者分享了一套完整的个人信息处理系统设计，解决"信息怎么稳定地流进来"的问题。系统分四层：主动保存层、搜索备用层（多 provider fallback）、视频采集层、平台雷达层。核心理念是"打通能力，克制地用"——热榜是信息雷达不是知识库内容，Inbox 看完即走，知识库保持干净。

## Key Claims

- 单一搜索 provider 是 AI Agent 任务的单点故障，多 provider fallback 是基础设施
- 搜索切换对 Agent 透明——Agent 只管调"搜索"，不感知 provider 变化
- 热榜的正确定位是"信息雷达"而非知识库内容，直接入库会破坏精选定位
- 系统能做全自动，但选择半自动是主动选择不是技术限制
- 信息流四象限：采集→编译→保存→调用，每步有对应工具和清晰边界
- 知识库价值上限由"噪音有没有被拦住"决定，不只是"存进去的内容质量"
