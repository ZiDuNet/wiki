# 别让 AI 写出来的网站，死在 localhost

## 核心观点

AI 生成的网站 `localhost:3000` 只有自己能打开。上线需要：买域名、选服务器、用宝塔面板部署、配置 DNS 和 HTTPS。从本地 Demo 变成真正公网可访问的网站。

## localhost 问题本质

`localhost` 代表本机，别人访问的是他自己的电脑，不是你的项目。真正上线需要：
- 网站文件放到服务器
- 项目能在服务器运行
- 域名解析到服务器
- 用户访问域名能找到项目
- 开启 HTTPS 避免浏览器不安全提示

## 上线完整流程

| 步骤 | 操作 | 说明 |
|-----|------|------|
| 1 | AI 编程工具生成项目 | Trae/CodeBuddy/Qoder |
| 2 | 准备服务器 + 安装宝塔 | 云厂商选择宝塔镜像 |
| 3 | 上传项目到服务器 | 打压缩包 → 文件管理 → 解压 |
| 4 | 安装 Node 环境 | Node 版本管理器 → npm |
| 5 | 启动项目 | Node 项目管理器 → 自动识别启动选项 |
| 6 | 配置域名映射 | 外网映射开关打开 |
| 7 | 申请 SSL 证书 | Let's Encrypt 免费 |

## 宝塔面板核心能力

- 服务器环境可视化管理
- Node 项目一键部署
- 域名绑定与 SSL 申请
- 日志查看与监控

## 关键技术点

- **域名解析**：境内服务器需 ICP 备案
- **反向代理**：Nginx 配置端口转发
- **SSL 证书**：仅域名可申请，IP 不支持免费证书
