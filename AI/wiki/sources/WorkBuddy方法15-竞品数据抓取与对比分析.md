# WorkBuddy方法15 | 竞品数据抓取与对比分析：知己知彼

## 核心摘要

本文介绍如何利用 WorkBuddy 的浏览器自动化能力，自动抓取竞品数据并生成对比分析表。将原本需要2小时的手动竞品调研工作压缩到10分钟完成。

## 关键观点

### 竞品监控的痛点

- **信息分散**：竞品信息分布在官网、应用商店、社交媒体
- **更新频繁**：价格、功能、活动经常变化，手动跟踪跟不上
- **整理困难**：收集到的信息零散，难以形成系统对比
- **容易遗漏**：手动检查容易漏掉关键更新

### WorkBuddy 解决方案

用户指定竞品和监控维度，WorkBuddy 自动抓取数据、生成对比表。

**核心 Prompt 模板：**
```
请使用浏览器自动化技能，打开[竞品网站URL]，抓取以下信息：
1. 产品名称和价格
2. 核心功能列表
3. 用户评价数量和评分
4. 最新更新时间

分析要求：
1. 与我们的产品进行对比（优势/劣势）
2. 生成竞品对比矩阵表
3. 输出为Excel格式
4. 附200字以内的分析结论
```

### 进阶用法

- 批量监控多个竞品（3-5个为宜）
- 生成 SWOT 分析图
- 定期定时任务自动更新

### 避坑指南

1. **不要抓取频率过高**：可能触发反爬机制，建议每周1-2次
2. **不要完全信任数据**：价格可能是促销价，需多渠道验证
3. **注意法律风险**：仅抓取公开信息，遵守 robots.txt

### 核心逻辑

- 人负责：指定竞品和维度
- AI负责：抓取、整理、分析
- 人负责：复核数据、解读结论
