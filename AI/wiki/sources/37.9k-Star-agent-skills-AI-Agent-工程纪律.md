# 37.9k Star 的 agent-skills：AI Agent 也该有工程纪律

## Summary

Addy Osmani 开源的生产级 AI coding agent 工程技能包 agent-skills已在 GitHub 获得 37.9k Stars。它不是又一个提示词合集，而是把需求澄清、计划拆解、增量实现、测试验证、代码评审和发布交付写成可加载的 SKILL.md，让 AI Agent 按工程流程收尾。

## Key Claims

1. **Skills encode workflows, quality gates, and best practices** — 把资深工程师平时会做但 Agent 经常偷懒跳过的动作拆成流程
2. **7 个 slash commands 串起交付线**：DEFINE → PLAN → BUILD → VERIFY → REVIEW → SHIP
3. **TDD 反借口表是核心价值** — 把 Agent 常说的"我可以等代码写完再补测试"等借口写进 skill，逼它回到证据上
4. **不绑定特定模型** — Claude Code、Cursor、Gemini CLI、Windsurf、OpenCode、GitHub Copilot、Kiro 都能用
