# 白虎面板 — 轻量级 NAS 定时任务调度平台

**来源：** 微信公众号/飞牛 NAS/我在 NAS 里养了一只「白虎」，平替青龙面板！海康存储部署 baihu-panel.md
**摄入日期：** 2026-05-30
**类型：** 文章
**作者：** 可爱的小Cherry

## 摘要

白虎面板（baihu-panel）是针对青龙面板（qinglong）性能占用过高问题而生的轻量级定时任务调度平台，采用 Go + Vue3 开发，Docker 部署，适合在 NAS 上安静运行签到脚本、API 监控、定时备份等轻量任务。

## 核心观点

- **定位：** 轻量级定时任务调度，替代沉重的青龙面板，适合"只想安安静静跑几个脚本"的用户
- **技术栈：** Go + Vue3，Docker/compose 部署，开箱即用无需复杂配置
- **安全性：** AES-GCM 加密存储密钥，日志自动打码，防止截图/导出发送时泄露
- **远程执行：** 支持远程 Agent 插件，可把 Agent 下载到服务器远程调度任务
- **多语言支持：** 深度集成 Mise，支持 Python/Node/Go/Rust/Ruby/Java/PHP/Deno/Bun 等十多种运行环境和版本管理
- **内建助手库：** Python/Node.js 零配置推信，无需手动管理 API Token 和 URL
- **部署：** 以海康存储 R1 为例，通过容器镜像部署，分配 8052 端口，设置 TZ=Asia/Shanghai 环境变量

## 功能特性

| 特性 | 说明 |
|------|------|
| 任务调度 | 标准 Cron 表达式，常用时间规则快捷选择，日志不落文件 |
| 脚本管理 | 在线代码编辑器，文件树，压缩包上传解压 |
| 在线终端 | WebSocket 实时终端，命令执行结果实时输出 |
| 消息推送 | TGB/Bark/钉钉/企微/飞书/邮件等主流渠道 |
| 机密管理 | 类似 GitHub Secrets，AES-GCM 加密，日志自动打码 |
| 环境变量 | 任务执行时自动注入 |
| 现代UI | 响应式设计，深色/浅色主题，移动端适配 |
