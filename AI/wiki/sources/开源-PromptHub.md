## Summary

PromptHub 是一款开源免费的 AI Prompt 与技能管理工具，解决 AI 工程师在多平台（Claude Code、Cursor、Windsurf 等 15+ 平台）之间切换时 Prompt 和 Skill 文件管理混乱的问题。核心特性：本地优先（SQLite 存储，不上传云端）、版本控制、多模型对比测试、一键分发。

## Key Claims

1. **多平台一键分发**：支持 Claude Code、Cursor、Windsurf 等 15+ 主流 AI 平台，Skill 文件一键分发
2. **本地优先隐私保护**：数据存储在本地 SQLite 数据库，绝不上传云端
3. **版本控制**：可追溯每次 Prompt 的修改记录
4. **多模型对比**：同时测试多个模型，找到最优 Prompt 配置
5. **即时搜索**：毫秒级全局搜索，快速定位上百个 Prompt
