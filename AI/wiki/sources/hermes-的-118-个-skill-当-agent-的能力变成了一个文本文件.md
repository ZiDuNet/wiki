# Hermes 的 118 个 Skill：当 Agent 的能力变成了一个文本文件

**Source:** AI赋能说
**Category:** Hermes
**Date ingested:** 2026-05-10
**Type:** article

## Summary

深度解析 Hermes v0.10 的 118 个 Skill 文件——全是 Markdown，没有代码。揭示 Agent 能力可以被定义为纯文本文件：触发条件、执行步骤、注意事项。Skill 本质上是操作手册，Agent 通过理解文本执行动作。

## Key Claims

- Hermes v0.10 有 118 个 Skill，全部是 Markdown 文件（SKILL.md）
- 没有 .py/.js 代码，纯文本定义 Agent 行为
- 典型 Skill：claude-code（委托编码任务）、codex、iMessage/Reminders/FindMy/Notes（Apple 生态）
- Skill 本质是操作手册，告诉 Agent 遇到特定情况怎么做
- 能力可扩展、可共享、可版本控制
