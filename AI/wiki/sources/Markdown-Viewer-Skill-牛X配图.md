# 牛 X 的Skill

## Summary

Markdown Viewer Skill 是一个包含 100+ 图例、6000+ 精选矢量图标的 AI 配图工具。一句话就可以根据 Markdown 内容自动定制各类图表和配图，并自动插入到 Markdown 文件中。支持流程图、架构图等，适合 Claude Code 等 AI 编程工具。

## Key Claims

1. **100+ 图例 + 6000+ 矢量图标** — 丰富的视觉资源库
2. **一句话生成配图** — 让 AI 根据 Markdown 内容自动生成图表
3. **自动插入 Markdown** — 无需手动复制粘贴
4. **安装简单** — `npx skills add markdown-viewer/skills`
