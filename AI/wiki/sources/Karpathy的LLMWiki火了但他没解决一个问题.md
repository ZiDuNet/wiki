# Karpathy的LLMWiki火了但他没解决一个问题

## Summary

分析Karpathy LLM Wiki的核心问题：知识库是被动容器，需要人工喂料才能运转，导致三天热情、一周遗忘。提出三步解决方案：信息自动进来→自动变成知识→主动推送反馈。引用Vannevar Bush的Memex设想，说明80年前的问题和现在一样——不是工具不好，是维护太累。

## Key Claims

1. Karpathy的LLM Wiki核心问题：需要人工喂代码，三天热情、一周遗忘
2. Agent解决了维护问题，但采集和反馈问题还在
3. 三步解决方案：信息自己进来→自己变成知识→主动来找你
4. Farza的Farzapedia：2500条素材生成400篇互相链接的个人百科，wiki是为Agent建的
5. Vannevar Bush的Memex设想从未落地，因为没人愿意持续维护
6. wiki不只是记忆，是Agent的工作底稿
