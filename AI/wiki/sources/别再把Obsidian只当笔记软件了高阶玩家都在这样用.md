# 别再把Obsidian只当笔记软件了高阶玩家都在这样用

## Summary

介绍Obsidian从基础笔记软件进化为知识操作系统的进阶用法。涵盖CSS Snippets（界面定制）、Templater（自动化模板）、QuickAdd（工作流自动化）、Obsidian URI（跨应用跳转）、插件开发五大高阶能力。推荐三层模板结构：Snippets片段→Templates模板→Workflows工作流。

## Key Claims

1. Lv1基础用户→Lv4系统构建者的能力升级路径
2. CSS Snippets目标：降低长期使用心理摩擦，让阅读写作更顺手
3. Templater真正价值：把固定重复动作全部自动化
4. QuickAdd本质：轻量级自动化引擎，Macro可串多个动作为一键工作流
5. Obsidian URI可实现跨应用跳转，让Obsidian成为工作流入口
6. 推荐三层模板结构：Snippets→Templates→Workflows
