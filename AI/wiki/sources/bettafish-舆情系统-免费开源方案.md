# BettaFish 舆情系统：开源免费舆情分析

**来源：** 我帮朋友搭了个免费的舆情系统，省下了每年几万块的订阅费.md
**摄入日期：** 2026-05-30
**类型：** 文章
**公众号：** So talk

## 摘要

作者帮朋友公司搭建了一套免费舆情系统，使用开源项目 BettaFish（微舆）。解决了品牌合作前摸底艺人/KOL 口碑的需求——风评如何、有无负面、粉丝真实声音、情绪走向。测试了电影《给阿嫲的情书》女主角李思潼，30 分钟生成 2.1 万字分析报告。多 Agent 架构分工协作，全程靠 Vibe Coding（AI 辅助）完成部署。

## 核心观点

- **舆情系统解决三件事**：当前风评（有无潜在雷）、粉丝说什么（真实口碑还是控评）、负面情绪走向（扩散还是消退）
- **传统方式缺陷**：人工各平台搜，又慢又片面，专业舆情软件价格劝退中小团队
- **BettaFish 多 Agent 协作**：一个 Agent 全网抓内容，一个分析情绪和关键词，一个生成结构化报告
- **核心功能三件套**：情绪时间线（判断负面偶发还是持续）、关键词聚类（固有印象 + 品牌调性匹配）、内容来源分布（平台声量 × 用户群体）
- **局限**：部分平台覆盖不全，实时性不如商业产品，适合背景调研而非危机实时监控
- **部署方式**：Docker，文档清楚，主要卡点是依赖冲突，靠 AI 定位解决
