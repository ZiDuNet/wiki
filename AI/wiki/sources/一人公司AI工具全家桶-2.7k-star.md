# 一人公司 AI 工具全家桶

## 核心摘要

**one-person-company** 是 GitHub 上由 **cyfyifanchen** 维护的开源 AI 工具清单项目（2.7k Star），口号是"有些工具是宝，有些工具是坑，帮你踩坑精准找宝"。项目按一人公司实际工作流组织，覆盖 AI 对话模型、Vibe Coding 工具、内容创作、品牌设计、效率工具完整链路。

## 一人公司 AI 工具矩阵

项目提出六层结构：

1. **决策层（大脑）** — Claude / GPT / Gemini / DeepSeek，多模型交叉
2. **开发层（产品）** — Cursor / Claude Code / GitHub Copilot
3. **内容层（获客）** — AI 图文 + AI 视频 + AI 语音克隆
4. **设计层（品牌）** — AI Logo + AI UI/UX + AI 网站
5. **效率层（运营）** — AI 邮件 + 自动化工作流 + AI 项目管理
6. **验证层（测试）** — AI 原型 + 一键 MVP

## Vibe Coding 工具链

2025 年最火概念之一：描述需求 → AI 生成代码 → 测试反馈 → AI 修复改进。

收录工具：Cursor（最热门 AI IDE）、Claude Code（Anthropic 命令行工具）、Windsurf（互补 AI IDE）、Trae（字节 AI IDE 国内生态）、GitHub Copilot（VS Code 天然选择）、Augment Code（新锐）。

## AI 对话策略

作者实测策略：**日常主力 Claude 3.7 Sonnet + Gemini 2.5 Pro**，需要交叉验证时切 DeepSeek 和 Grok。核心建议：不要只用一个模型，不同任务切换不同模型并交叉验证。

## 声音克隆工具

项目特别推荐：10 秒音频样本创建专属 AI 声音，支持跨语言、语速调节、逐字朗读，自部署代码 100% 开源。

## 为什么值得收藏

1. **实测验证**：作者日常使用，包含踩坑心得，不是简单罗列
2. **按工作流组织**：不是技术分类，是一人公司实际运营场景分类
3. **持续更新**：44 次提交，保持跟踪市场变化
