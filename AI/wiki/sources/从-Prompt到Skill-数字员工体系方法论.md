## Summary

文章系统阐述从 Prompt 到 Skill 的演进路径，提出 Skill 是 AI 从"聊天伴侣"进化为"数字员工"的关键。AI 进化五级台阶：提示词 → 工具调用 → MCP → 智能体 → Skill。Skill 本质是"给 AI 颁发职业资格证书"——封装专业知识与流程，使 AI 能在特定场景稳定、专业地完成任务。

## Key Claims

1. **AI 五级进化**：提示词 → 工具调用 → MCP → 智能体 → Skill，Skill 是最终形态
2. **Skill 三重价值**：标准化（解决不稳定）+ 私有知识化（解决不了解用户）+ 专业化（解决博而不精）
3. **Skill 完整结构**：SKILL.md（岗位说明书）+ references/（知识库）+ scripts/（工具箱）+ assets/（素材库）
4. **渐进式披露机制**：元数据层（启动时）→ 指令层（任务相关）→ 资源层（按需加载），节省上下文
5. **数字员工团队**：积累多个 Skill 后，拥有 24 小时待命的数字员工团队，支持 Git 版本控制
