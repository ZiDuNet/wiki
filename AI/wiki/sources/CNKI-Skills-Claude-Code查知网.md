# CNKI Skills 查知网一条龙

## 核心摘要

**CNKI Skills for Claude Code** 让 Claude Code 通过浏览器操作知网，把检索、筛选、解析、下载、引用导出一条龙变成一句自然语言指令。不是绕过知网权限，而是模拟人工操作——你能访问的它帮你自动化，你没权限的它也无法破解。

## 能力模块

1. **关键词检索** — 快速找到相关文献
2. **高级筛选** — 按年份、来源（CSSCI/北大核心）、相关度筛选
3. **论文详情解析** — 提取摘要、关键词、作者单位、基金项目
4. **期刊信息查询** — 投稿前查期刊信息
5. **PDF/CAJ 下载** — 批量下载可访问全文
6. **引用导出** — 标准引用格式
7. **Zotero 入库** — 文献元数据 + 附件 + 分类整理

## 典型使用场景

**场景 1：开题前的文献调研**
> 帮我检索"生成式人工智能在高校教学中的应用"相关中文论文，筛选 2020 年之后的核心期刊文献，整理成表格。

**场景 2：写文献综述**
> 在刚才的检索结果中，只保留 2019 年以来发表在 CSSCI 或北大核心期刊上的论文，按发表时间从新到旧排序。

**场景 3：批量获取文献详情**
> 打开相关性最高的前 5 篇论文，提取摘要、关键词、作者单位和基金项目信息。

**场景 4：下载+整理到 Zotero**
> 帮我下载前 10 篇可以获取全文的论文，并记录哪些成功、哪些失败。
> 把这 15 篇核心期刊论文导入 Zotero，创建一个"XX 研究"分类。

## 工作流对比

| | 传统方式 | CNKI Skills |
|---|---|---|
| 检索 | 人手动搜 | 自然语言指令 |
| 筛选 | 人一个个点 | 自动按条件过滤 |
| 获取摘要 | 人一个个打开 | 自动提取 |
| 下载 | 人一个个点 | 自动尝试下载 |
| 整理 | 人手动复制到 Zotero | 自动导入 |

## 重要边界

- **不绕过权限**：能访问的才能自动化，不能访问的还是不能访问
- **不替代学术判断**：哪些文献重要、哪些观点值得引用，最终要自己读判断
- **适合第一轮文献准备**：从 0 到 1 的批量筛选，不适合深度学术分析
