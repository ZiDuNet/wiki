# 用 Claude Code + Obsidian，打造属于自己的智能信息中枢

**来源：** 用 Claude Code + Obsidian，打造属于自己的智能信息中枢.md
**摄入日期：** 2026-05-26
**类型：** 文章
**作者：** 清晨还是傍晚

## 摘要

作者基于"6个信息处理筛子"的框架，用 Claude Code 在 Obsidian 仓库目录下对话，将本地笔记库改造为自动化信息处理系统。核心思路：输入端零负担、规则驱动自动处理、每日清空中间状态。

## 核心观点

- **信息焦虑的根源不是提示词，而是每次都要自己判断分类**——自动化系统才能根治
- **三个机制对应完整闭环**：统一入口（收件箱）→ 机器清洗（skill 自动分类）→ 每日归档（收工检查）
- **claude.md 全局规则文件**：存放系统级规则，每次 Claude Code 启动先读此文件
- **Skill 自动生成**：Claude Code 读取"6个筛子"逻辑后自动生成 skill，自动套用规则
- **收工流程强制归档**：知识库失败的真实原因不是没有输入，而是没有每天清空中间状态

## 信息处理三机制

### 机制一：极简统一入口
- 删除所有中间文件夹（待读文章/碎片灵感），只保留唯一的 `收件箱/` 根目录
- 原则：不要在输入端增加任何大脑负担，先收进来，后面交给 AI 处理

### 机制二：一句口令全自动"洗牌"
- Claude Code 生成 skill，将 6 个筛子全部写入执行规则
- 输入"处理收件箱"→ AI 自动读文件、匹配筛子、生成卡片并汇报

### 机制三：每日收工强制归档
- "收工"指令触发待确认区检查，有未处理卡片则列出建议去向
- 必须做选择（入库/暂存/删除），收工流程才算完成
- **核心认知**：知识库失败的真实原因是中间状态没有每天清空
