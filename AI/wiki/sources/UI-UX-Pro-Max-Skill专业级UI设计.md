## Summary

ui-ux-pro-max-skill（UI/UX Pro Max）是一款给 AI 编程工具（Claude Code、Cursor、Windsurf 等 17 个平台）使用的「设计智能」插件。AI 写 UI 代码前自动生成完整设计系统：67 种风格（Glassmorphism/Neubrutalism/Bento Box 等）、161 套行业配色方案、57 套字体组合、161 条行业推理规则（哪些设计适合/禁忌）。核心功能 Design System Generator 可根据产品类型自动匹配设计规范。

## Key Claims

1. **Design System Generator**：输入"美容 SPA 落地页"，自动匹配 Soft UI 风格+粉色配色+Cormorant Garamond 字体+完整页面结构建议
2. **161 条行业规则**：金融禁 AI 紫/粉渐变（不专业）；医疗禁高对比度警告色（需放松）；游戏推荐赛博朋克/霓虹灯
3. **67 种 UI 风格**：Glassmorphism、Claymorphism、Neubrutalism、Bento Box Grid、AI-Native UI 等
4. **跨平台支持**：Claude Code/Cursor/Windsurf/GitHub Copilot/Kiro/Roo Code 等 17 个平台
5. **安装命令**：`npm install -g uipro-cli` → `uipro init --ai claude`
