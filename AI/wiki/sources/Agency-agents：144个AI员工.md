# Agency-agents：别再只会调提示词了，这个开源项目直接给你 144 个 AI 员工

**Source:** Agent/Agency-agents：别再只会调提示词了，这个开源项目直接给你 144 个 AI 员工.md
**Date ingested:** 2026-05-11
**Type:** article

## Summary

介绍了 GitHub 开源项目 agency-agents（144 个专职 Agent，覆盖 12 个 division）。不是 Agent 框架，而是"AI 员工说明书仓库"——每个 Agent 是一个 Markdown 文件，定义身份、任务、边界、交付标准、执行流程。核心观点：AI 不是只需要提示词，它更需要岗位说明书。

## Key Claims

- Agency-agents 不是框架，更像"可安装的 AI 专家团队"
- 每个 Agent 是 Markdown 文件，包含身份、核心任务、工作边界、交付标准、执行流程、沟通风格
- Agent 角色颗粒度要细：不是"编程专家"，而是 Frontend Developer、Backend Architect、Security Engineer 等
- 多 Agent 真正有价值的地方不是同时聊天，而是让不同"岗位视角"参与同一个问题
- 支持 Claude Code、GitHub Copilot、Gemini CLI、OpenCode、Cursor、Aider、Windsurf、Kimi Code、[[OpenClaw]] 等
- AI 工具正从"一个聊天窗口"走向"一组可调用的专业岗位"
