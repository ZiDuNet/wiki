# 自己动手搭API中转站之Sub2API：一个网关统管 OpenAI / Claude / Gemini，限流计费全搞定

**分类：** Claude
**日期：** 2026-05-13

## 摘要

Sub2API是一个开源AI API网关平台，统一管理Claude、OpenAI、Gemini等多平台订阅账号，提供标准API接口。核心功能包括OAuth账号管理、Token自动刷新、智能调度、多维限流、Token级异步计费，并内置支付宝/微信/Stripe支付系统，支持SaaS模式和简易模式部署。技术栈为Go + Vue 3 + PostgreSQL + Redis。
