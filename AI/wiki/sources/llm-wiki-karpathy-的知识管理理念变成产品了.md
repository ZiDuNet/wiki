# LLM Wiki：Karpathy的知识管理理念变成产品了，文档扔进去自动长出Wiki

**Source:** blue桃之夭夭
**Category:** LLM Wiki
**Date ingested:** 2026-05-10
**Type:** article

## Summary

介绍 LLM Wiki 开源产品，将 Karpathy 的知识管理理念落地。与传统 RAG 的本质区别：RAG 每次从零检索，LLM Wiki 增量式构建持久 Wiki，知识有积累有复利。GitHub 6400+ 星。

## Key Claims

- RAG 每次问答从零开始，没有积累；LLM Wiki 增量式构建，知识持续生长
- LLM Wiki 自动提取实体、概念、关系，生成相互链接的 Markdown 文件
- 支持 sources → entities → concepts → synthesis 四层结构
- Obsidian 作为 IDE，LLM 作为程序员，Wiki 作为代码库
- 开源不到一个月 GitHub 6400+ 星
