# AI帮我写专利交底书？这个716星技能做到了

> 从项目文档到可交付的技术交底书，AI全自动完成——专利点挖掘、联网国知局查新、脱敏成文与自检闭环，一站式解决专利申请最头疼的文书工作。

## 核心信息

- **项目**: patent-disclosure-skill（中国专利.skill）
- **GitHub**: handsomestWei/patent-disclosure-skill
- **Star数**: 716 Star, 92 Fork
- **协议**: MIT 开源协议
- **规范**: AgentSkills 标准

## 七大核心能力

### 1. 项目智能扫描
- 按优先级自动读取文档和代码
- 自动把 `.docx` / `.pptx` 转成 Markdown 再扫描
- 不漏掉任何可能有专利价值的技术细节

### 2. 专利点挖掘
- 从项目材料里自动识别潜在专利申请点
- 与用户讨论、合并候选专利点
- 输出清晰的专利点分析结果

### 3. 国知局优先查新（关键特性）
1. **优先**爬取 CNIPA 专利公布公告站，精准获取对比专利文献
2. 如国知局站异常或无结果，自动降级到普通网络搜索（Google Scholar/Patents 等）
3. 检索结果自动写入交底书第一章
4. 专属爬虫工具 `cnipa_epub_search.py`

### 4. 标准化交底书生成
- 使用脱敏模板，避免信息泄露风险
- 自动生成 mermaid 格式系统架构图和流程图，渲染成 PNG 插入文档
- 默认输出 `.docx` 格式，专利代理人可直接编辑修改

### 5. 标准化交付命名
- 文件命名：`{案例名称}_{YYYYMMDDHHmmss}.md` + 同名 `.docx`
- 版本管理清清楚楚

### 6. 自动自检
- 检查逻辑闭环是否完整
- 检查公式和参数是否一致
- 检查其他常见疏漏

### 7. 多轮迭代支持
- 自动合并/修正已有交底书文件
- 生成独立的新版本文件
- 自动维护 `交底书修订对话记录.md`，所有修改痕迹可追溯

## 技术架构

```
patent-disclosure-skill/
├── SKILL.md              # 入口：触发条件、工具表、步骤与提示词映射
├── prompts/              # 分步模板（Agent 按步骤读取执行）
├── tools/                # 图示渲染、格式转换、国知局查新等工具集
├── examples/             # 示例原材料与交付物
├── outputs/              # 用户交付目录（已加入 .gitignore）
└── requirements.txt      # Python 依赖
```
