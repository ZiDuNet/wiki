## Summary

文章系统阐述 AI 进化的五个阶段（提示词 → 工具调用 → MCP → Agent → Skill）以及 Skill 作为数字员工体系基础的核心价值。Skill 是给 AI 颁发的"职业资格证书"，将专家经验从"人脑里的手艺"变成可调用、可检查、可复用的能力。核心机制是渐进式披露（三层按需加载），使 AI 同时具备数十种专业能力却不因"能力太多"而迟钝。Skill 管理体系即数字员工的组织管理，包括个人 Skill 库（全局级/项目级）和团队 Skill 库（版本控制 + 新员工快速上手 + 经验永不流失）。

## Key Claims

1. **AI 进化五级台阶**：提示词（一次性、不稳定、被动）→ 工具调用（AI 能操作外部世界）→ MCP（工具连接统一标准，AI 时代"USB 接口"）→ Agent（自主规划+记忆+工具，有不稳定/缺私有知识/博而不精问题）→ Skill（标准化+私有知识化+专业化，解决前三者问题）。
2. **Skill 三重价值**：标准化（质检清单式执行确保质量一致）、私有知识化（公司制度/个人偏好封装进 Skill，AI 像熟悉公司惯例的老员工）、专业化（资深专家经验可打包/传递/复用）。
3. **Skill 完整结构**：SKILL.md（必须，岗位说明书）+ references/（知识库，存放规范/样例/模板）+ scripts/（工具箱，弥补 AI 精确计算短板）+ assets/（素材库，Logo/模板/签名档）。
4. **渐进式披露机制**：第一层元数据（名称+描述，AI 启动时加载）→ 第二层 SKILL.md（用户提出相关任务时加载）→ 第三层 references/scripts（执行过程中按需加载）；类比：任务来了再翻对应章节。
5. **三种 Skill 创建方法**：手工写（文本编辑器创建文件夹和 SKILL.md）→ AI 帮生成（描述需求，AI 自动生成完整 SKILL.md）→ 对话萃取法（AI 像顾问一样采访专家，将隐性知识变显性规则）。
6. **Skill 的三级约束**：轻量约束（提示词指令，有灵活度）→ 中度约束（模板填充，格式固定）→ 强力约束（程序脚本，完全精确）；聪明 Skill 合理搭配三种约束。
7. **数字员工团队管理**：个人 Skill 库（全局级通用/项目级专属）；团队 Skill 库（最佳实践沉淀 + 新员工快速上手 + 离职经验不流失 = 数字化知识资产）；版本控制（Git 管理）。
