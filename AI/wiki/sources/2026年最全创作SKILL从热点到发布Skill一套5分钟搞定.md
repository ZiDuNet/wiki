## Summary

文章系统性介绍 AI 原生内容创作全流程技能包，覆盖从热点采集、选题搭建、文章写作、视觉排版到一键发布的 5 个核心环节。核心观点：2026 年进入 AI 原生阶段，关键不是"AI 能不能帮我写"，而是"用一套系统化的 Skill 让 AI 覆盖从热点到发布的全流程"。全套技能来自 ClawHub（OpenClaw 官方技能注册中心，13,700+ 技能）和 SkillHub（跨 Agent 技能聚合平台，87,100+ 技能）。效果目标：产出一篇内容的时间从 4 小时压缩到 1 小时，自动化后降至 5 分钟。

## Key Claims

1. **信息收集三角套件**：last30days-skill（30 天跨平台深度研究，覆盖 Reddit/X/YouTube/TikTok/Hacker News/Polymarket 等 12+ 平台）→ nicepkg/openclaw（中文热搜聚合，覆盖抖音/微博/百度/B站/快手，无需 API Key）→ agent-browser（AI 优化无头浏览器，支持批量采集）；三组合计约 20 分钟，传统方式需 1-2 小时。
2. **选题分析**：self-improving-agent（ClawHub 热榜第一，397k+ 安装）利用自我反思+结构化分析能力，可持续学习优化选题建议；配合 last30days 数据可生成含热度/竞争度/内容缺口的选题评估表格。
3. **文章写作**：baoyu-format-markdown（Markdown 格式化）和 baoyu-translate（多语言翻译），遵循"框架先行→素材填充→初稿生成→人工精修"人机协作流程，AI 负责框架/事实/初稿/润色，人负责核心观点/独特角度/事实审核/调性把控。
4. **视觉排版四工具**：Nano Banana Pro（AI 图片生成，ClawHub 348 star，88k+ 安装）→ SuperDesign（专业 UI/视觉设计指南）→ Image Cog（多模型图像生成与编辑）→ Visual Note Card（中文信息图卡片，生成 HTML 信息图，支持 PNG 导出）。
5. **发布分发**：wechat-md-publisher-skill、Social Media Agent、Weibo Browser Ops、PowerPost 等支持多平台自动发布。
6. **ClawHub 技能平台**：OpenClaw 官方技能注册中心，13,700+ 技能，支持语义搜索、版本管理、社区评分；安装命令 `npx clawhub@latest install`。
