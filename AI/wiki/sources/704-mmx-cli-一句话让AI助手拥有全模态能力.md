# mmx-cli: 一句话让AI助手拥有全模态能力

mmx-cli是MiniMax官方推出的命令行工具，为AI Agent助手提供全模态能力支持。核心功能：视频生成（Hailuo 2.3）、音乐生成（Music 2.6）、图片生成（Image 01）、语音合成（Speech 2.8）、文本对话、视觉理解、网络检索。安装三步：npm install -g mmx-cli → mmx auth login --api-key → npx skills add MiniMax-AI/cli。兼容OpenClaw、Claude Code、Cursor等主流Agent平台，通过SKILL机制实现零代码集成。
