# Vibe Coding 实战，我用半天时间做了个会议助手

**分类：** Vibe Coding
**日期：** 2026-05-13

## 摘要

作者使用Claude Code配合阶跃星辰（Step Plan）的服务，在半天内开发了一个本地会议助手应用。该应用可将会议录音自动转写为文本、识别不同发言人、用AI分析会议要点和待办事项，支持长达78分钟的录音处理，API成本极低（约0.135元/40分钟）。技术栈包括Next.js、TypeScript、Tailwind CSS、SQLite及Step Plan的ASR和LLM服务。
