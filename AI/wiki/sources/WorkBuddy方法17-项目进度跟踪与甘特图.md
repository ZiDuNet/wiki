# WorkBuddy方法17：项目进度跟踪与甘特图

**来源：** WorkBuddy/智能进化Wayen
**摄入日期：** 2026-05-26
**类型：** 方法指南

## 摘要

WorkBuddy 方法17 介绍如何用一句话 Prompt 自动生成甘特图和项目进度报告。核心功能包括自动生成甘特图、标识延期任务（红色）、标识即将到期任务（黄色）、计算整体完成百分比、列出关键任务。进阶用法支持多项目组合管理、资源冲突检测、风险预警。

## 核心观点

- **痛点分析**：状态更新慢、延期难发现、汇报费时、资源协调难——核心是跟踪工具落后
- **解决方案**：指定项目数据文件，AI 自动生成甘特图、标识风险、输出报告
- **核心 Prompt**：读取项目进度表 Excel → 生成甘特图 + 进度报告 + 风险标识
- **进阶用法**：多项目组合管理、资源冲突检测（同一人任务重叠）、风险预警、里程碑达成
- **避坑指南**：数据及时更新、依赖关系明确标注、发现延期后及时调整

## 提及实体

- [[WorkBuddy]] — 腾讯云 CodeBuddy 团队推出的 AI Agent 办公工具

## 涉及概念

- [[甘特图自动生成]] — 用 Prompt 驱动 AI 自动生成甘特图，标识延期和即将到期任务
- [[项目进度跟踪]] — AI 自动计算完成百分比、列出关键任务、生成进度报告
- [[Prompt驱动工作流]] — 用结构化 Prompt 让 AI 执行完整项目管理任务
- [[多项目组合管理]] — AI 同时跟踪多个项目，检测资源冲突，生成组合报告

## 实操要点

**基础数据字段**：任务名称、开始日期、结束日期、状态、负责人、依赖任务

**核心 Prompt 模板**：
```
请读取"[文件路径]/[项目进度表].xlsx"，生成项目进度报告：
【要求】
1. 自动生成甘特图
2. 标识延期任务（红色）
3. 标识即将到期任务（黄色）
4. 计算整体完成百分比
5. 列出本周需关注的关键任务
```

**效果**：周会准备时间从 2 小时降到 10 分钟
