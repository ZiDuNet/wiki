# NAS 赚外快啦！5个 Agent 自动生成「百万小说」，极空间部署 InkOS

> 来源: [极空间私有云](https://mp.weixin.qq.com/s?__biz=MjM5OTM5NTEzNw==&mid=2247571876&idx=1&sn=a0486f87b3d55431416186cf2a501608) | 2026-05-12

## 摘要

本文介绍如何在极空间私有云（NAS）上通过 Docker 部署 InkOS——一个利用 5 个 Agent 协同工作生成百万字小说的 AI 流水线工具。适合持有 GLM、KIMI、MiniMax、GPT 等 Coding Plan 且 Token 用不完的用户，将闲置 Token 转化为创意内容产出。

### 核心要点

- **InkOS** 是一款 L站 发起的多 Agent AI 小说生成工具
- 5 个 Agent（雷达、建筑师、写手、审计员、修订者）组成完整写作流水线
- 支持同人创作（Canon/AU/OOC/CP），可导出番茄小说格式
- 通过 Docker 部署在极空间 NAS 上，消耗多余 Token
- 支持多模型路由：高级模型负责架构/书写，低价模型处理埋线/剧情梳理

## 五大 Agent 分工

| Agent | 职责 |
|---|---|
| 雷达 | 市场选题雷达，扫描番茄排行榜热门题材 |
| 建筑师 | 构建世界观、人物卡、剧情卡等底层架构 |
| 写手 | 核心内容生成，约 3000 字/章节 |
| 审计员 | 审查内容质量和一致性 |
| 修订者 | 最终修订润色 |

## 系统核心功能

- **题材管理**：内置主题规范（章节定义、疲劳词、节奏、规则）
- **文风提炼**：可导入成熟作品，提炼为文风规则复用
- **续写/改写**：章节续写、母本续写、同人创作
- **伏笔池**：跟踪埋线剧情，随章节更新
- **支线/感情线**：梳理分支剧情与人物情感
