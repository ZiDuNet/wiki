# WeChat Radar：群聊情报看板

> 📎 来源: [人工智能AI和AI智能体研究会](https://mp.weixin.qq.com/s?__biz=MzY0MDg3NzI0Mg==&mid=2247484935&idx=1&sn=0b3318fc4ed5ce5915ff820ae3133da7)

## 核心命题

解决"群太多、真正有用的消息被淹没"问题。不让你翻聊天记录，直接给你一张"今日简报"。

## 四大核心能力

### 1. 话题雷达（跨群聚合）

多个群在同一天聊同一个东西，不用一个一个点开才知道。话题雷达把同一天的热门话题收在一起，看一眼就知道今天圈子里在讨论什么。

### 2. 链接情报（去重整理）

技术群、开源群每天被丢进来的链接太多，同一个好工具可能被不同人往不同群里扔了七八遍。自动把文章、GitHub 链接、小工具链接去重，整理出可读标题。

### 3. 群日报（一键摘要）

把当天群聊内容做一键摘要，可以复制出来丢给 ChatGPT、Claude、Kimi 等 AI，让 AI 帮你写大纲、列工具试用清单、甚至直接生成周报。

### 4. 本地存储（隐私安全）

所有数据在电脑的 `~/.wechat-radar/` 目录下，用 SQLite，默认不上传云端。谁聊了什么、哪些话题热、哪个群最活跃，全在你自己的硬盘上。

## 界面特点

- 奶白色界面，深色模式支持
- 情报驾驶舱：活跃群数、总消息数、文章链接、工具链接、@ 我、高信号人物一屏全收
- "今日优先看"分区，把最值得看的内容顶上来

## 安装与使用

```bash
git clone https://github.com/[项目地址]
```

编辑 `config.yaml`，填上微信数据路径和想监控的群名。

**Demo 模式**：设环境变量 `WECHAT_RADAR_DEMO=1`，先用模拟数据看界面长什么样。

跑起来后，浏览器打开本地 **7860 端口**，情报看板就在那儿等你。

## 项目状态

- 2025年5月24号刚开源
- 连续更新多版，已能完整跑通

## 核心价值

**以前**：靠运气和眼力，刚好在某个时间点点进去，刚好看到那条消息才算没白过。

**现在**：WeChat Radar 替你看，看完给你一张纸。花五分钟扫一眼，再用两分钟丢给 AI 处理，一天群聊里真正有价值的东西就到手了。
