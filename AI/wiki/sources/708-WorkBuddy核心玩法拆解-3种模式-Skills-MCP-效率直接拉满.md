# WorkBuddy核心玩法拆解：3种模式+Skills+MCP，效率直接拉满

WorkBuddy三大核心系统深度拆解：1) 三种工作模式——Craft（直接执行，目标明确时用）、Plan（先规划再执行，适合复杂任务）、Ask（只问不动，省积分更安全）；2) Skills技能系统——预置+自定义Skill扩展AI能力边界；3) MCP协议——标准化工具调用接口，连接外部工具链。选对模式是高效使用WorkBuddy的第一步，三者协同构成完整的AI办公自动化体系。
