# Obsidian使用必备：如何将PDF、DOCX、XLSX文档批量转为Markdown？

**Source:** YC思维与学习
**Category:** Obsidian
**Date ingested:** 2026-05-10
**Type:** article

## Summary

推荐四款文档转 Markdown 工具，解决 Obsidian 知识管理中 PDF/Word/Excel 导入难题。覆盖不同场景：通用转换、学术 PDF、OCR 识别、零代码图形界面。

## Key Claims

- **MarkItDown**：微软开源，格式覆盖最广（PDF/DOCX/XLSX/PPT/HTML 等），`pip install 'markitdown[all]'` 一行安装
- **Marker**：专注学术 PDF，精准处理公式、表格、代码块，但不支持 DOCX/XLSX
- **RapidOCR**：轻量级 OCR，去掉了 PaddlePaddle 依赖，用 ONNX Runtime，适合扫描件
- **核烁工具**：国产图形界面方案，零代码批量处理
- MarkItDown + RapidOCR 可组合使用：先 OCR 扫描件再统一转 Markdown
