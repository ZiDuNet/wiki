# 告别AI失忆！OpenClaw+Obsidian搭自媒体记忆宫殿，新手也能上手

## Summary

一篇面向自媒体从业者的实操教程，手把手教读者用 [[OpenClaw]] + [[Obsidian]] 搭建"第二大脑"，解决 AI 工具"失忆"问题。教程分为四步：搭建 Obsidian 知识仓库、打通 OpenClaw 与 Obsidian 的双向联动、定制专属爆款分析技能、设置记忆触发机制。

## Key Claims

- AI 失忆是自媒体从业者最大的痛点：聊完干货转头就忘，灵感素材散落各处
- OpenClaw 可通过 CLI 指令安装 Obsidian 技能，实现双向联动
- x-reader 技能支持微信公众号、小红书、B站、YouTube 等主流平台内容抓取
- 可创建 wechat-article-analyzer 技能实现微信文章自动化分析全流程
- 在 AGENTS.md 中添加记忆触发规则，OpenClaw 可自动检索知识库内容
- 后续可打通 Claude Code + OpenClaw + Obsidian 实现多工具联动
