# 10.6k Star！guizang-ppt-skill：让AI直接输出可演示 HTML 页面

## 摘要

guizang-ppt-skill 是一款让 AI Agent 直接生成横向翻页 HTML 演示稿的 Skill。不到一个月 GitHub 冲至 10.6k Star，提出"约束设计"方法论——通过固定风格系统、具名版式、锚点色、校验脚本让 AI 稳定产出高质量 PPT，而非依赖模型当场发挥。

## 核心洞察

### HTML PPT 为什么更适合 AI

AI Agent 最擅长处理文本、代码、文件。HTML/CSS 本身就是文本，AI 可以直接读、改、校验、预览。结构透明：标题在哪、图片在哪、布局是哪种、样式怎么写——全部可被 AI 读出。

### 约束设计方法论

guizang-ppt-skill 不靠"审美好一点"这种模糊要求，而靠：
- 固定风格（电子杂志风 or 瑞士国际主义）
- 固定版式（22 个具名版式 S01-S22）
- 固定锚点色（克莱因蓝、柠檬黄、柠檬绿、安全橙）
- 固定图片槽位
- 固定校验脚本

**普通提示词靠模型当场发挥。高质量 Skill 把可重复的东西写进结构里。**

## 两套视觉系统

### Style A：电子杂志 x 电子墨水
适合观点表达、个人分享、叙事型演讲。

### Style B：瑞士国际主义
适合事实表达、产品分析、方法论、数据页、项目汇报。网格、直角、1px 发丝线、高饱和锚点色、极致字号对比。

## 适合人群

1. **经常做分享的人**：线下分享、产品发布、demo day，先让 AI 产初稿再微调
2. **经常整理长资料的人**：长文章拆成 6-10 页演示稿，更易传播
3. **想研究高质量 Skill 的 AI 用户**：学习 Skill 如何做成"系统"

## 不适合场景

- 大段表格数据
- 培训课件（信息密度可能不够）
- 需要多人反复协作编辑的传统 PPT 流程
