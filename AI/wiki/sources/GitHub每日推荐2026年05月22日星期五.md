## Summary

每日 AI 热点聚焦：提示工程、LLM 应用与 MCP 服务的生态爆发。本日推荐三个 GitHub 项目：f/prompts.chat（提示词共享平台，162k stars）、Shubhamsaboo/awesome-llm-apps（LLM 应用集合，111k stars）、punkpeye/awesome-mcp-servers（MCP 服务器资源集合，87k stars）。

## Key Claims

1. **f/prompts.chat**（⭐162,660）：原名 Awesome ChatGPT Prompts，社区驱动的提示词共享平台，支持上传/浏览/收藏，覆盖 ChatGPT、Claude、Gemini 等主流模型；纯 HTML 无后端，可免费自托管；适合企业场景注重数据隐私的场景。局限：纯静态列表，缺乏动态交互与质量评估机制。
2. **Shubhamsaboo/awesome-llm-apps**（⭐111,394）：汇集 100+ 可直接运行的 AI Agent 与 RAG 应用，基于 Python 构建，主打"克隆、定制、部署"极简流程，覆盖聊天机器人到多智能体协作系统；适合希望快速上手 AI 应用开发、学习 Agent 与 RAG 最佳实践的 Python 开发者。局限：部分应用依赖外部 API，快速上手可能遇到依赖兼容性问题。
3. **punkpeye/awesome-mcp-servers**（⭐87,344）：精心整理的 MCP（Model Context Protocol）服务器资源集合，降低 MCP 协议学习与落地门槛，适合正在探索 MCP 协议或需要构建 AI 服务端组件的开发者。局限：纯列表式仓库，缺乏对服务器质量、维护状态的评估机制。
