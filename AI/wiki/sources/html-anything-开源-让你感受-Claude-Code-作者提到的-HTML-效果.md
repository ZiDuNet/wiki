# html-anything 开源！让你感受 Claude Code 作者提到的 HTML 效果！

> 来源: 开源星探 | 2026-05-19

## 核心摘要

Anthropic 的 Claude Code 团队宣布内部文档不再写 Markdown，改写 HTML，理由是"Markdown 是写给写作者看的，HTML 才是给读者看的"。html-anything 是 nexu-io 团队发布的开源 HTML 编辑器，让 AI Agent 帮你把任何内容转换为世界级设计水准的 HTML，15000 行代码，支持 75 套 Skill 模板，自动识别 18 种 Code Agent CLI，零 API Key 成本。

## 核心亮点

1. **75 套 Skill 模板，覆盖 9 种交付形态**：杂志文章、Keynote 演示、简历、海报、小红书卡片、推文卡片、Web 原型、数据报告、Hyperframes 视频
2. **自动识别 18 种 Code Agent**：Claude Code、Cursor Agent、OpenAI Codex、Gemini CLI、GitHub Copilot CLI、OpenCode、Qwen Coder、Aider 等，零 API Key，复用已有登录会话
3. **一键发布多平台**：微信公众号（CSS 内联）、X/微博/小红书（高 DPI PNG）、知乎（LaTeX 处理）

## 设计约束

每个 Skill 都有严格约束：CJK 优先字体栈、8px 基线网格、对比度 ≥ 4.5、使用真实数据。
