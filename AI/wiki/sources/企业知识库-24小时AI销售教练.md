# 企业知识库 + AI 销售教练：零售培训完整落地

**来源：** 把企业知识库做成24小时在线销售教练.md
**摄入日期：** 2026-05-30
**类型：** 文章
**公众号：** 销售部落Sales+

## 摘要

演示案例：基于企业私域知识库，搭"AI 销售教练"。不是只回答问题，而是把资料查询、话术训练、录音质检、随机考核串成闭环。工具组合：腾讯乐享知识库 + Codex/Claude Code/WorkBuddy/Cursor 等 Agent 工具。水果连锁门店为演示行业。知识库是企业的"业务底座"——模型会换工具会变，但企业自己的客户问题、成交经验不会凭空长出来。

## 核心观点

### AI 销售教练四类能力
1. **随问随查**：Agent 从本地知识库找答案，不凭空编通用话术
2. **自动出题**：根据知识库内容随机出题，逐题考核，指出遗漏卖点/流程动作
3. **模拟客户对练**：Agent 扮演不同类型客户（挑剔/犹豫/预算有限/注重品质），对话后复盘评分
4. **录音质检**：Agent 对照知识库标准流程和服务礼仪，给评分 + 问题定位 + 可替换话术

### 知识库工具链
- **知识库**：腾讯乐享知识库
- **Agent 工具**：Codex、Claude Code、WorkBuddy、Cursor 等
- **接入方式**：微信扫码 / 乐享 Skill / WorkBuddy/Claude Code/Codex/Cursor

### 从 0 到 1 搭建步骤
1. 整理销售素材（服务礼仪、产品卖点、常见异议、会员推荐、售后提醒）
2. 在腾讯乐享创建知识库，导入存量资料
3. 通过 MCP 连接到 Agent 工具
4. 搭四类 Agent（质检/客户模拟/技能考核/随问随查）
5. 发布到微信/飞书/钉钉

### 场景一：销售质检 Agent
- 对照企业标准流程（迎宾→破冰→需求判断→产品推荐→价值说明→异议处理→促成→送宾）
- 三维度打分：服务礼仪 / 销售流程执行 / 话术与异议处理
- 输出：总分 + 分项评分 + 话术优化表 + 知识库建议

### 场景二：客户模拟 Agent
- 扮演挑剔/犹豫/预算有限/注重品质/多家比价型客户
- 情绪值系统（初始50，满分100）
- 第二阶段：检索知识库给出复盘报告

### 场景三：销售技能考核 Agent
- 随机生成5道题，逐题提问判卷
- 每次只发一道题，等待作答后再下一题
- 考核结束输出：总分 + 知识盲区 + 建议复习文档链接

### 知识库价值再发现
- 知识库不是资料仓库，是企业训练 AI 的"业务底座"
- 销冠经验沉淀进知识库 → Agent 质检/陪练/出题时传给更多销售
- 企业培训最怕经验只留在少数人脑子里
