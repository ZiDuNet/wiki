# DouYin_Spider：抖音逆向与爬虫实战

**来源：** DouYin_Spider：抖音逆向与爬虫实战.md
**摄入日期：** 2026-05-29
**类型：** 项目介绍

## 摘要

介绍 [[DouYin_Spider]]（cv-cat版）开源抖音逆向与爬虫项目，封装抖音全部API接口，支持直播间监听、用户信息抓取、视频数据提取、逆向分析等功能。

## 核心内容

- 抖音全部API接口封装：登录、用户信息、视频列表、评论等
- 直播间监听：实时弹幕、礼物、点赞数据
- 用户信息抓取：昵称、粉丝数、关注数
- 视频数据提取：播放量、点赞数、评论数、分享数
- 逆向分析：参数构造、签名算法（供学习研究）
- 安装方式：git clone + pip install
- 配置方式：config.py 填写手机号和验证码
