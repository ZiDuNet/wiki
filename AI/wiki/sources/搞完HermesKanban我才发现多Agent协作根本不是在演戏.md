# 搞完 Hermes Kanban 我才发现，多 Agent 协作根本不是在演戏

> 来源: Hermes实践派 | 日期: 2026-05-13

## 摘要

作者实操Hermes Kanban多Agent协作功能，发现多Agent分工比单Agent有本质优势。Kanban模式让任务流转清晰可见，Agent角色分工明确，避免上下文污染。

## 核心要点

- Hermes Kanban：看板视图管理多Agent任务
- 角色分工：主Agent负责任务分配，子Agent执行具体工作
- 上下文隔离：避免单会话上下文膨胀
- 任务流转：TODO → IN PROGRESS → DONE
- 适用场景：内容生产、代码开发、多步骤复杂任务
