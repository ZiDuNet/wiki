# LangGraph、OpenClaw、Hermes：三种 Agent 路线，不是一回事

**Source:** 厚国兄
**Category:** OpenClaw
**Date ingested:** 2026-05-10
**Type:** analysis

## Summary

系统对比三种 Agent 路线的本质区别：LangGraph 是底层编排框架（让 Agent 有结构），OpenClaw 是个人助手入口（让 Agent 能使用），Hermes 是自进化运行时（让 Agent 会成长）。三者不是竞争关系，而是不同层面。

## Key Claims

- LangGraph = 底层编排骨架，定义 Agent 的执行流程和状态管理
- OpenClaw = 个人助手入口，让 AI 通过多渠道（飞书/微信/Telegram）触达用户
- Hermes = 自进化运行时，Agent 通过 Skill 和记忆系统持续成长
- 常见误区：把 LangGraph 当产品、把 OpenClaw 当框架
- 三者互补，不是替代关系
