# 让你的 Hermes Agent 发挥更大的价值

**来源：** Hermes/i龙虾
**摄入日期：** 2026-05-26
**类型：** 使用指南

## 摘要

文章介绍 Hermes Agent 的五个真正发挥价值的用法：/goal 命令配合元提示、看板工作流、竞品技术拆解、记忆 Wiki、每日主动学习。核心思想是设计一套让 Agent 持续工作的流程，而不是把它当成高级搜索框。

## 核心观点

### 一、/goal 命令的正确用法

> **不要自己写提示，让 AI 帮你优化提示，再给 /goal**

流程：
1. 开普通对话，描述想做的事
2. 让 AI 生成适合 /goal 的详细提示词
3. 拿到提示复制进 /goal

/goal 设计逻辑：执行长时间运行任务（跑过 10+ 小时），前提是足够好的目标描述。

### 二、看板工作流（被严重低估）

```bash
hermes dashboard  # 打开仪表盘 → Kanban
```

**晨间工作流**：
- 每早列出今日要做的事
- 把 Hermes 能做的全部丢进看板
- 去做人工处理的事
- 回来时看板任务已跑完或完成

区别：普通任务管理提醒你去做，这个看板是真的把任务给做了。

### 三、竞品技术拆解

Prompt：
```
对该网站进行完整的技术调研和拆解：
- 使用了哪些技术栈？
- 有哪些核心功能？
- 前端框架是什么？
- 使用了哪些第三方服务和 API？
- 付费功能的定价逻辑是什么？
- 哪些功能值得参考？
最后整理成 Markdown 报告。
```

Hermes 自己打开浏览器，点来点去，看控制台，分析网络请求，输出完整报告。

### 四、记忆 Wiki

让 Hermes 搭建本地网站，把每次对话主题、工作、想法分类整理。

提示词：
```
这个网站应该包含：
1. 我们讨论过的所有主题列表，可以点击查看详情
2. 每日工作日志，记录每天我们一起完成了什么
3. 每个条目都应该有对话记录和工作摘要
请帮我把这个站点构建出来。
```

价值：自动维护的工作日记 + Agent 带上下文工作。

### 五、每日主动学习

定时任务：每天早 9 点主动问「你今天最重要的一件事是什么？」

然后：
1. 列出能帮你做的相关任务
2. 更新对你的记忆（做什么项目、关注什么）

**积累效应**：三个月后 Agent 知道你的项目、节奏、瓶颈。
