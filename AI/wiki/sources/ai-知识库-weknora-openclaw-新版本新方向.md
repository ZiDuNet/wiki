# AI 知识库 WeKnora + OpenClaw：从新版本里，我看到了知识库的新方向

**Source:** 畅说AI科技
**Category:** OpenClaw
**Date ingested:** 2026-05-10
**Type:** article

## Summary

分析 WeKnora 新版本的多方向整合：RAG 问答、ReAct Agent、MCP 工具、Wiki 模式、知识图谱、多源同步、Langfuse 可观测性、私有化部署。认为知识库正在从"上传文档问答"向综合 AI 工作台演进。

## Key Claims

- WeKnora 不再是简单的"上传文档问答"知识库
- 新版同时整合 RAG、ReAct Agent、MCP、Wiki、知识图谱等能力
- 知识图谱让知识有结构，不是平铺的文档
- MCP 工具让 Agent 能调用外部能力
- Langfuse 提供可观测性，追踪 Agent 决策过程
