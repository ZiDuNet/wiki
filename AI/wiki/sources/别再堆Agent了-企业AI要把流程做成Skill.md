## Summary

文章核心观点：企业 AI 的瓶颈不是 Agent 不够多，而是核心流程没有 Skill 化。Skill 是"可复用工作的运行说明书"，不是"更长的提示词"。一个完整 Skill 包包含：SKILL.md（入口）+ examples（样例）+ references（方法论）+ scripts（脚本）+ assets（素材）+ checklist（验收清单）。企业应从主流程（销售/采购/财务/研发/流程诊断）而非边角活（周报/邮件）入手做 Skill。

## Key Claims

1. **Skill 不是提示词**：提示词解决"这次怎么回答"，Skill 解决"以后同类工作能否按同一方法稳定执行"
2. **企业瓶颈在 Skill 而非 Agent**：今天搭 Agent 门槛不高，但能否进入业务流取决于背后有没有可执行方法
3. **Skill 三层能力**：调度入口（name/description）+ 渐进加载（references/scripts/assets）+ 质量验收（checklist）
4. **description 关键**：需回答三件事——处理什么输入、生成什么结果、什么话触发
5. **主流程优先于边角活**：销售线索转化/采购评审/财务风险控制/研发评审才是核心价值
6. **Skill 如小产品**：需要版本、样例、缺陷记录、评测标准、稳定输出要求
