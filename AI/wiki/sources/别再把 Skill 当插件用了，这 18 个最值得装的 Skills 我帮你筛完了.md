# 别再把 Skill 当插件用了，这 18 个最值得装的 Skills 我帮你筛完了

> 来源: [单向箔](https://mp.weixin.qq.com/s?__biz=Mzg4MDY0Mzg3OQ==&mid=2247483891&idx=1&sn=03322251430564a48c2be1e084bf7146&chksm=cec84b1c55ea2460dd04397aeaa0f2a9a7ea631bc957d56afa74402dffabde815bb9c984b72e) | 2026-05-13

## 摘要

Skill是给AI装的"外挂"，本质上是一个放了SKILL.md文件的文件夹。本文筛选出18个最实用的Skills，分为四大类：搜索增强、AI能力增强、开发工具、外部工具联动、管理Skills。

核心推荐：Multi Search Engine（集成17个搜索引擎的搜索类Skill，必装）、Self-Improving（分层记忆系统，长期投资越用越懂你）、taste-skill（前端颜值救星，让AI生成的前端界面不再是千篇一律）、Skill Vetter（安全审查Skill，装任何Skill之前先过一遍）。其他重要Skill包括：GitHub（开发者必装）、Obsidian（Obsidian用户必装）、Openai Whisper（本地语音转文字）、humanizer-zh（修复AI写作特征）等。建议从Skill Vetter、Multi Search Engine、Self-Improving、taste-skill这四个开始安装。
