**Source:** 布鲁斯AI
**Category:** Hermes
**Date ingested:** 2026-05-10
**Type:** tutorial

## Summary

详解 Hermes Agent 生态核心创意技能 HyperFrames：用 HTML/CSS/JS/GSAP 作为视频唯一可信源，逐帧捕获页面内容，FFmpeg 编码输出 MP4/WebM 视频。由 HeyGen 开发、Apache-2.0 开源。

## Key Claims

- HyperFrames = HTML 作为视频工程文件，逐帧渲染 → FFmpeg 编码 → MP4 输出
- 一行核心命令启动：hermes + HyperFrames Skill
- 支持：电影级动态标题卡、同步字幕口播视频、音频卡点动效、产品宣传片
- 前端开发者零学习成本，直接用 HTML/CSS/JS/GSAP 技术栈
- 确定性、无损、可复现——不像录屏有画质损失
