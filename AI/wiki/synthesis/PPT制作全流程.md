# PPT 制作全流程

## 概述

AI 做 PPT 在 2026 年已经不是"能不能"的问题，而是"怎么做好"的问题。全球 AI 演示文稿市场已跨过 47 亿美元，企业采用率突破 60%。但大多数人用 AI 做 PPT 的方式，从根上就是错的。本文综合 20+ 篇源文章，系统梳理 AI PPT 的工具生态、方法论和最佳实践。

## 一、核心认知：先破一个幻觉

### 1.1 AI 做 PPT 不等于一键生成

现实：AI 确实能在 45-60 秒内生成 10 页不错的初稿。但如果直接交出去，大概率得到的是领导一句"这是 AI 生成的吧？重做。"

AI 做PPT真正消灭的是"排版税"——对齐、配色、找素材的体力活。但 AI 消灭不了的是：**你的 PPT 到底要说什么，说给谁听，想让对方做什么决定。**

### 1.2 正确的定位

把 AI 理解成一个**极其高效但没有判断力的助手**。你负责方向，它负责执行。它负责出稿，你负责品控。

### 1.3 关键原则

PPT 不是从打开软件开始的。PPT 是从想清楚三个问题开始的：
1. 给谁看？
2. 要达成什么目标？
3. 在什么场景下播放？

## 三、Skill 方案深度评测

### 3.1 四大推荐 Skill

**1. guizang-ppt-skill（HTML PPT）**

- 输出：单文件 HTML，横向翻页
- 亮点：WebGL 流体背景，Apple 发布会质感
- 配色：5 套预设（墨水经典、靛蓝瓷、森林墨、牛皮纸、沙丘）
- 适合：技术发布会、个人分享
- 缺点：HTML 格式，不能在 PowerPoint 中编辑

**2. huashu-design（花叔）**

- 亮点：Tweaks 系统实时调参，不用重新生成
- 特色：HTML 动画导出 MP4/GIF（25fps + 60fps 插帧）
- 设计方向顾问：5 个流派 x 20 种设计哲学
- 适合：交互原型、设计变体探索
- 缺点：需要 React 环境

**3. Kami-design**

- 风格：暖羊皮纸底色 + 墨水蓝点缀
- 覆盖：8 种文档类型（简历、白皮书、研报等）
- 图表：14 种图表原语，自动选类型
- 输出：WeasyPrint 高质量 PDF，印刷级别
- 适合：专业文档排版

**4. ppt-master（商务首选）**

- 核心：AI 多角色协作流水线
- 角色：Strategist -> Image_Generator -> Executor
- 8 步确认制：每步确认后再生成
- 输出：**原生 PPTX，完全可编辑**
- 适合：商务汇报、正式场合
- 内置 15 个完整项目、229 页高质量示例

### 3.2 html-ppt-skill

把 PPT 做成 HTML 网页的方案：
- 不用装 Office，Chrome 浏览器双击开讲
- 自带演讲者视图（S 键）
- 主题切换（T 键）
- 全屏（F 键）
- 总览（O 键）

安装：
```bash
npx skills add https://github.com/lewislulu/html-ppt-skill
```

## 四、PPT 制作方法论

### 4.1 正确的工作流

```
第一步：大模型搭逻辑骨架（策略师）
    -> 确定受众、目标、约束
    -> 生成逻辑大纲
第二步：PPT 工具生成视觉（排版师）
    -> 按大纲生成幻灯片
第三步：人工品控（你）
    -> 检查内容准确性
    -> 调整视觉细节
```

**关键**：大语言模型是"策略师"，PPT 工具是"排版师"。不要让排版师干策略师的活。

### 4.2 万能 Prompt 模板

```
你是一名资深商业演示策略顾问。我需要为[受众]准备一份关于[主题]的演示，
目标是让他们[做出什么决定]。请按照"背景—问题—洞察—方案—行动"的结构，
生成一份[10页]PPT的逻辑大纲，每页包含：
- 页面标题（用洞察式标题）
- 核心信息（一句话）
- 支撑证据类型
禁止使用"提高效率""推动创新"等通用措辞，每个论点必须用具体数据支撑。
```

### 4.3 初稿品控五步法

AI 出的初稿通常有五个通病，需要逐一修正：

1. **字太多**：每页只留一个核心信息，做减法
2. **逻辑浅**：补充具体数据和分析深度
3. **设计单调**：利用排版节奏（anchor/dense/breathing）
4. **废话多**：删除"提高效率"类通用措辞
5. **缺乏故事线**：建立背景-冲突-解决的叙事弧线

### 4.4 PPT Master 8 步确认制

1. 画布格式（16:9/4:3/小红书等）
2. 页数范围
3. 目标受众
4. 风格目标
5. 配色方案
6. 图标方案
7. 字体方案
8. 图片方案

每步确认后再生成，出来的质量确实不一样。
