# Claudian

**类型:** 实体 (插件/产品)
**提及文章数:** 1

## 简介

Claudian是Obsidian插件，把Claude Code搬进Obsidian，配合Skills实现知识的自动加工与持续进化。完整支持Claude Code的Skills，输入/即可看到可用命令和已注册Skills。支持内联编辑：选中一段文本，Claude可直接在原文中修改，无需复制粘贴。

## 核心特性

- 完整支持Claude Code Skills系统
- 内联编辑能力
- 本地化处理（隐私保障）
- 免费 Obsidian插件
- 可扩展Skills生态

## 四大优势

1. 成本低 — 免费 Obsidian插件
2. 本地化 — 隐私保障，数据不出本地
3. 可扩展 — Skills生态持续丰富
4. 知识激活 — 让知识真正被使用
