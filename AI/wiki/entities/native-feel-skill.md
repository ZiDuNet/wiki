# native-feel-skill

**类型:** 开源项目 / Agent Skill
**来源:** [[推荐 3 个 GitHub 上刚开源但实用的项目，收藏一波]]

## 简介

Agent Skill，专门教你怎么设计跨平台桌面应用，让它在 macOS 和 Windows 上运行时的体验跟原生应用几乎没有区别。

## 背景

Raycast 底层是 WebView + Node.js，但用起来丝滑得像原生应用。有人直接反编译了 Raycast Beta.app，把答案扒了出来。

## 作者

yetone，也是 avante.nvim 插件的作者。项目发布不到两天就在 GitHub 上拿到了 1000+ Stars。

## 使用场景

- 重构现有应用，使其更具原生感
- 从零开始开发跨平台原生体验应用

## 知识来源

- Raycast 团队公开的技术深度剖析文章
- 作者对 Raycast Beta v0.60.0 的逆向工程分析
