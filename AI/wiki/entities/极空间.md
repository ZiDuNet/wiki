# 极空间

> 极空间私有云（ZSpace），国内 NAS 厂商，提供 Docker 部署环境。

## 简介

极空间是国内私有云/NAS 厂商，其产品支持 Docker 部署，可运行 InkOS 等 AI 工具。用户可将闲置的 GLM、KIMI、MiniMax、GPT Coding Plan Token 通过 InkOS 转化为创意内容。
