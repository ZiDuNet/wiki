# Remotely Save

**类型:** 实体（工具/插件）
**提及文章数:** 1

## 简介

Remotely Save 是 Obsidian 社区非常成熟的同步插件，通过 [[WebDAV]] 协议实现多端同步。是目前国内用户综合体验最平衡的免费方案核心组件。

## 核心结构

```
Obsidian
    ↓
Remotely Save 插件
    ↓
WebDAV
    ↓
坚果云 / NAS / 私有服务器
```

## 特性

| 特性 | 说明 |
|---|---|
| 价格 | 插件免费（后端看选型） |
| 移动端支持 | ✅ 完整支持 |
| 冲突处理 | 中等 |
| 技术门槛 | 中等（需配置 WebDAV） |

## 推荐组合

### 最佳新手组合
**Remotely Save + 坚果云 WebDAV**

配置完成后，整体体验已非常接近官方 Obsidian Sync。

### NAS 用户升级组合
**Remotely Save + NAS WebDAV**

支持的 NAS 品牌：极空间、群晖、飞牛、威联通

优势：
- 数据完全在自己手里
- 局域网同步速度非常快
- 基本已是终极方案之一

## 优势

1. **免费**：插件本身免费，坚果云 WebDAV 也可免费使用（有流量限制）
2. **多端同步**：桌面端和移动端均支持
3. **国内速度快**：使用坚果云或 NAS，不受海外服务器影响
4. **数据自主**：数据存储在自己控制的平台
5. **技术门槛适中**：相比 Git，不需要太多技术基础

## 注意事项

⚠️ Remotely Save 是社区维护的第三方插件，存在开发者停止维护的可能。

建议：
- 关注插件更新动态
- 同时保留一份备用同步方案
