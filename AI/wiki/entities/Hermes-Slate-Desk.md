# Hermes Slate Desk

**类型:** 工具/产品
**前身:** Hermes Desktop Lite
**最新版本:** V2.0
**基于:** [[Hermes-Agent]], [[Electron]]

## 简介

Hermes Slate Desk（原Hermes Desktop Lite）V2.0将聊天客户端升级为真正的桌面工作台。定位：Hermes Agent的桌面控制台，不再只是聊天窗口。

## V2.0 核心变化

- **首页工作台**：系统状态 + 快捷入口
- **三栏布局**：导航 + 上下文 + 工作区
- **AI笔记核心化**：目录/Markdown/预览/导出
- **聊天直接操作笔记**：查询/读取/总结/创建/追加/移动
- **技能中心**：市场搜索安装更新
- **模型配置页** + 全局切换器
- **频道配置集中管理**
