# 政策法规监控 Skill

**类型:** Agent Skill
**来源文章:** [[政策法规监控 Skill：持续跟踪行业新规，把变化变成行动清单]]

## 简介

"持续监控 + 变化识别 + 影响分析 + 行动清单生成"的专用 Skill，面向业务团队而非律师，把合规变化转换为可执行清单。

## 核心机制（四层）

1. **信息源清单**：明确监控哪些官网公告、平台规则、行业通知、内部制度
2. **变化识别**：对比新旧文本，标出新增、删除、阈值变化和生效时间
3. **影响映射**：把文本变化映射到产品功能、运营流程、合同文案、客服话术、技术接口
4. **行动清单**：输出负责人、优先级、截止时间和复核状态

## 典型输出字段

| 字段 | 说明 |
|------|------|
| 政策变化摘要 | 关键变化内容提取 |
| 涉及业务模块 | 产品/运营/法务/技术受影响模块 |
| 风险等级 | 高/中/低 |
| 产品功能调整 | 具体改动项 |
| 技术侧行动项 | 研发执行清单 |
| 待确认事项 | 法务/运营需人工确认项 |
| 影响时间 | 建议完成节点 |

## 适用行业

- AI 硬件（数据采集、录音授权、模型调用备案）
- 跨境电商（商品资料、平台规则）
- 金融科技（监管政策）
- 教育工具（内容合规）
