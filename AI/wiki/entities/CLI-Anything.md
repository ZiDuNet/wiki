# CLI-Anything

**类型:** 开源项目
**Star:** 35.6K

## 简介

让所有软件原生支持 AI Agent 调用的 CLI 工具项目。通过标准化的 CLI 接口，使 AI Agent 能够直接调用任意软件的能力，输出结构化（JSON）、行为可靠（退出码）、可组合（管道）。

## 核心思想

- **CLI 优先**：如果一个软件有良好的 CLI，Agent 就能直接调用它
- **结构化输出**：通过 --output json 获取结构化响应
- **Unix 哲学延伸**：每个命令做一件事，做好它

## 关键意义

CLI-Anything 的 35.6K Star 印证了 **Agent-Native** 趋势：软件行业正在集体意识到，未来的用户不只是人类，还有 AI Agent。
