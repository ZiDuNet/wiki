# html-anything

**类型:** 实体 / 开源项目
**提及文章数:** 1

## 简介

html-anything 是 nexu-io 团队发布的开源 HTML 编辑器，专为 Agent 时代打造。15000 行代码，支持 75 套 Skill 模板，自动识别 18 种 Code Agent CLI，实现零 API Key 的多平台 HTML 内容生成与发布。

## 项目地址

https://github.com/nexu-io/html-anything

## 核心功能

- **75 套 Skill 模板**：覆盖杂志文章、Keynote 演示、简历、海报、小红书卡片、推文卡片、Web 原型、数据报告、Hyperframes 视频
- **18 种 Code Agent 自动识别**：Claude Code、Cursor Agent、OpenAI Codex、Gemini CLI、GitHub Copilot CLI、OpenCode、Qwen Coder、Aider 等
- **一键多平台发布**：微信公众号（CSS 内联）、X/微博/小红书（高 DPI PNG）、知乎（LaTeX 处理）
- **零 API Key**：复用已有登录会话，边际成本 $0
