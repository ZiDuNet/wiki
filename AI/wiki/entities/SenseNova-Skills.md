# SenseNova-Skills

商汤 SenseNova 模型配套的办公/多模态 Skills 集合。

## 功能

- 图像生成（infographic、imitate）
- PPT 生成（creative/standard 模式，支持 PDF/DOCX 输入）
- Excel 数据分析（大文件处理、清洗、可视化）
- 深度研究工具

## 适用场景

- 办公自动化、报告生成、数据可视化
- 结合 [[OpenClaw]]/[[Hermes]] 实现 Agent 端到端办公
