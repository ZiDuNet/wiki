## 简介

Affaan Mustafa 是 [[ECC]]（Everything Claude Code）项目的作者，预测市场聚合平台 Itô 的联合创始人，elizaOS 核心贡献者。2025年9月在 Anthropic × Forum Ventures 黑客松中夺冠，用 Claude Code 8 小时手搓出实时协作聊天平台 zenith.chat，奖金 $15,000。ECC 项目在 GitHub 达到 18.2万+ Stars，MIT 开源，集成 60 个专用 Agent、232 个 Skill、75 条命令、1282 种安全检查。
