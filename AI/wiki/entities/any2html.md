# any2html

**类型:** 实体 (Skill)
**作者:** 半大熊猫
**GitHub:** https://github.com/blockpanda/any2html

## 简介

专为 AI Agent 设计的高级前端排版 Skill，可将长文本、数据表格、文章链接转化为极具复古美感、视觉舒适、纯静态的高质量 HTML 信息卡片。适用于小红书、Twitter、公众号等平台的内容配图生成。

## 三种版本

| 版本 | 特点 | 适用场景 |
| --- | --- | --- |
| **竖版** | 多页排版，带精美页脚编号（01/03） | 小红书图文笔记滑动卡片 |
| **横版** | 无高度上限，内容在一张图里铺展 | 长文转超长逻辑信息图 |
| **插图版** | 极致克制，仅保留标题与核心金句 | 公众号/Notion 首图/封面图 |

## 安装命令

```bash
npx skills add blockpanda/any2html --skill any2html
```
