# guizang-ppt-skill

一款让 AI Agent 直接生成横向翻页 HTML 演示稿的 Skill。不到一个月 GitHub 冲至 10.6k Star。

## 基本信息

- **类型：** Skill / AI 工具
- **GitHub：** https://github.com/op7418/guizang-ppt-skill
- **Star：** 10.6k+
- **版本：** v1.1.0
- **安装方式：**
  ```bash
  npx skills add https://github.com/op7418/guizang-ppt-skill --skill guizang-ppt-skill
  # 或
  git clone https://github.com/op7418/guizang-ppt-skill.git ~/.claude/skills/guizang-ppt-skill
  ```

## 两套视觉系统

### Style A：电子杂志 x 电子墨水
适合观点表达、个人分享、叙事型演讲。

### Style B：瑞士国际主义
适合事实表达、产品分析、方法论、数据页、项目汇报。网格、直角、1px 发丝线、高饱和锚点色。

## 核心方法论：约束设计

22 个具名版式（S01-S22）+ 4 套锚点色 + 校验脚本 = 稳定产出。
