# 一人企业方法论

**类型:** 实体（方法论体系）
**作者:** 易仁永澄
**提及文章数:** 1

## 简介

《一人企业方法论³》是易仁永澄提出的一套系统化方法论，帮助个人将已有的能力重组成一个轻资产、可验证、可复用的个人业务。

## 核心框架

方法论将一人企业的搭建拆解为 **九步建盘**：

| 阶段 | 名字 | 功能 |
| --- | --- | --- |
| 01 | 资源盘点 | 按8类盘点手上有什么 |
| 02 | 利基定位 | "三环合一"找细分市场 |
| 03 | 价值主张 | 拆 Jobs / Pains / Gains |
| 04 | 商业模式 | Lean Canvas + 收费结构 |
| 06 | MVP设计 | 决定验证哪个假设 |
| 07 | 转化闭环 | 触达→承接→成交路径 |
| 08 | 资产沉淀 | 沉淀可复用资产 |
| 09 | 经营复盘 | 找瓶颈，定下周期重点 |

**设计原则**：01 → 07 严格线性，不跳步；08、09 按需触发。

## AI Skill 化

方糖团队将方法论封装为 **OPC 技能集**（9个 AI Agent Skill），使其成为可调用的流水线：

- `opc-orchestrator` — 总编排
- `opc-resource-audit` — 资源盘点
- `opc-niche-positioning` — 利基定位
- `opc-value-proposition` — 价值主张
- `opc-business-model-design` — 商业模式设计
- `opc-mvp-designer` — MVP设计
- `opc-conversion-loop` — 转化闭环
- `opc-asset-ops` — 资产沉淀
- `opc-dashboard-review` — 经营复盘

## 核心价值

1. **防止跳步**：AI 总编排会拦住常见的失败模式（跳过盘点直接定位）
2. **结构化输出**：每步产出文档（inventory.md、lean-canvas.md 等），作为下一步输入和复盘底稿
3. **外部理性**：AI 反复劝退、设边界、定成功标准，补充个人创业最缺的理性
