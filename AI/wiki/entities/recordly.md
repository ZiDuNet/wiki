# Recordly

开源桌面录屏 + 编辑工具，录完之后自动处理画面，适合做产品演示和教程视频。

## 基本信息

| 项目 | 信息 |
|---|---|
| GitHub | https://github.com/webadderallorg/Recordly |
| 平台 | macOS / Windows / Linux |

## 核心功能

- **自动缩放**：根据光标活动自动生成 zoom 建议，聚焦观众注意力
- **光标美化**：平滑移动、运动模糊、点击弹跳、摇摆效果，支持 macOS 风格光标
- **时间线编辑**：拖拽式编辑器，支持裁剪、变速、添加标注、额外音轨
- **摄像头气泡**：可叠加在录屏上，支持位置、大小、圆角、阴影等自定义
- **样式化输出**：内置壁纸、渐变背景、圆角、阴影、画面比例预设
- **扩展市场**：社区插件（点击音效、设备边框、浏览器 mockup 等）
- 支持导出 MP4 和 GIF，质量可选

## 用途场景

对经常需要做演示视频的人来说，Recordly 能省掉大量后期时间。对比 Screen Studio 等付费工具，Recordly 完全免费开源。
