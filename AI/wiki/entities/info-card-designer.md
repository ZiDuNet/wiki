# info-card-designer

**类型:** 实体 (Skill)
**作者:** 向阳乔木
**GitHub:** https://github.com/joeseesun/qiaomu-info-card-designer

## 简介

将文字或 URL 自动设计为杂志质感 HTML 信息卡，并自动截图输出 PNG。可直接发到 X、小红书、微信等平台。

## 核心特点

- **三种风格**：经典风格、杂志风格、艺术风格
- **Hook 模式**：每条描述改写为 10-20 字钩子句，有冲击感
- **宽度自定义**：480/600/900px，说「生成 480 宽的卡片」即可切换
- **超长卡片分割**：>1200px 自动分割成多张图
- **字体一致性**：使用仓耳今楷（TsangerJinKai）本地字体，截图渲染 100% 一致

## 安装命令

```bash
npx skills add joeseesun/qiaomu-info-card-designer
```
