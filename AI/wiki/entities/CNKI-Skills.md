# CNKI Skills

**类型:** 实体（Claude Code Skill）
**用途:** 知网自动化文献检索

## 简介

CNKI Skills 是一套让 Claude Code 通过浏览器自动化操作知网的 Skill，覆盖检索、筛选、解析、下载、导出 Zotero 全流程。不是绕过知网权限，而是模拟人工操作——你能访问的它帮你自动化。

## 能力模块

1. 关键词检索
2. 高级筛选（年份/CSSCI/北大核心）
3. 论文详情解析
4. 期刊信息查询
5. PDF/CAJ 下载
6. 引用导出
7. Zotero 入库
