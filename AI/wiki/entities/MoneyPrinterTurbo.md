# MoneyPrinterTurbo

**类型:** 开源项目
**GitHub Stars:** 57k+
**功能:** 短视频全自动生成

## 简介

一键全自动生成高清短视频的工具。输入主题后自动：写文案 → 抓取素材 → 配音 → 加字幕 → 合成视频。支持竖屏/横屏输出。

## 核心能力

- 主题输入 → 全自动内容生产
- 多素材自动抓取
- 配音合成
- 字幕自动生成
- 竖屏/横屏双格式支持
