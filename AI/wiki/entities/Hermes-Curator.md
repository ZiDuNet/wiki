# Hermes-Curator

[[Hermes]] Agent 的 Skills 整理工具，一键解决 Skills 文件夹膨胀问题。

## 功能

- 自动去重
- 自动归类
- 清理过期/冲突的 Skills

## 解决的问题

- Skills 文件夹越来越大
- 重复、过期、冲突的 Skills 混杂
