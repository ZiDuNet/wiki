# files.md

**类型:** 开源项目 / 笔记工具
**来源:** [[推荐 3 个 GitHub 上刚开源但实用的项目，收藏一波]]

## 简介

极简 Markdown 笔记应用，Obsidian 的开源替代品。定位"不被功能绑架的真正属于你自己的笔记空间"。作者 Artem Zakirullin 花了 5 年打磨，2000+ GitHub Stars。

## 核心特点

| 特点 | 说明 |
|------|------|
| 零安装零依赖 | 浏览器打开 app.files.md 就能用，作者承诺 10 年后打开 HTML 文件照样能跑 |
| 数据完全属于你 | 就是本地 .md 文件，支持 iCloud/Dropbox/Google Drive 同步 |
| LLM 友好 | 自带 llms.txt，复制到 CLAUDE.md 里，AI Agent 就能直接理解和操作你的笔记库 |
| Telegram 机器人 | 快速记录想法 |
| 知识图谱关联 | 笔记间自动链接 |
| 代码量极小 | 一个人就能看懂整个项目 |

## 与 Obsidian 对比

对 Obsidian 重度用户来说，files.md 可能太简陋。但如果一直在找"不被功能绑架的笔记空间"，这个项目值得试试。
