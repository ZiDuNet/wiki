# WeChat Radar

**类型:** 实体（开源工具）
**开源时间:** 2025年5月24日
**提及文章数:** 1

## 简介

WeChat Radar 是微信群聊情报看板工具，解决"群太多、真正有用的消息被淹没"问题。不让你翻聊天记录，直接给你一张"今日简报"。

## 四大核心能力

### 1. 话题雷达
跨群聚合，把同一天的热门话题收在一起，看一眼就知道今天圈子里在讨论什么。

### 2. 链接情报
自动把文章、GitHub 链接、小工具链接去重，整理出可读标题。

### 3. 群日报
一键摘要当天群聊内容，可丢给 ChatGPT/Claude/Kimi 等AI处理，生成大纲、工具清单、周报。

### 4. 本地存储
所有数据在 `~/.wechat-radar/` 目录，SQLite 存储，默认不上传云端。

## 界面特点

- 奶白色界面，深色模式支持
- 情报驾驶舱：活跃群数、总消息数、文章链接、工具链接、@我、高信号人物一屏全收
- "今日优先看"分区

## 安装使用

```bash
git clone https://github.com/[项目地址]
# 编辑 config.yaml，填写微信数据路径和监控群名
# Demo 模式：WECHAT_RADAR_DEMO=1
# 浏览器打开 localhost:7860
```

## 核心价值

- 以前：靠运气和眼力翻群聊
- 现在：AI 替你看，给你一张纸，5分钟扫一眼，2分钟丢给AI处理
