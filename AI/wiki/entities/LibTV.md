# LibTV（哩布哩布）

**类型:** 实体/AI视频创作平台
**来源:** [[Skill结合LibTV-轻松做出AI实机视频]]

## 简介

LibTV（哩布哩布）是一个 AI 视频创作平台，将提示词生成、参考图生成、分镜图生成、视频节点和最终合成预览整合在一个工作台中。支持 Creator（手动）和 Agent（自动）双入口模式。

## 核心功能

| 功能 | 说明 |
|------|------|
| Lib Image | 图片生成模块，支持角色四视图、UI总览、分镜图 |
| SeedDance 2.0 | 视频生成模型，支持图生视频 |
| 视频合成 | 多片段按顺序合成最终成片 |
| Creator 入口 | 适合手动检查角色、UI、镜头和节奏 |
| Agent 入口 | 适合自动化生成、拆分、编排动作 |

## 工作流特点

- **多宫格切分**：让分镜更规整
- **多模型支持**：多种图片和视频模型应对不同需求场景
- **画布合成**：在画布里按顺序合成最终视频
