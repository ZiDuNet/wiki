# Baihu Panel（白虎面板）

轻量级 NAS 定时任务调度平台，采用 Go + Vue3 开发，Docker 部署，旨在替代性能占用较高的青龙面板（qinglong）。

## 基本信息

| 项目 | 内容 |
|------|------|
| 项目名 | baihu-panel / 白虎面板 |
| 技术栈 | Go + Vue3 |
| 部署方式 | Docker / Docker Compose |
| 定位 | 轻量级定时任务调度面板 |

## 核心功能

- **任务调度：** 标准 Cron 表达式，常用时间规则快捷选择，日志不落文件
- **脚本管理：** 在线代码编辑器，文件树，压缩包上传解压
- **在线终端：** WebSocket 实时终端
- **消息推送：** TGB / Bark / 钉钉 / 企微 / 飞书 / 邮件等
- **机密管理：** AES-GCM 加密，类似 GitHub Secrets，日志自动打码
- **环境变量：** 任务执行时自动注入
- **远程执行：** 远程 Agent 插件，可在服务器远程调度任务
- **多语言支持：** 深度集成 Mise，支持 Python/Node/Go/Rust/Ruby/Java/PHP/Deno/Bun 等
- **内建助手库：** Python/Node.js 零配置推信

## 与青龙面板对比

| 维度 | 青龙面板 | 白虎面板 |
|------|---------|---------|
| 性能占用 | 较高 | 极致轻量 |
| 生态成熟度 | 完善 | 发展中 |
| 加密存储 | — | AES-GCM + 日志打码 |
| 远程 Agent | — | 支持 |
| 目标用户 | 需要多功能面板 | 只需轻量跑脚本 |
