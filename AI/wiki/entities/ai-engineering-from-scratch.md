# ai-engineering-from-scratch

> GitHub: https://github.com/rohitg00/ai-engineering-from-scratch
> Stars: ~7.5k (2026-05)
> 网站: https://aiengineeringfromscratch.com

## 简介

428 节课、20 个阶段、约 320 小时的 AI 工程全栈学习手册，从线性代数到自主多智能体系统。

## 课程规模

- 20 阶段
- 428 节课
- 约 320 小时
- 四种语言（Python、TypeScript、Rust、Julia）

## 教学模式

六步教学：Motto → Problem → Concept → Build It → Use It → Ship It

## 课程产出

每节课产出可复用工具：
- Prompts
- Skills
- Agents
- MCP Servers

## 课程阶段

- Phase 0: 环境设置
- Phase 01-02: 数学基础
- Phase 03-05: ML基础
- Phase 06-08: 深度学习
- Phase 09-11: CV/NLP/语音
- Phase 12-14: Transformers/生成AI/RL
- Phase 15-17: LLMs/多模态/工具协议
- Phase 18-19: 智能体工程/自主系统
