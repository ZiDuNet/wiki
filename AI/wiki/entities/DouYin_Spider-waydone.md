# DouYin_Spider (waydone)

**类型:** 实体 — 开源项目（fork/变体）
**GitHub:** https://github.com/waydone/DouYin_Spider
**技术栈:** Python + Node.js

## 简介

waydone 维护的 [[DouYin_Spider]] 版本，功能与 cv-cat 版类似，面向AI Agent与自动化场景，提供抖音平台数据爬取、直播间监听、私信实时处理等通信能力。

## 核心功能

- 用户主页与作品详情采集
- 评论区采集（多级回复）
- 智能搜索（视频/用户/直播）
- 关注列表与粉丝列表
- 消息通知、收藏列表、推荐流
- 直播间实时监听
- WebSocket私信收发
- 自动重试与断线重连
- JSON/EXCEL/MEDIA格式化输出
