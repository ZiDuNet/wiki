# OpenToonz

专业级开源 2D 动画制作软件，被吉卜力工作室使用十多年。

## 基本信息

| 项目 | 信息 |
|---|---|
| GitHub | https://github.com/opentoonz/opentoonz |
| 开发者 | DWANGO（日本） |
| Star | ~6900 |
| 平台 | Windows / macOS / Linux |
| 开源时间 | 2016 年 |

## 背景

底层基于意大利 Digital Video 公司开发的 Toonz。2016 年 DWANGO 开源，到 2026 年正好 10 周年。

**吉卜力工作室在这套软件上定制了十多年**，从《幽灵公主》时期就开始用。

## 核心功能

- 矢量和光栅绘图，支持数位板压感
- 骨骼绑定（Skeleton Rigging），角色动画效率高
- 洋葱皮（Onion Skin）—— 传统动画核心功能
- 粒子特效、样式表管理

## 评价

市面上免费的 2D 动画软件不多，能做到专业级别的更少。OpenToonz 算得上最完整的开源方案。
