# agents-best-practices

**类型:** 开源项目 / Agent Skill
**来源:** [[推荐 3 个 GitHub 上刚开源但实用的项目，收藏一波]]

## 简介

一套开发生产级 Agent 所需要的完整知识体系。从架构设计、工具权限、上下文管理到安全评估。

## 核心观点

> "模型负责提议行动，Harness 负责验证、授权、执行和记录。模型不是操作者，它只是建议者。"

## 三大使用场景

1. **生成 MVP Agent 蓝图**：给定业务场景，输出最小可用的生产级安全 Agent 架构
2. **审计现有 Agent**：诊断脆弱性、成本过高、调试困难等问题，给出修复优先级
3. **设计工具、权限和连接器**：安全接入 Slack/Linear/Google Drive/内部 API

## 内容覆盖

- 14 篇参考文档覆盖 Agent 开发方方面面
- 8 条运行时哲学规则（来自实战）
- 支持 Claude Code 和 Codex CLI
