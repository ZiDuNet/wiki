# Skill Graphs

**Type:** project
**Description:** Skills 组合方式的图形化表示方法

## 简介

Skill Graphs 是一种将 AI Agent Skills 之间的组合关系可视化的方法论。它将每个 Skill 视为图中的节点，Skill 之间的数据流、依赖关系、编排顺序作为边，形成一张有向图。Skill Graphs 2.0 进一步引入了权重（调用频率）、类型（串行/并行/条件）等属性，帮助用户理解和优化多 Skill 协作流程。

核心理念：将碎片化的 Skills 从"工具箱"升级为"可组合的图网络"，通过可视化发现冗余、瓶颈和优化机会。
