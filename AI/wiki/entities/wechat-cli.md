# wechat-cli

**Type:** Entity (工具)
**Mentioned in:** 1 articles

## 简介

wechat-cli 是一个微信命令行工具，支持通过终端收发微信消息、管理群聊、获取群成员信息等。在 Hermes Agent 生态中，wechat-cli 作为微信接入的底层工具，让 Agent 能够自动化处理微信群聊消息，例如搭建群聊情报助手、自动总结群消息、定时推送等场景。

与飞书 CLI 类似，wechat-cli 将微信的 IM 能力暴露为命令行接口，便于 Agent 编排和自动化。

## 核心能力

- 群聊消息收发与监控
- 群成员信息查询
- 消息自动总结与分类
- 支持集成到 Hermes Agent 工作流
