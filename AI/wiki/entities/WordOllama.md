# WordOllama

**类型:** 实体
**来源:** [[wordollama-2-agent能力更新]]

## 简介

为 Word/WPS 增加 AI 能力的免费开源插件，支持本地模型、ChatGPT 和国产大模型。官网：`https://www.wordollama.com`

## 关键更新（2.0）

- **Agent 任务面板**：输入任务描述，AI 自动规划并调用 Word 能力执行
- **修订模式**：默认用修订模式完成修改，方便改后审查
- **SKILL 支持**：可导入符合标准的 Skill，支持带 Python 等代码的功能性 Skill
- **静默审查**：保存时自动审查修改段落是否有问题

## 安装

```powershell
iex(irm 'https://download.wordollama.com/WordOllamaInstaller.ps1')
```
