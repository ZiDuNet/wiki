# 宝塔面板

**类型:** 实体 / 工具

## 简介

服务器可视化管理面板，将服务器、网站、环境、域名、SSL、日志等操作集中到一个界面。降低网站部署门槛，适合小白用户。

## 核心能力

- 服务器环境可视化管理（Nginx、Node.js 等）
- Node 项目一键部署与版本管理
- 域名绑定与 SSL 证书申请（Let's Encrypt 免费）
- 文件管理、上传解压
- 日志查看与监控

## 部署流程

1. 云厂商购买服务器，选择宝塔镜像
2. 登录面板，安装 Nginx
3. 安装 Node 版本管理器
4. 上传项目代码，解压
5. Node 项目管理器一键启动
6. 域名映射 + SSL 申请
