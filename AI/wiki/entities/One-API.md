# One-API

**类型:** 实体（开源项目）
**提及文章数:** 1

## 简介

One-API，开源API中转平台，GitHub 20K+ Star。将不同AI模型（OpenAI/Claude/Gemini等）统一封装为OpenAI兼容接口，支持多渠道负载均衡，一条docker命令即可部署。

## 核心特点

- OpenAI兼容接口
- 对接OpenRouter等多渠道
- SQLite数据存储
- Docker一键部署
- 多渠道负载均衡（一个挂了自动切换）
