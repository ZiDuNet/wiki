# BettaFish（微舆）

**类型:** 工具/开源项目
**GitHub:** 666ghj/BettaFish

## 简介

BettaFish（微舆）是一个开源免费的舆情分析系统，用多 Agent 协作架构实现全网舆论追踪和分析。输入一个人名或话题，自动生成结构化分析报告，包含情绪时间线、关键词聚类、内容来源分布。目标是让中小团队不用花几万块订阅商业舆情 SaaS，也能做品牌合作前的背景调查。

## 核心能力

- **多 Agent 协作**：一个 Agent 全网抓内容，一个分析情绪和关键词，一个生成报告
- **情绪时间线**：追踪情绪变化时间点，对应事件，判断负面是偶发还是持续
- **关键词聚类**：高频词分析，快速了解公众对特定人物的固有印象
- **内容来源分布**：平台声量 × 用户群体画像，影响合作传播路径判断
- **Docker 部署**：文档清楚，依赖冲突时靠 AI 定位解决

## 使用场景

- 品牌方/市场团队选合作对象前的背景调查
- 公关从业者监控自家品牌舆论动态
- 研究者/内容创作者追踪话题舆论演变
- AI 应用学习者学习多 Agent 架构

## 局限

部分平台数据覆盖不全，实时性不如商业产品，适合背景调研而非危机实时监控
