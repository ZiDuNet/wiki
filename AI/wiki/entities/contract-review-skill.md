# contract-review-skill

**类型:** 实体 (Skill)
**配套资源:** contract-review-skill-zh-v1.zip
**下载链接:** https://pan.quark.cn/s/c0fb8d0aa0af

## 简介

面向中文商务合同的 Agent 能力包，帮业务、销售、采购、项目经理做第一轮风险筛查。**不能替代律师**，而是将可复核的风险清单（风险项+原文位置+风险说明+修改建议+人工确认人）作为输出。

## 核心设计

1. **先判断合同类型**：销售合同、采购合同、软件外包、NDA，重点风险不同
2. **渐进式加载风险清单**：不同类型合同加载不同检查项
3. **固定输出风险表**：必须包含六列：风险等级、风险项、原文位置、风险说明、修改建议、人工确认人

## 支持的合同类型

| 类型 | 重点检查项 |
| --- | --- |
| 销售合同 | 付款期限、验收标准、违约责任 |
| 采购合同 | 交货周期、质量标准、付款方式 |
| 软件外包 | 交付物完整性、需求变更规则、知识产权归属 |
| NDA | 保密范围、保密期限、违约责任 |

## 避坑指南

- ⚠️ 不确定内容必须标记，不能编造条款
- ⚠️ 修改建议要能落地，不能只写"建议完善付款条款"
- ⚠️ 不要覆盖原合同，修改版另存为新文件
