# InkOS

> AI 小说生成流水线工具，通过 5 个 Agent 协同生成百万字小说。

## 简介

InkOS 是一款始发于 L站 的多 Agent AI 小说生成工具，通过雷达、建筑师、写手、审计员、修订者五个 Agent 组成流水线，实现数百万字小说内容的自动生成。支持同人创作（Canon/AU/OOC/CP），可导出番茄小说格式。

## 核心特性

- **多 Agent 协作**：5 个专业 Agent 分工，流水线式写作
- **市场选题雷达**：扫描番茄小说排行榜热门题材
- **文风提炼**：导入成熟作品，提炼可复用的文风规则
- **模型路由**：不同 Agent 调用不同成本/能力的模型
- **NAS 部署**：支持 Docker 方式部署到极空间私有云
