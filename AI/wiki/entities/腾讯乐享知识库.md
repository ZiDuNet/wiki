# 腾讯乐享知识库

**类型:** 企业工具/知识库平台

## 简介

腾讯乐享知识库是企业内部知识管理工具，支持上传文档、录音转写、培训材料等内容。通过 MCP 协议可连接到各类 Agent 工具（Codex、Claude Code、WorkBuddy、Cursor 等），实现知识查询、话术训练、录音质检、技能考核等场景。是企业 AI 销售教练场景的核心知识底座。

## 在 AI 销售教练中的应用

- 存储销售培训素材（服务礼仪、产品卖点、异议处理、会员推荐）
- 通过 MCP 连接到 Agent，提供检索和质检依据
- Agent 质检、陪练、出题时调用知识库作为标准答案
- 销冠经验沉淀进知识库，传给更多销售
