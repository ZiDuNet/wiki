# LLM友好笔记

**类型:** 概念 / 设计模式
**来源:** [[推荐 3 个 GitHub 上刚开源但实用的项目，收藏一波]]

## 定义

笔记工具自带标准化的机器可读摘要文件（如 llms.txt），使 AI Agent 能直接理解和操作笔记库，而不需要用户手动解释笔记结构。

## 代表案例

**files.md** 自带 llms.txt：
> "复制到 CLAUDE.md 里，AI Agent 就能直接理解和操作你的笔记库"

这使得你的笔记库从"人类阅读工具"变成"AI 能操作的知识库"。

## 关键优势

- AI 不需要猜测笔记结构，可以直接查找相关内容
- Agent 可以自主导航和检索，不需要人类在中间翻译
- 笔记从"第二大脑"变成"AI 能访问的知识库"
