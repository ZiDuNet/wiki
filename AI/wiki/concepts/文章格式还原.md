# 文章格式还原

将微信公众号文章的排版和样式100%还原保存的技术方案。

## 方案

[[wechat-article-exporter]] 的 HTML 导出格式会将文章中的图片和样式文件一起打包，确保导出后的 HTML 文件能够完整还原原始文章的视觉效果，包括：

- 文字排版（字体、颜色、间距）
- 图片布局
- 内嵌多媒体元素
- 原始页面样式

## 支持格式

除 HTML 外，还支持 JSON / Excel / TXT / Markdown / DOCX 格式导出，但只有 HTML 格式能做到100%还原。
