# 轻量级定时任务调度

用轻量级工具替代沉重的全能面板，在资源受限的环境（如 NAS）中稳定运行定时任务。

## 核心思路

**"杀鸡用牛刀"的对立面** — 如果你只想跑几个签到脚本、监控 API、定时备份，不需要部署一个功能完备但资源占用高的全能面板。

## 关键设计原则

| 原则 | 说明 |
|------|------|
| 资源优先 | 极致轻量，减少 CPU 和内存占用 |
| 日志不落盘 | 避免磁盘频繁 IO |
| 开箱即用 | Docker 部署无需复杂配置 |
| 够用就好 | 砍掉大多数人用不到的功能 |

## 典型场景

- NAS 上的定时签到脚本
- API 监控与告警
- 数据库定时备份
- 定时爬虫抓取
