# 工具分工哲学

**类型:** 概念

## 定义

在 AI Agent 工程落地中，不同工具应该放在正确的位置。工具没有优劣，只有位置放得对不对。

## 核心分工

| 工具 | 角色 | 定位 | 特点 | 适用场景 |
|------|------|------|------|---------|
| Claude Code | 建筑队 | 一次性、强执行的基建任务 | 能力强，无状态，干完就撤 | 配环境、装依赖、调网关 |
| Hermes | 物业/施工管家 | 长期知识管理 | 理解偏好、自我纠错、归类体系 | 知识库维护、自进化系统 |

## 关键洞察

> "把研究员当建筑工用，是浪费。把建筑队当研究员用，是灾难。"

- 建筑队特点：能力强但无状态，房子盖完就撤，不负责后续装修维护
- 物业特点：在房子里安家，按规矩整理物品，理解偏好，能自我纠错

## 应用案例

LLM Wiki 工程落地两步接力：

1. **第一步**：Claude Code 搞定基建
   - 把 Hermes 搭建文档丢给 Claude Code
   - Claude Code 读文档、写配置、解报错
   - 一次性搞定环境部署

2. **第二步**：Hermes 落地知识库
   - 自建结构、自我检查、跑测试
   - 长期维护知识库，建立交叉引用
   - 持续进化，越用越聪明
