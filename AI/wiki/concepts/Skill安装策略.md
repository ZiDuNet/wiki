# Skill安装策略

关于如何系统化安装 Agent Skills 的方法论，核心原则：分批安装、指标绑定、周度复盘。

## 核心原则

| 原则 | 说明 |
|------|------|
| **分批安装** | 先装高收益起步组合（如 5 个），逐周扩展 |
| **指标绑定** | 每个 skill 绑定 1 个验收指标（返工率/评审时长/交付时长） |
| **周度复盘** | 每周复盘：是否提升质量？是否冲突？保留/替换/淘汰？ |

## 错误 vs 正确做法

| 场景 | 错误做法 | 正确做法 |
|------|----------|----------|
| 首次使用 | 一次装满 20 个 | 先装前 5 个，逐周扩展 |
| 评估效果 | 靠主观感觉 | 绑定具体指标 |
| 团队协作 | 个人随意加 | 统一白名单 + 周度复盘 |

## 高收益起步组合示例

1. `find-skills` — 解决"不会找技能"的入口问题
2. `vercel-react-best-practices` — 约束 React/Next.js 常见性能坑
3. `frontend-design` — 提高 UI 质量，减少模板化输出
4. `web-design-guidelines` — 补审查标准，避免低级 UX 错误
5. `remotion-best-practices` — 视频内容场景直接提速

## 避坑提醒

1. 不要把 skill 当插件收藏夹，要当成**规则资产**
2. 没有验收指标的安装，基本等于没落地
