# HTML演示

**类型:** 工具/技术方案
**英文:** HTML Presentation

## 简介

使用HTML + CSS + JavaScript构建可交互的幻灯片演示，替代传统PPTX。优势：零依赖、跨平台、可嵌入动画/公式/代码高亮。

## 核心优势

- **零云依赖**：本地HTML文件直接打开
- **动画丰富**：支持Anime.js等动画库
- **公式支持**：KaTeX/MathJax渲染数学公式
- **代码高亮**：可嵌入代码演示块
- **版本可控**：HTML文件可通过Git管理
