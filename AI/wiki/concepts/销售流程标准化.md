# 销售流程标准化

**类型:** 概念
**来源:** [[销售线索跟进 Skill：把散乱客户信息变成成交行动清单]]

## 定义

把销售跟进中的关键规则（流程、模板、边界、人工复核点）固定到 Agent Skill 里，使输出稳定可重复。

## 四层机制

1. **字段标准**：客户来源、联系人角色、核心需求、预算信号、决策链、异议点、下一步动作——必须稳定出现
2. **判断规则**：结合预算、时间窗口、决策人、明确需求和回复频率综合判断
3. **输出模板**：线索表 + 行动清单 + 跟进话术 + 复盘建议
4. **人工复核点**：价格承诺、合同条款、特殊优惠必须人工确认

## 为什么需要标准化

普通提示词的问题是：这次让模型"帮我整理客户"，下次让模型"帮我判断意向"，输出字段和判断标准可能完全不一样。真正稳定的业务执行需要把流程、模板、边界和复核点沉淀到 Skill 里。
