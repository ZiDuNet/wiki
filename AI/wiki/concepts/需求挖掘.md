# 需求挖掘

**类型:** 概念
**定义:** 从用户行为数据中发现真实需求的方法论

## 核心内容

需求挖掘是指通过各种渠道（如 GitHub Issue/PR、用户讨论、替代方案等）发现用户真实需求的过程。

### GitHub 需求挖掘方法

通过分析热门项目的 Issue 和 PR：
- **Issue** = 用户留言区，反映用户痛点
- **PR** = 修改方案，反映用户自主解决行为

### 判断标准

一个小功能背后可能藏着真实需求：
1. 用户反复提起（频率高）
2. 有人补充具体场景（需求明确）
3. 情绪很强（痛点深）
4. 需求边界逐渐清楚（可产品化）

### 案例：Claude Code buddy 功能

Claude Code 的 buddy 桌宠功能在 Issue 中热度极高：
- 用户写长留言
- 有人补充使用场景
- 有人说明为什么需要它
- 后续出现多个定制桌宠项目
