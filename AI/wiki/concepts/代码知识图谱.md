# 代码知识图谱

**类型:** 概念 / 代码分析

## 简介

代码知识图谱是将代码库变成可交互、可搜索、可问答的结构化图谱的技术。通过 [[Tree-sitter]] 静态解析代码结构，再用 LLM 生成语义理解，生成节点（文件/模块）、边（依赖关系）、颜色（架构层）的三层可视化界面。

## 核心功能

1. **可点击**：每个节点是一个文件或模块，点击查看摘要
2. **可搜索**：搜索「auth 相关的部分在哪」直接定位
3. **可问答**：直接问「支付流程是怎么走的？」
4. **影响分析**：改动后跑 `/understand-diff` 看影响范围

## 技术路线

不是纯 LLM 分析，而是两步分开：

1. **静态解析**：[[Tree-sitter]] 提取代码结构（函数、类、依赖关系）
2. **语义理解**：LLM 生成摘要和问答能力

两步分开结果更可靠，不是让 AI 凭感觉猜代码。

## 架构层自动识别

图谱颜色区分架构层：
- API 层（路由、控制器）
- Service 层（业务逻辑）
- Data 层（数据库、模型）
- UI 层（前端组件）

## 图谱可提交到 Git

生成的知识图谱是 JSON 文件，提交一次团队所有人共享。新人入职直接打开图谱看，不用从零开始扫代码。

## 适用场景

- 接手 20 万行代码的新项目
- 做代码 Review 的 Tech Lead
- 快速了解开源库内部逻辑
- 分析改动影响范围
