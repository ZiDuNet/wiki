# 客户模拟Agent

**类型:** Agent 类型

## 简介

客户模拟 Agent 扮演不同类型客户（挑剔型/犹豫型/预算有限型/注重品质型/多家比价型），与销售进行真实对话演练。对话结束后切换为销售教练模式，调用知识库给出复盘报告（能力评分 + 关键问题回放 + 知识库建议）。

## 核心机制

- **情绪值系统**：初始 50，满分 100，影响店员得分
- **第二阶段复盘**：检索知识库中水果销售话术、异议处理、产品知识作为复盘依据

## 应用场景

新人每天练 10 分钟，今天练"嫌贵"，明天练"比价"，后天练"送礼场景推荐"
