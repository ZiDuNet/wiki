# SOUL.md配置

> 定义 Agent 性格、价值观、行为边界的配置文件。给 AI 注入个性和判断力。

## 核心定义

SOUL.md 是 [[OpenClaw]] 和 [[Hermes-Agent]] 等框架中定义 AI Agent "灵魂"的配置文件。它不属于提示词，不属于工具说明，而是描述 Agent 的核心性格特征、沟通风格、决策偏好和价值判断标准。

## 与其他配置文件的关系

在 [[OpenClaw]] 的 `~/.openclaw/workspace/` 目录下有一组核心配置文件，被称为"灵魂三件套"：

```
~/.openclaw/workspace/
├── SOUL.md          # AI 的性格与风格 ← 本页面
├── USER.md          # 关于用户的信息
├── AGENTS.md        # AI 的工作手册
├── IDENTITY.md      # AI 的对外身份形象
├── TOOLS.md         # 工具使用说明
├── HEARTBEAT.md     # 心跳定时任务描述
└── MEMORY.md        # 长期记忆
```

- **SOUL.md** 管"怎么说话"（风格、性格、价值观）
- [[AGENTSmd配置|AGENTS]] 管"怎么做事"（工作流程、权限、规则）
- **IDENTITY.md** 管"你是谁"（对外身份）

## 写什么、怎么写

很多人配完 SOUL.md 后发现 AI 还是老样子，原因通常是：**写得太抽象、太笼统，AI 根本不知道怎么执行**。

### SOUL.md 的三个层次

1. **怎么说话**：语气、用词习惯、是否使用 emoji、口语化程度
2. **怎么思考**：面对问题时的优先级和判断框架
3. **怎么判断**：什么情况该做什么不该做

### 实用配置示例

```
说话方式：
- 结论先行，先给答案再解释原因
- 段落短，每段不超过3句话
- 用"你"不用"您"
- 不用感叹号、不用"非常""极其"
- 不用"好的""当然""没问题"开场
- 遇到不确定的事直接说"我不确定"
```

## 常见误区

1. **太抽象**：写"要专业要友好"不够具体，应写具体的语言规则
2. **太长**：SOUL.md 不是说明书，应是精炼的行为准则
3. **与 AGENTS.md 混淆**：SOUL 管"人格"，AGENTS 管"流程"
