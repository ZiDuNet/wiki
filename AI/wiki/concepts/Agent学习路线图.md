# Agent学习路线图

**类型:** 概念
**来源:** awesome-agentic-ai-zh 项目

## 定义

从零到构建多 Agent 系统的系统化学习路径，包含 8 个阶段、2 条分流路径。

## 两套路径

### Track A — CLI Power User（8-10 周）
- 适合：用现成工具提效
- 目标：把 CLI Agent 用到极致

### Track B — Agent Builder（16-22 周）
- 适合：从零打造 Agent
- 目标：进化为 Agent 系统构建者

## 八阶段

| Stage | 主题 |
|---|---|
| 0 | Python/Git/API 基础 |
| 1 | LLM 基础（Token/API） |
| 2 | Prompt 设计 |
| 3 | Function Calling/ReAct |
| 4 | Agent 框架 |
| 5 | Claude Code 生态 |
| 6 | RAG/Memory |
| 7 | Multi-Agent 生产化 |
| 8 | Agent Interfaces |

## 三层概念进化

1. Prompt Engineering（Stage 2）
2. Context Engineering（Stage 3+）
3. Harness Engineering（Stage 7）
