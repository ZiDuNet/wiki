# 瑞士国际主义风格

一种源于 20 世纪瑞士的现代设计风格，强调网格、直角、极简和高对比。

## 设计特征

| 特征 | 说明 |
|---|---|
| Grid | 严格网格系统，固定列数 |
| 直角 | 无圆角，方块形状 |
| 1px 发丝线 | 极细线条分隔 |
| 高饱和锚点色 | 强对比色作为视觉锚点 |
| 极致字号对比 | 大小字号强烈对比 |
| 无装饰 | 无阴影、无渐变、无圆角 |

## 在 [[guizang-ppt-skill]] 中的应用

瑞士国际主义是该 Skill 的 Style B，适合：

- 事实表达
- 产品分析
- 方法论
- 数据页
- 项目汇报

## 版式系统参数

| 参数 | 值 |
|---|---|
| Grid | 16 列 |
| 版式数量 | S01-S22（22 个具名版式） |
| 锚点色 | 克莱因蓝、柠檬黄、柠檬绿、安全橙 |

## 与其他风格对比

| 风格 | 适用场景 |
|---|---|
| 瑞士国际主义（Style B） | 事实表达、项目汇报、方法论 |
| 电子杂志 × 电子墨水（Style A） | 观点表达、个人分享、叙事型演讲 |
