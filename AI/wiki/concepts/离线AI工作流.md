# 离线AI工作流

**类型:** 概念

## 定义

完全本地运行的 AI 工作流，不依赖任何云端服务，数据不发送到外部服务器，断网也能跑。

## 三大动机

1. **隐私与数据安全**：笔记、研究、思考不会成为训练数据
2. **断网可用性**：航班、高铁、WiFi 挂了都能用
3. **成本可控**：一次性下载，无限次使用

## 技术栈四层架构

| 层级 | 工具 | 职责 |
|-----|------|------|
| 模型层 | LM Studio / Ollama | 本地模型运行，提供 API |
| 笔记层 | Obsidian | Markdown 存储，双向链接 |
| 连接层 | Copilot / Smart Connections | 插件连接模型与笔记 |
| 辅助层 | llama.cpp / PrivateGPT | 底层引擎，本地问答 |

## 核心价值

不在于「替代云端」，而在于**多一个选择**。需要隐私时完全离线，需要最强模型时仍可用云端 API。
