# 替代动作非人

**来源文章:** [[别再问要不要上AI-Agent-先问哪一步最该被替代]]

## 定义

Agent 第一阶段不应该先思考"替代哪个岗位"，而应该先思考"流程里哪一个动作最适合先被替代"。因为岗位太大，动作才可落地。

## 为什么是动作而非岗位

一个岗位通常同时包含：
- 机械重复动作
- 判断动作
- 沟通动作
- 协调动作
- 兜底动作

Agent 第一阶段最适合接手的是：
- 重复
- 标准化
- 低风险
- 易量化

## 判断公式

> **高频 + 标准化 + 低风险 + ROI 易量化**

## 四类判断问题

1. 这件事发生频率高不高？
2. 它的规则够不够清楚？
3. 做错了风险能不能控制？
4. 做成之后收益能不能量化？

## 实践意义

- 从哪里切入 → 明确
- 自动化边界在哪 → 清晰
- 出错后谁兜底 → 确定
- 效果怎么衡量 → 可量化
- 什么时候扩大范围 → 有标准
