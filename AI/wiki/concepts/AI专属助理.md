# AI专属助理

## 核心定义

让 AI 从"通用助手"进化为"理解用户背景的个性化助理"，通过资料库记住用户的专属信息（工作文档、投资笔记、写作风格等），在后续对话中自动调用。

## 进化路径

```
通用AI助手 → 记住专属信息 → 理解背景 → 持续进化 → 专属助理
```

## 核心价值

1. **记住专属信息**：上传文档后不再需要反复解释背景
2. **快速搜索精准调用**：自动搜索资料库中的相关文档作为参考
3. **分类管理**：按项目/主题/时间分类整理，精准调用

## 应用场景

- [[WorkBuddy]] 资料库 + 专家：调用专业资料给出精准分析
- [[WorkBuddy]] 资料库 + 技能：调用参考数据完成精准操作
- [[WorkBuddy]] 资料库 + 自动化：定期更新资料保持新鲜度
