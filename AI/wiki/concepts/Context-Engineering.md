# Context Engineering

**类型:** 概念
**来源:** awesome-agentic-ai-zh 三层概念进化

## 定义

动态组合 system prompt + memory + 检索结果 + tool schema 的工程能力。

## 定位

三层概念进化的第二层（Stage 3+）：

1. **Prompt Engineering** → 单一 prompt 怎么写
2. **Context Engineering** → 动态组合上下文组件
3. **Harness Engineering** → 完整生产系统

## 核心内容

- 动态构建 system prompt
- 管理 memory 与检索结果
- 组合 tool schema
- 为 Agent 提供完整上下文
