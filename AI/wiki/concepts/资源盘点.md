# 资源盘点

一人企业方法论的第01步：按8类确认手上有什么，是整个流程的起点。

## 定义

资源盘点是系统化梳理个人已有资源的过程，为后续利基定位和业务设计提供输入。

## 8类盘点框架

| 类别 | 内容 |
| --- | --- |
| 经验 | 行业经验、项目经历、专业技能 |
| 人群 | 老客户、潜在客户、社群关系 |
| 能力 | 硬技能、软技能、可迁移能力 |
| 关系 | 合作方、渠道方、可转介绍的人 |
| 渠道 | 已有的传播渠道、获客渠道 |
| 资产 | 内容资产、案例资产、工具资产 |
| 约束 | 时间约束、资金约束、精力约束 |
| 硬性边界 | 绝对不碰的事、底线规则 |

## 案例：室内设计师林夏的盘点

AI 不让她笼统说"我有客户"，而是逼她列：

- 私域 50+ 深度老客户、200+ 沉睡咨询
- 高信任老客户 5–8 个能转介绍/做实景拍摄
- 12–15 套高清实景 + 30 套施工前后对比
- **硬性边界**：不碰公司准客户、不垫资、不接传统全包私单、不接白嫖

## 设计原则

- **不笼统**：AI 会追问具体数字和细节
- **设边界**：硬性边界是防止滑坑的关键
- **真实可盘点**：需要有真实存量，不是愿景
