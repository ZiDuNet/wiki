# 用户分群

**类型:** 概念
**首次出现:** `synthesize-research` Skill 全文中文版

## 定义

根据行为、需求、特征的相似性，将用户划分为不同的群体，以便理解不同类型的用户在产品/服务上的表现差异。

## 与人物画像的关系

- **用户分群**：基于数据的统计分析分类，强调群体边界和规模
- **人物画像**：基于分群结果的定性描述，强调典型特征和故事

画像是分群的可操作版本：分群给出数字，分群给出叙事。

## 分群维度

### 行为维度（最有效）

| 维度 | 示例 | 用途 |
|------|------|------|
| 使用频次 | 日活/周活/月活 | 判断粘性 |
| 使用深度 | 功能数/使用时长 | 判断价值 |
| 关键行为 | 转化/分享/留存 | 判断产品匹配 |
| 生命周期 | 新手/成长/成熟/流失 | 针对性策略 |

### 人口统计维度（最弱）

- 年龄、性别、地区——预测力往往不如行为维度
- 只有在行为数据不可得时才作为主要维度

### 混合维度

```
行为分群 + 背景信息 → 更完整的分群描述
例：高频使用者 + 企业管理员 → 高价值企业用户群
```

## 分群分析方法

### 定量方法

- **聚类分析**：K-means、层次聚类
- **RFM 分析**：最近购买/购买频率/购买金额
- **行为序列分析**：路径聚类、时序模式

### 定性方法

- **访谈**：通过深度对话发现行为模式
- **亲和图**：协作式聚类观察
- **主题分析**：从访谈数据中提炼分群逻辑

## 分群结果的应用

| 应用场景 | 分群用途 |
|---------|---------|
| 产品路线图 | 优先满足高频高影响群体需求 |
| 运营策略 | 不同分群不同触达方式 |
| 个性化推荐 | 按分群特征推荐内容/功能 |
| 增长实验 | 按分群设计 A/B 测试 |

## 发现分群时的处理

当研究中发现明显不同的用户类型时：
1. 记录分群特征（行为、目标、痛点）
2. 估算各分群规模（用定量数据验证）
3. 评估分群对产品决策的影响
4. 为每个分群制定差异化策略
