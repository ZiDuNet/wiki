# 双后端架构

**类型:** 概念 / 架构模式
**来源:** [[干掉 Whisper：VoiceVault 从 Whisper 迁移到 FunASR]]

## 定义

用 trait object 对多种后端实现统一抽象，调用方不依赖具体后端，通过泛型参数注入实现切换。

## VoiceVault 实现

```rust
pub trait TranscriptionBackend: Send + Sync {
    fn transcribe(&self, pcm_16k: &[f32]) -> Result<Vec<Segment>>;
    fn backend_name(&self) -> &str;
    fn language(&self) -> &str;
}
```

调用方持有 `Arc<dyn TranscriptionBackend + Send + Sync>`，不关心底层是 Whisper 还是 FunASR。

## 迁移收益

- 迁移只改 ~50 行核心代码
- 不改 CLI 和桌面端转录管线
- 所有原有单元测试继续通过
- 配置文件一行切换后端：`backend = "funasr"`
