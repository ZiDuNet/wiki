# 群聊情报聚合

**类型:** 概念

## 简介

群聊情报聚合是指从多个微信群/聊天群中自动提取、去重、整理有价值信息的技术和方法。解决"群太多、真正有用的消息被淹没"问题。

## 核心痛点

- 加过十几个技术群、AI群，每天几百条消息滚过去
- 好东西（新工具分享、深度讨论、@你的事）混在"收到""哈哈哈""+1"里
- 翻聊天记录浪费时间，不翻怕错过

## 四大能力维度

### 1. 话题雷达（跨群聚合）

- 多个群同一天聊同一个话题，不用一个个点开
- 看一眼就知道今天圈子讨论什么
- 热点话题识别与聚合

### 2. 链接情报（去重整理）

- 自动去重：同一个链接被扔七八遍只保留一份
- 整理可读标题
- 分类：文章、GitHub、小工具链接

### 3. 群日报（摘要生成）

- 一键摘要当天群聊内容
- 可导出给 AI（ChatGPT/Claude/Kimi）二次处理
- 应用场景：写大纲、列工具清单、生成周报

### 4. 本地存储（隐私保障）

- 数据不上传云端
- SQLite 本地存储
- 全部在自己硬盘上

## 工作流程

```
群聊消息 → 自动采集 → 去重整理 → 情报看板 → AI处理 → 输出成果
```

**时间效率：**
- 以前：靠运气和眼力翻群聊
- 现在：5分钟扫一眼看板 + 2分钟丢给AI处理 = 一天有价值信息到手

## 典型应用

- 技术群/开源群监控
- 行业信息追踪
- 工具发现与整理
- 周报生成
