# Docs-As-Code

**类型:** 概念

## 定义

把文档像代码一样管理——集中存放、版本控制、协作编辑。

## 核心特征

1. **本地文件**——文档是磁盘上的文件，不依赖云服务
2. **纯文本格式**——markdown 等，Git 完美支持
3. **版本控制**——历史追踪、分支协作
4. **迁移自由**——随时备份、随时迁移

## Obsidian 实现

Obsidian 的「仓库（vault）」概念即 Docs As Code 的表达：
- 一个仓库 = 一个文件夹
- 所有 markdown、图片、附件属于仓库
- 天然适合 Git 版本管理
