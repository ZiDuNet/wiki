# 黑客松

**类型:** 概念 / 竞赛活动

## 简介

黑客松（Hackathon）是一种限时编程竞赛活动，参与者需要在短时间内完成项目开发。在 AI Agent 领域，黑客松成为展示 Agent 工程能力的重要舞台。

## 案例：Anthropic × Forum Ventures 黑客松

**时间：** 2025年9月，纽约
**冠军：** [[Affaan-Mustafa]] 与 @DRodriguezFX
**奖金：** $15,000
**作品：** zenith.chat（实时协作聊天平台）
**开发时间：** 8小时

获胜关键不是新奇算法，而是 Affaan 过去十个月每天高强度使用 [[Claude Code]] 时打磨出来的一套配置系统——后来的 [[ECC]] 项目。

## 黑客松与 Agent 工程的关系

黑客松展示了 Agent 工程的核心价值：
- 配置积累的价值：日常使用打磨的系统比临时创意更重要
- 工具链集成：Claude Code + 配置 = 完整开发环境
- 开源转化：黑客松作品可以成为长期开源项目
