# 多智能体协作

将复杂任务拆分给多个专门化的 AI Agent 协作完成，每个 Agent 负责特定角色或领域。

## 协作模式

- 角色分工（导演/编剧/制片等）
- 管线编排（串联工作流）
- 并行执行（多 Agent 同时工作）
