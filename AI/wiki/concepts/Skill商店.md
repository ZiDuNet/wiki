# Skill商店

集中展示和分发 AI Agent Skills 的平台或目录。

## 核心功能

| 功能 | 说明 |
|---|---|
| 精选技能 | 内置高质量 Skill 推荐 |
| 自定义源 | 支持添加 GitHub、skills.sh、本地目录等商店源 |
| 标签筛选 | 按标签快速过滤 |
| 安全扫描 | 安装前检查 Skill 内容安全性 |

## 代表平台

| 平台 | 说明 |
|---|---|
| [[PromptHub]] | 内置 20+ 精选技能，支持自定义商店源 |
| [[skills-sh]] | Skill 分发平台 |
| clawhub | Skill 聚合平台 |

## Skill 来源

- Anthropic 官方 Skill
- OpenAI 官方 Skill
- 社区贡献 Skill
- 个人/团队自定义 Skill
