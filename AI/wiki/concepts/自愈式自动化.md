# 自愈式自动化

**类型:** 概念
**来源:** Browser Harness 项目

## 定义

AI Agent 在执行任务时发现缺少功能，自动编写代码补齐缺陷，继续执行——**self-healing**。

## 与传统自动化对比

| 传统自动化 | 自愈式自动化 |
|---|---|
| 人写代码让机器跑 | 机器发现缺代码自己写 |
| 页面改动脚本废 | AI 自己修路 |
| 维护火葬场 | 持续自我进化 |

## 工作流

```
发现问题 → 分析缺失 → 自己写 helper → 应用修复 → 继续执行
```

## 代表实现

- [[Browser-Harness]]：发现缺上传函数 → 在 `agent-workspace/` 写 helper → 继续操控浏览器
