# 内容创作

**Keywords:** 内容创作, 内容生产, 写作skill, 公众号, 封面图, 小红书, 信息图

## 简介

内容创作是 AI Agent 技能体系中应用最广泛的场景之一。借助 [[Skills技能系统|Skills]] 和 Agent 框架，内容创作正从"人工逐字打磨"进化为"AI 驱动的流水线式生产"，覆盖选题、写作、配图、排版、发布全流程。

## AI 内容创作的核心场景

### 1. 公众号文章
- [[Hermes-Agent]] + 飞书 CLI 实现从选题到发布的完整闭环
- [[baoyu-skills]] 提供 100+ 风格的封面图自动生成
- 从飞书文档一键发布到微信公众号的 Skill

### 2. 小红书内容
- [[CodeBuddy]] + Skills 实现小红书信息图系列生成
- 自动生成小红书风格的图文内容
- [[小红书]] 爬虫 Skill 用于竞品分析和选题研究

### 3. PPT 内容
- [[PPT制作]] 场景下的内容自动化（详见 [[PPT制作]] 页面）
- [[html-ppt-skill]] 支持 HTML 格式的精美演示文稿

### 4. 学术写作
- [[论文写作]] 相关 Skills 支持文献检索、综述生成
- [[科研工具]] 集合覆盖学术研究全流程

## 推荐的 Skills 与工具链

| 工具/技能 | 用途 | 适用场景 |
|-----------|------|----------|
| [[baoyu-skills]] | 13000+ Star 的内容创作全家桶 | 全类型内容配图 |
| [[html-ppt-skill]] | HTML 格式演示文稿 | PPT/方案展示 |
| [[Hermes-Agent]] | 端到端内容工作流 | 公众号、小红书 |
| [[OpenClaw]] | 多 Agent 协作创作 | 团队级内容生产 |

## 关键方法论

- **去 AI 味**：通过 [[Obsidian]] 内容创作系统 + 结构化提示词让输出更自然
- **Skill 配方**：组合多条 Skill 形成"选题-写作-配图-发布"一条龙
- **多 Agent 协作**：不同 Agent 负责不同环节（选题 Agent、写作 Agent、排版 Agent）
