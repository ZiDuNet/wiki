# Agent工程

**类型:** 概念

## 定义

将 AI Agent 使用从「工具」升级为「系统」的工程实践。七块拼图：CLAUDE.md + Skill + MCP + Harness + Workflow + 项目隔离 + Context 管理。

## 四阶段进化

| 阶段 | 状态 | 瓶颈 |
|-----|------|------|
| 纯小白 | 当搜索引擎用 | 每件事亲自问/改/确认 |
| Prompt 重度爱好者 | 积累提示词模板 | Prompt 承载信息有限 |
| AI 工具大师 | 装 Skill、配 MCP | 项目多会乱 |
| AI 系统使用者 | 项目隔离、Harness 调度 | 无瓶颈，系统越用越顺 |

## 系统化收益

- 工具：快一点
- 系统：快十倍

## 实践路径

1. **今天**：检查全局 Skill，业务绑定挪到项目
2. **本周**：给最重要项目写 CLAUDE.md
3. **本月**：选一个频繁任务写 Harness 配置
4. **持续**：新项目用独立目录结构从头搭
