# 销售质检Agent

**类型:** Agent 类型

## 简介

销售质检 Agent 对照企业知识库标准流程，对销售通话录音/转录稿进行评分和复盘。典型打分维度：服务礼仪 / 销售流程执行 / 话术与异议处理。输出包含总分、评级、分项评分、话术优化表。

## 应用场景

主管日常抽查 + 销售自查。提前拿到质检报告，主管再做重点复核。
