# 多工具同步

将中央技能库中的 Skill 同步到多个 AI Agent 工具（Cursor、Claude Code、Codex 等）的技术机制。

## 同步方式

| 方式 | 说明 |
|------|------|
| **软链接** | ln -s 创建符号链接，节省空间，更新自动生效 |
| **复制** | cp 复制文件，独立副本，中央库更新需重新同步 |

## Skills-Manager 实现

- skill 卡片上 per-Agent 角标显示安装状态
- 点击角标切换安装/卸载
- 支持批量操作

## 支持的工具

Cursor、Claude Code、Codex、OpenCode、Amp、Kilo Code、Roo Code、Goose、Gemini CLI、GitHub Copilot、Windsurf、TRAE IDE、Antigravity、Clawdbot、Droid 等 15+ 工具。

## 目录对应

| Agent | 全局目录 |
|-------|----------|
| Claude Code | ~/.claude/skills/ |
| Cursor | ~/.cursor/skills/ |
| Codex | ~/.codex/skills/ |
| Windsurf | ~/.windsurf/skills/ |
