# 六步教学模式

AI 工程学习课程的教学框架：Motto → Problem → Concept → Build It → Use It → Ship It。

## 六步流程

1. **Motto** — 学习口号/目标
2. **Problem** — 问题引入
3. **Concept** — 概念讲解
4. **Build It** — 手写实现
5. **Use It** — 工具实现
6. **Ship It** — 可交付工件

## 特点

- 每节课产出可复用工具
- 先手写原理再用框架
- 学会它、造出来、发出去
