# 持续学习系统

**类型:** 概念 / Agent 能力

## 简介

持续学习系统是让 AI Agent 跨会话积累知识和习惯的机制。[[ECC]] 的持续学习 v2 系统通过置信度机制自动学习用户的编码习惯，几周后 Agent 写出的代码自带个人风格。

## ECC 持续学习 v2 工作原理

| Session | 行为 | 置信度 |
|---|---|---|
| Session 1 | 纠正 async error 处理模式 → 系统记录 | 0.3 |
| Session 5 | 同样的模式反复确认、修正 | 0.6 |
| Session 10 | 模式稳定 | 0.9 → 自动应用 |

置信度达到 0.9 后，系统自动应用学习到的模式。Claude Code 写出来的代码自带用户的编码习惯，不再是「所有人用起来都一样」的通用模型输出。

## 核心命令

```bash
/instinct-status     # 查看已学习的模式
/evolve              # 把相似模式聚合成新技能
/instinct-export     # 导出你的「习惯」，分享给团队
```

## 解决的问题

[[Claude Code]] 每次新会话都是一张白纸——不知道用户的代码风格、偏好、上次纠正过什么。持续学习系统改变了这个局面：

1. 观察用户每次的修改
2. 自己总结规律
3. 置信度达到阈值后自动应用
4. 可导出分享给团队
