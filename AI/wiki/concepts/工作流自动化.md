# 工作流自动化

**类型:** 概念
**首次出现:** 45个Hermes Agent / OpenClaw自动化案例（上）

## 定义

通过 AI Agent 替代人工执行重复性任务流程，实现从"人操作工具"到"Agent 自动运转"的转变。

## 核心特征

- **持续运行**：Agent 在机器上后台持续运行，无需人工干预
- **事件驱动/时间驱动**：通过 cron 定时或 webhook 触发
- **自然语言编排**：用自然语言描述需求，Agent 自动拆解执行
- **工具链整合**：搜索 → 分析 → 生成 → 推送，全流程自动串联

## 典型场景

| 类别 | 场景数 | 代表场景 |
|------|--------|---------|
| 内容创作 | 10 | 热点扫描、文章生成、多平台适配 |
| 邮件沟通 | 10 | 优先级分类、跟进提醒、会议简报 |
| 信息研究 | ~10 | 竞品监控、行业报告整理 |
| 日程任务 | ~10 | 日报生成、任务排队、提醒触发 |
| 文件数据 | ~5 | 格式转换、数据清洗、报告生成 |

## Hermes 实现要素

```
需求描述 → 自然语言 prompt → Skill 保存 → cron 定时触发 → 结果推送
```

关键机制：
- **cron**：自然语言设置定时任务
- **MEMORY.md**：存储个人风格偏好
- **Skill**：工作流复用，一次配置多次使用
- **MCP**：扩展工具接入（飞书/Gmail/Tavily等）

## 与传统 RPA 的区别

| | 传统 RPA | Agent 工作流 |
|---|---|---|
| 配置方式 | 图形界面拖拽 | 自然语言描述 |
| 适应变化 | 固定流程，变化需重新配置 | Agent 可自主判断调整 |
| 触发方式 | 手动/时间 | 事件驱动 + 智能触发 |
| 学习成本 | 高，需专业培训 | 低，对话即编程 |
