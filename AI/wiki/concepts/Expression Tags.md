# Expression Tags

文本转语音中的情感表达控制标签，用于控制语音的情感、呼吸、笑声等非语言元素。

## 标签类型

- `<laugh>` — 笑声
- `<breath>` — 呼吸
- `<sigh>` —叹气

## 代表项目

- [[supertonic]] — v3 版本支持 Expression Tags
