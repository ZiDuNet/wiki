# 定量研究

**类型:** 概念
**首次出现:** `synthesize-research` Skill 全文中文版

## 定义

通过结构化数据收集和统计分析，回答"有多少"、"多大程度"、"什么关系"等问题，对定性发现进行规模化验证。

## 与定性研究的关系

```
定性研究 ←→ 定量研究
  ↓            ↓
探索假设      验证规模
发现模式      检验结论
理解原因      测量影响
```

两者形成反馈回路：定性产生假设，定量验证规模；定量发现异常，定性深挖原因。

## 核心指标

### 问卷类

| 指标 | 说明 | 陷阱 |
|------|------|------|
| 响应率 | 样本代表性 | 低响应率可能引入系统性偏差 |
| 分布 | 不要只看均值 | 双峰分布均值无法揭示 |
| NPS/CSAT | 满意度和推荐度 | 小样本下波动大 |
| 分群对比 | 按用户类型拆分 | 总体平均掩盖差异 |

### 行为数据类

| 指标 | 说明 | 用途 |
|------|------|------|
| 留存率 | 用户回访比例 | 产品价值核心指标 |
| 漏斗转化 | 各环节流失 | 识别阻塞点 |
| 使用频次 | 功能使用深度 | 判断功能价值 |
| 路径分析 | 用户行为序列 | 优化使用体验 |

## 常见分析错误

1. **只看平均值**：3.5 均值可能是"都不冷不热"也可能是"一半喜欢一半讨厌"
2. **忽略未回应偏差**：未回复的人和回复的人系统性不同
3. **过度解读小差异**：NPS 提升 0.1 分往往是噪声而非信号
4. **Likert 当等距**：5分制"非常同意"和"同意"的距离 ≠ "同意"和"中立"的距离
5. **混淆相关与因果**：A 和 B 相关不等于 A 导致 B

## 分布形状的重要性

```
正态分布（中间多）    → 均值有代表性
双峰分布（两极多）    → 均值掩盖了真实分群
长尾分布（少数高频）  → 关注头部忽略尾部
```

## 数据与定性来源矛盾时

当定量数据与定性发现不一致时：
1. 检查测量人群是否不同
2. 检查定量问题是否测到了你以为的内容
3. 诚实报告差异，继续调查
4. 矛盾本身是信号，不是错误
