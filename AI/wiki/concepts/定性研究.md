# 定性研究

**类型:** 概念
**首次出现:** `synthesize-research` Skill 全文中文版

## 定义

通过访谈、观察、开放问卷等方式，理解用户"为什么"这样做，而非仅仅"做了什么"。侧重于深入理解行为背后的动机、感受和情境。

## 与定量研究的区别

| 维度 | 定性研究 | 定量研究 |
|------|---------|---------|
| 回答的问题 | 为什么/如何 | 有多少/多大 |
| 样本量 | 小（10-50人） | 大（100+） |
| 数据类型 | 文本、叙事、观察 | 数字、统计 |
| 分析方式 | 主题编码、模式识别 | 统计分析、趋势分析 |
| 结论类型 | 假设、洞察 | 验证、规模化 |

## 核心方法

### Thematic Analysis（主题分析法）

六步流程：熟悉材料 → 初始编码 → 发展主题 → 复核主题 → 细化主题 → 输出报告

核心原则：
- 编码宁可多，合并比拆分容易
- 主题要有区分度，能讲出连贯故事
- 回到数据检验每个主题的充分性

### Affinity Mapping（亲和图法）

协作式整理观察的方法：
1. 每条独立观察写成单独便签
2. 按相似性聚类（不预设类别）
3. 命名分组抓住共同线索
4. 识别高层级主题

### Triangulation（三角验证）

通过多来源交叉增强置信度：
- **方法三角**：访谈 + 问卷 + 数据分析
- **来源三角**：不同参与者/分群
- **时间三角**：不同时间点重复观察

## 定性 → 定量反馈回路

```
定性（访谈）→ 产生假设，发现模式
    ↓
定量（问卷/数据）→ 验证规模，检验假设
    ↓
定性（深挖）→ 解释意外发现，深入理解
```

## 数据采集方式

| 方式 | 产出 | 适用场景 |
|------|------|---------|
| 深度访谈 | 转录稿、引语 | 探索性研究、复杂决策 |
| 焦点小组 | 讨论记录、共识 | 概念验证、方向探索 |
| 开放式问卷 | 文本回复 | 大规模初筛 |
| 观察法 | 行为记录 | 自然场景下的真实行为 |
| 日志分析 | 使用路径、频次 | 产品迭代、体验优化 |

## 关键原则

- **行为 > 口头偏好**：人们实际做的和他们说的常不同
- **矛盾即信号**：不同来源给出不同结论时，差异揭示分群
- **引语是证据，发现是解释**：区分原始数据和分析师解读
- **离群点很重要**：不强行归类，异常值往往最有价值
