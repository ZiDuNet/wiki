# AI操作系统

**类型:** 概念

## 定义

将 Claude Code 理解为「AI 操作系统」，而非简单的聊天框。类比 macOS 是桌面操作系统，Claude Code 是 AI 员工们跑在上面的系统。

## 组件类比

| 组件 | 类比 | 核心职责 |
|-----|------|---------|
| Skill | 员工技能手册 | 告诉 AI 怎么做某件具体的事 |
| MCP | 外部工具连接器 | 给 AI 真正能操作外部世界的能力 |
| Harness | 项目经理 | 决定谁干什么、按什么顺序干 |
| Agent | 员工 | 实际执行任务的角色 |
| CLAUDE.md | 公司制度文件 | 约束整个系统的行为准则 |
| Project | 业务部门 | 隔离不同业务的上下文 |

## 认知转变

不是在「装插件」、不是在「加功能」——**我在搭一家 AI 公司**。公司大了，需要制度、分部门、流程。

## Skill 三层结构

1. **知识层**：知道什么是好的结构、SEO 规范、平台差异
2. **流程层**：Step 1 → Step 6 的执行步骤
3. **工具调用层**：读文件、调脚本、处理配图
