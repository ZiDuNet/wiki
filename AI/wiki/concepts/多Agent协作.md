# 多Agent协作

**类型:** 架构模式

## 简介

多个 AI Agent 分工负责不同任务（抓取、分析、报告生成），通过协作完成复杂任务。与单 Agent 相比，擅长处理需要多维度信息的场景，如舆情分析需要同时抓取多平台内容并做综合判断。

## 典型模式

一个 Agent 负责全网内容抓取，一个负责情绪和关键词分析，一个负责生成可读报告
