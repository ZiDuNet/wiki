# API中转

API中转站 = AI时代的水电工，帮用户绕过注册/支付/网络障碍，收取API调用差价。

## 核心逻辑

- 海外服务器部署One-API，接入OpenRouter/官方接口
- 给国内用户一个直连地址，微信支付宝付款
- 赚取官方价格与用户支付价格之间的差价

## 商业要点

- 核心卖点：国内直连 + 微信支付 + 比官方便宜20%~50%
- 工具成熟：One-API，GitHub 20K+ Star，Docker一键部署
- 收益模型：冷启动→成长期→稳定期（6个月周期）
- 护城河：垂直领域技术支持，不是价格战

## 三个坑

1. 合规风险：遵守法规，不碰灰色地带
2. 价格战必死：大厂有规模优势
3. 服务器被封：需备用节点
