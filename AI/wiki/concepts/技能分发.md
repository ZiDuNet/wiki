# 技能分发

将中央技能库中的 Skill 分发到各 AI Agent 工具（全局目录或项目目录）的过程。

## 分发场景

| 场景 | 说明 |
|------|------|
| 全局分发 | 中央库 → ~/.claude/skills/ 等用户级目录 |
| 项目分发 | 中央库 → 项目/.claude/skills/ 等项目级目录 |
| Preset 分发 | 按预设技能组批量分发 |

## 分发方式

- **软链接**：节省空间，更新自动生效
- **复制**：独立副本，适合项目级隔离

## Skills-Manager 实现

- 全局工作区：按 Agent 查看其全局目录里的实际存在的全部 skill
- 项目工作区：管理项目级 skill，与中央库双向同步
- 关联工作区：把任意目录指成 skill 根
