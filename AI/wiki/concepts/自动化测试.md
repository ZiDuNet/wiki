# 自动化测试

**类型:** 概念 (技术/方法论)
**提及文章数:** 2

## 定义

自动化测试是使用软件工具自动执行测试用例的技术，通过AI Agent实现从测试计划生成到失败修复的全自动化链路。

## Test Agents架构

Playwright Test Agents包含三个协作Agent：

| Agent | 职责 | 输出 |
|-------|------|------|
| Planner | 探索应用 | Markdown格式测试计划 |
| Generator | 代码生成 | 可执行的Playwright测试代码 |
| Healer | 修复维护 | 修复失败测试或标记skip |

## 工具选择策略

| 工具类型 | Token消耗 | 适用场景 |
|---------|----------|---------|
| MCP | 高 | 感知工具，写单个测试 |
| CLI | 低 | 执行工具，搭自动化流程 |
| Agent | 自主 | 建整体测试覆盖 |

## 核心流程

1. **测试计划生成** — Planner探索应用，输出测试计划
2. **代码转换** — Generator把计划转为可执行代码并实时验证
3. **失败修复** — Healer自动修复失败测试，无法修复则标记skip并说明原因
