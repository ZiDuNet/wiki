# 中央技能库

Skills-Manager 等工具提出的概念：用一个统一的目录（如 ~/.skills-manager）集中存放已安装的所有 Skill，再通过软链接或复制分发到各 Agent 的技能目录。

## 核心价值

| 问题 | 解决方案 |
|------|----------|
| 工具多、路径乱 | Cursor/Claude Code/Codex 等各自一套 skills 目录，手工拷贝容易漏、版本不一致 |
| 想「我的技能库」 | 先集中收纳，再按需装到某个 Agent 或某个项目 |
| 项目级与全局分开管 | 全局工作区 + 项目工作区，与中央库双向同步 |

## 目录结构

默认中央库位置：
```
~/.skills-manager/
├── skills/          # 已安装的 skill
├── presets/         # 预设技能组
└── config.json      # 配置文件
```

## 与各 Agent 的关系

```
中央库 ~/.skills-manager
    ↓ 软链接/复制
    ├── ~/.claude/skills/
    ├── ~/.cursor/skills/
    ├── ~/.codex/skills/
    └── 项目/.claude/skills/
```
