# SSH隧道

**Keywords:** ssh, tunnel, 零侵入, 加密通信

## 定义

SSH隧道是一种通过 SSH 协议建立的加密通信通道，用于在不安装额外软件的情况下实现客户端与服务器之间的安全数据传输。

## 核心特点

### 零侵入架构
- 客户端逻辑完全在本地运行
- 服务器端无需安装 Agent 或后端服务
- 只需服务器开放标准 SSH 端口（22）

### 安全性
- 所有通信通过 SSH 协议加密
- 与直接 `ssh` 登录使用同一条通道
- 不增加服务器攻击面

### 性能
- 基于 TCP 协议，稳定可靠
- 支持端口转发和隧道嵌套

## 应用场景

### 运维工具
- [[GMSSH]] 使用纯 SSH 隧道实现图形化运维终端
- 远程文件管理、实时监控、控制台操作
- 避免传统运维面板需要安装 Agent 的问题

### 与传统方案对比

| 方案 | 服务器端要求 | 安全性 |
|-----|------------|--------|
| SSH 隧道 | 仅需开放22端口 | 高，无额外攻击面 |
| 宝塔面板 | 需安装 Agent | 中，增加攻击面 |
| 1Panel | 需装后端服务 | 中，增加攻击面 |
