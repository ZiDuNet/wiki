# Skill分发

将同一份 Skill 一键安装到多个 AI 编程工具平台的能力。

## 核心价值

避免在多个工具目录间复制粘贴，实现 Skill 的统一管理和分发。

## 支持平台

| 平台类型 | 具体工具 |
|---|---|
| AI Coding Agent | [[Claude]], [[Codex]], [[Hermes-Agent]] |
| IDE 插件 | [[Cursor]], [[Windsurf]], [[Trae]] |
| CLI 工具 | Gemini CLI, Qoder, OpenCode, Roo Code |

## 分发模式

| 模式 | 说明 |
|---|---|
| Symlink | 共享编辑，一处修改多处生效 |
| Copy | 各平台保留独立副本 |

## 代表工具

- [[PromptHub]] — 支持 15+ 平台一键分发
- [[Skills-Manager]] — 中央技能库统一管理分发
