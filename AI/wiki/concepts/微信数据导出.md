# 微信数据导出

## 定义

微信数据导出是指从微信客户端的加密数据库中提取聊天记录、联系人等数据的技术过程。微信 Mac 版使用 SQLCipher 加密的 SQLite 数据库（AES-256-CBC逐页加密），密钥藏在进程内存中，无官方API或导出功能。

## 技术难点

1. **加密数据库**：SQLCipher加密，AES-256-CBC逐页加密
2. **密钥隐藏**：密钥存在于进程内存中，无法直接读取
3. **无官方API**：微信未提供数据导出接口
4. **系统保护**：macOS阻止对/Applications下App的codesign操作

## 解决方案：wechat-cli

wechat-cli 通过以下技术链路实现导出：

```
task_for_pid读取进程内存 → mach_vm_read扫描密钥模式 → AES-256-CBC透明解密 → 结构化SQL查询 → JSON/Markdown输出
```

### 核心命令

- `export`：导出为Markdown或纯文本（知识库导入关键）
- `history`：按时间范围获取聊天记录
- `search`：全局关键词搜索
- `new-messages`：增量新消息（自动化同步）

### macOS签名要点

需要给微信添加 `get-task-allow` 调试权限：
1. 复制微信到 `~/Applications`（绕开/Applications保护）
2. 提取并修改 entitlements（移除sandbox相关权限）
3. 用ad-hoc签名重新签名

## 输出格式

导出的Markdown自带时间戳、发言人标注、消息类型标记：

```markdown
# 聊天记录: 技术交流群
- [2026-04-08 23:32] 某工程师: 周末用Codex，半天把毕业设计写完了
- [2026-04-09 10:38] 某架构师: 前端用Gemini，后端用Claude
- [2026-04-10 09:18] 某PM: [图片] (local_id=234)
```

## 应用场景

1. **知识库构建**：导出聊天记录编译成LLM Wiki
2. **群聊情报助手**：自动总结群聊消息
3. **团队知识沉淀**：将讨论转化为可查询知识
4. **个人记忆备份**：保存重要对话历史

## 安全考量

- **只读操作**：不修改、不删除任何消息
- **本地优先**：数据全程不离开本机
- **可审计**：C源码320行+Python解密78行，可逐行审计
- **合规提醒**：群聊记录涉及他人发言，需符合隐私法规
