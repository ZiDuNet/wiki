# 数字员工操作系统

"数字员工操作系统"是 [[Clawith]] 提出的定位，指同时承担以下职责的平台：

1. **运行时**：Agent 在此平台上持续运行（而非一次性对话）
2. **身份管理**：管理 Agent 的身份（soul.md）、记忆（memory.md）
3. **调度引擎**：Trigger Daemon 负责自主触发和任务调度
4. **组织管理**：权限分级（Autonomy Policy）、审计日志、用量配额
5. **渠道接入**：连接飞书/钉钉/企微/Discord/微信等 IM 渠道

## 与普通 Agent 平台的区别

普通平台（如 Coze、Dify）的 Bot 是"响应式"的；数字员工操作系统的 Agent 是"主动式"的——自己管理日程、自主行动。
