# 跨平台桌面应用（WebView原生感）

**类型:** 概念 / 技术模式
**来源:** [[推荐 3 个 GitHub 上刚开源但实用的项目，收藏一波]]

## 背景

Raycast 底层是 WebView + Node.js，但用起来丝滑得像原生应用。这说明"看起来原生"和"用 Web 技术实现"并不矛盾。

## 关键设计

native-feel-skill 研究的核心问题：如何让 WebView + Node.js 实现的桌面应用在 macOS 和 Windows 上有原生体验。

## 实现要点

1. **架构揭秘**：Raycast 是 Electron 类的 WebView 应用，但视觉和交互设计做到极致
2. **逆向工程**：深入分析 Raycast Beta 的 UI 响应、窗口管理、系统集成
3. **设计模式提炼**：把"看起来像原生"的视觉/交互模式系统化
