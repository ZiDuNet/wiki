# 四信号知识图谱

**类型:** 概念

## 定义

在 LLM Wiki 企业级扩展中，用于构建和组织大规模知识网络的图谱方法。结合语义搜索、社区检测等技术，解决数百页面、数十万字规模的知识组织问题。

## 四信号含义

知识图谱构建中的四个关键信号维度：

| 信号类型 | 说明 |
|---------|------|
| 结构信号 | 页面间的链接关系、目录层级 |
| 语义信号 | 内容主题相似度、概念关联 |
| 时序信号 | 知识演进脉络、版本历史 |
| 使用信号 | 查询频率、引用热度、用户关注 |

## 与 Louvain 社区检测的关系

Louvain 算法用于社区检测，在知识图谱中应用：
- 自动发现知识主题聚类
- 识别概念边界
- 优化索引结构
- 辅助分层导航

## 企业级应用场景

1. **分层索引构建**：全局 index.md → 子目录 index.md → 具体页面
2. **语义搜索优化**：BM25 + 向量混合搜索 + LLM 重排序
3. **知识可视化**：Graph View 帮助发现结构问题
4. **孤立页面检测**：识别没有链接的页面
5. **缺失链接补全**：提到概念但没有独立页面时提示

## 关键技术栈

| 技术 | 用途 |
|-----|------|
| BM25 | 传统文本检索 |
| 向量搜索 | 语义相似度匹配 |
| LLM 重排序 | 智能结果优化 |
| Louvain 算法 | 社区检测与聚类 |
| Graph View | 可视化展示 |

## 与 LLM Wiki 的结合

在 LLM Wiki 三层架构中：
- Raw Sources 层：原始数据输入
- Wiki 层：知识图谱核心构建区
- Schema 层：定义图谱维护规则

Lint 操作会检查：
- 矛盾检测：不同页面数据冲突
- 陈旧断言：时间敏感数据过期
- 孤立页面：缺失链接关系
- 数据空白：主题缺少来源支撑

## 实践要点

1. 每个页面至少链接 2 个其他页面
2. Graph View 定期检查结构问题
3. 社区检测结果指导目录重组
4. 高频查询页面优先优化索引
